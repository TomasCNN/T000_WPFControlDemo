# 999999009-15_工业上位机日志完整落地方案

分 3 套方案：简易原生日志（快速上手）、NLog 工业级日志（推荐项目长期用）、极简异步日志（专门给相机回调低 CT 场景）

## 一、核心设计原则（相机采集场景必看）

1. **采集回调严禁同步写文件**：同步 IO 会产生几十 ms 随机 CT 尖刺，直接丢帧；
2. 所有日志走**异步队列**，采集线程只提交日志消息，不阻塞；
3. 分级日志：Debug/Info/Warn/Error，生产环境关闭 Debug 减少输出；
4. 日志包含关键上下文：帧序号、相机状态、耗时 CT、异常堆栈；
5. 自动分割文件、自动删除过期日志，防止磁盘爆满。

### 方案 1：NLog 工业标准日志（项目首选，功能最全）

### 1. 安装 NuGet 包

plaintext

```tex
Install-Package NLog
Install-Package NLog.Config
```

### 2. 配置 NLog.config（放在程序输出目录，复制到输出目录）

xaml:

```xaml
<?xml version="1.0" encoding="utf-8" ?>
<nlog xmlns="http://www.nlog-project.org/schemas/NLog.xsd"
      xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
      autoReload="true"
      internalLogLevel="Warn"
      internalLogFile="logs/internal-nlog.txt">

  <!-- 日志输出目标 -->
  <targets async="true">
    <!-- 滚动文件日志：异步写入，不阻塞业务线程 -->
    <target xsi:type="File" name="fileTarget" fileName="logs/app-${shortdate}.log"
            layout="${longdate}|${level:uppercase=true}|${threadid}|${logger}|${message} ${exception:format=tostring}"
            archiveEvery="Day"
            maxArchiveFiles="30"
            archiveNumbering="Sequence" />

    <!-- 控制台输出（调试用，生产可注释） -->
    <target xsi:type="Console" name="consoleTarget"
            layout="${longdate}|${level:uppercase=true}|${message}" />
  </targets>

  <!-- 日志规则 -->
  <rules>
    <!-- 全局日志，生产设为Info，调试设Debug -->
    <logger name="*" minlevel="Info" writeTo="fileTarget" />
    <logger name="*" minlevel="Debug" writeTo="consoleTarget" />
  </rules>
</nlog>
```

关键：`targets async="true"` 全局异步，**相机回调打印日志完全不会拉高 CT**。

### 3. 封装全局日志工具类

csharp:

```c#
using NLog;

public static class Logger
{
    private static readonly Logger _log = LogManager.GetCurrentClassLogger();

    // 调试日志（开发用，生产关闭）
    public static void Debug(string msg) => _log.Debug(msg);
    public static void Debug(string msg, object obj) => _log.Debug(msg, obj);

    // 普通信息：相机正常取图、启动成功
    public static void Info(string msg) => _log.Info(msg);
    public static void Info(string msg, object obj) => _log.Info(msg, obj);

    // 警告：轻微异常、超时、帧数下降
    public static void Warn(string msg) => _log.Warn(msg);

    // 错误：相机断开、取图失败、内存异常
    public static void Error(string msg) => _log.Error(msg);
    public static void Error(string msg, Exception ex) => _log.Error(ex, msg);
}
```

## 方案 2：极简原生异步日志（无第三方 NuGet，轻量化小工具）

不想引入 NLog 依赖，自己实现**阻塞队列异步日志**，专门适配相机低 CT 场景。

## 完整工具类

csharp:

```c#
using System;
using System.Collections.Concurrent;
using System.IO;
using System.Threading;

public static class AppLog
{
    // 阻塞队列：存储日志消息
    private static readonly BlockingCollection<string> _logQueue = new BlockingCollection<string>(1000);
    private static readonly Thread _writeThread;
    private static readonly string _logPath = Path.Combine(AppDomain.CurrentDomain.BaseDirectory, "logs");

    static AppLog()
    {
        // 创建日志文件夹
        if (!Directory.Exists(_logPath))
            Directory.CreateDirectory(_logPath);

        // 启动后台写文件线程
        _writeThread = new Thread(WriteLoop)
        {
            IsBackground = true,
            Priority = ThreadPriority.BelowNormal
        };
        _writeThread.Start();
    }

    // 后台循环写文件
    private static void WriteLoop()
    {
        string todayFile = Path.Combine(_logPath, $"{DateTime.Now:yyyy-MM-dd}.log");
        while (true)
        {
            try
            {
                string msg = _logQueue.Take();
                // 追加写入文件
                using var sw = File.AppendText(todayFile);
                sw.WriteLine(msg);
            }
            catch
            {
                // 写日志失败静默丢弃，不影响主程序
            }
        }
    }

    // 格式化日志
    private static string FormatLog(string level, string message, Exception ex = null)
    {
        string time = DateTime.Now.ToString("yyyy-MM-dd HH:mm:ss.fff");
        string thread = Thread.CurrentThread.ManagedThreadId.ToString();
        string logStr = $"{time} | {level,5} | 线程{thread} | {message}";
        if (ex != null)
            logStr += $"\n堆栈:{ex}";
        return logStr;
    }

    // 对外接口：仅入队，无IO，极速返回
    public static void Info(string msg)
        => _logQueue.Add(FormatLog("INFO", msg));

    public static void Error(string msg, Exception ex = null)
        => _logQueue.Add(FormatLog("ERROR", msg, ex));

    public static void Warn(string msg)
        => _logQueue.Add(FormatLog("WARN", msg));

    public static void Debug(string msg)
        => _logQueue.Add(FormatLog("DEBUG", msg));
}
```

**使用方式和 NLog 完全一致，采集回调直接调用`AppLog.Info()`，入队操作微秒级，不会拉高 CT。**

## 方案 3：禁止踩坑！日志会拉高相机 CT 的错误写法

### 错误 1：回调内同步直接写文件

csharp:

```c#
// 绝对禁止！每次打开/写入文件IO阻塞，CT暴涨十几毫秒
File.AppendAllText("log.txt", "xxx");
```

### 错误 2：回调内拼接复杂字符串、序列化大图

csharp:

```c#
// 大量字符串分配，频繁GC，产生CT尖刺
Logger.Info($"图像数据:{opencvImage.ImageData}");
```

### 错误 3：频繁打印 Debug 级日志

高帧率相机每秒 100 帧，每条 Debug 日志都会填满队列、磁盘 IO 飙升，生产环境关闭 Debug。

## 工业相机场景日志最佳实践

1. **采集回调只打印关键信息**

   只打印异常、帧丢失、相机断开；正常帧不要每一帧都打 Info，可隔 50 帧打印一次统计。

2. **日志带上关键排查字段**

   帧序号、图像宽高、超时时间、GDI 对象数量、内存占用。

3. 异常日志必须传入 Exception，保存完整堆栈，快速定位崩溃点。

4. 日志文件夹自动清理，设置最多保留 30 天日志，避免磁盘占满程序卡死。

5. 统一使用异步日志框架，杜绝同步 IO 阻塞采集线程丢帧。

6. 程序退出时等待日志队列写完，防止日志丢失。
