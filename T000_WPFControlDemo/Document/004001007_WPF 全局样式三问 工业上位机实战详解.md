# 004001007_WPF 全局样式三问 工业上位机实战详解

## 问题一：详细说明 WPF 全局控件样式的具体实现案例

### 1.1 实现层级总览

WPF 全局样式有三种实现层级，工业项目推荐使用**层级 2（资源字典拆分）**，大型多主题项目使用**层级 3**：

| 层级 | 实现方式                      | 适用场景                 | 工业项目推荐度 |
| :--- | :---------------------------- | :----------------------- | :------------- |
| 1    | App.xaml 直接定义             | 小型项目、少于 10 个样式 | ⭐⭐             |
| 2    | 按功能拆分 ResourceDictionary | 中大型项目、完整工业界面 | ⭐⭐⭐⭐⭐          |
| 3    | 独立主题程序集                | 大型项目、多产品复用     | ⭐⭐⭐            |

------

### 1.2 层级 1：基础版（App.xaml 直接定义）

**最简单的全局样式实现**，适合项目初期快速搭建。

#### 完整代码

xaml:

```xaml
<!-- App.xaml -->
<Application x:Class="IndustrialVisionTemplate.App"
             xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             StartupUri="Views/MainWindow.xaml">
    <Application.Resources>
        <!-- 1. 先定义颜色资源 -->
        <SolidColorBrush x:Key="PrimaryColor" Color="#2196F3"/>
        <SolidColorBrush x:Key="SuccessColor" Color="#4CAF50"/>
        <SolidColorBrush x:Key="DangerColor" Color="#F44336"/>
        <SolidColorBrush x:Key="White" Color="#FFFFFF"/>
        <SolidColorBrush x:Key="Gray300" Color="#E0E0E0"/>

        <!-- 2. 定义全局按钮样式（所有Button自动应用） -->
        <Style TargetType="Button">
            <Setter Property="Background" Value="{StaticResource PrimaryColor}"/>
            <Setter Property="Foreground" Value="{StaticResource White}"/>
            <Setter Property="FontSize" Value="14"/>
            <Setter Property="Padding" Value="15,8"/>
            <Setter Property="MinWidth" Value="80"/>
            <Setter Property="CornerRadius" Value="4"/>
            <Setter Property="Template">
                <Setter.Value>
                    <ControlTemplate TargetType="Button">
                        <Border Background="{TemplateBinding Background}"
                                CornerRadius="{TemplateBinding CornerRadius}">
                            <ContentPresenter HorizontalAlignment="Center"
                                              VerticalAlignment="Center"/>
                        </Border>
                        <ControlTemplate.Triggers>
                            <Trigger Property="IsMouseOver" Value="True">
                                <Setter Property="Opacity" Value="0.9"/>
                            </Trigger>
                            <Trigger Property="IsPressed" Value="True">
                                <Setter Property="Opacity" Value="0.8"/>
                            </Trigger>
                        </ControlTemplate.Triggers>
                    </ControlTemplate>
                </Setter.Value>
            </Setter>
        </Style>

        <!-- 3. 定义特殊按钮样式（需要显式引用） -->
        <Style x:Key="DangerButtonStyle" TargetType="Button" BasedOn="{StaticResource {x:Type Button}}">
            <Setter Property="Background" Value="{StaticResource DangerColor}"/>
        </Style>
    </Application.Resources>
</Application>
```

#### 使用效果

xaml:

```
<!-- 自动应用全局按钮样式 -->
<Button Content="启动设备"/>

<!-- 显式引用危险按钮样式 -->
<Button Content="停止设备" Style="{StaticResource DangerButtonStyle}"/>
```

### 1.3 层级 2：工业标准拆分版（推荐）

**这是你当前项目正在使用的方式**，将不同类型的样式拆分到独立的资源字典文件中，结构清晰，便于维护。

#### 项目结构

plaintext

```tex
IndustrialVisionTemplate/
└── Styles/
    ├── 01_Colors.xaml          # 所有颜色统一管理
    ├── 02_Fonts.xaml           # 字体与尺寸规范
    ├── 03_ButtonStyles.xaml    # 按钮样式
    ├── 04_InputStyles.xaml     # 输入控件样式
    └── 06_DataGridStyles.xaml  # 生产记录表格样式
```

#### 关键步骤

1. **按功能拆分样式文件**：每个文件只负责一类控件的样式
2. **在 App.xaml 中按顺序合并**：颜色→字体→基础样式→派生样式
3. **使用 BasedOn 实现样式继承**：避免重复代码

#### 工业实战案例：生产记录 DataGrid 全局样式

xaml:

```xaml
<!-- Styles/06_DataGridStyles.xaml -->
<ResourceDictionary xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
                    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml">
    <!-- 全局DataGrid样式：所有DataGrid自动应用 -->
    <Style TargetType="DataGrid">
        <Setter Property="Background" Value="{StaticResource White}"/>
        <Setter Property="BorderBrush" Value="{StaticResource BorderDefault}"/>
        <Setter Property="RowHeight" Value="36"/>
        <Setter Property="ColumnHeaderHeight" Value="40"/>
        <Setter Property="GridLinesVisibility" Value="Horizontal"/>
        <Setter Property="CanUserAddRows" Value="False"/>
        <Setter Property="IsReadOnly" Value="True"/>
        <Setter Property="EnableRowVirtualization" Value="True"/>
    </Style>

    <!-- 表头样式 -->
    <Style TargetType="DataGridColumnHeader">
        <Setter Property="Background" Value="{StaticResource Gray100}"/>
        <Setter Property="FontWeight" Value="Bold"/>
        <Setter Property="HorizontalContentAlignment" Value="Center"/>
    </Style>

    <!-- 行样式：工业专用NG行自动变红 -->
    <Style TargetType="DataGridRow">
        <Style.Triggers>
            <DataTrigger Binding="{Binding IsOk}" Value="False">
                <Setter Property="Background" Value="#FFEBEE"/>
                <Setter Property="Foreground" Value="{StaticResource StatusStopped}"/>
            </DataTrigger>
        </Style.Triggers>
    </Style>
</ResourceDictionary>
```

#### App.xaml 合并

xaml:

```xaml
<Application.Resources>
    <ResourceDictionary>
        <ResourceDictionary.MergedDictionaries>
            <!-- 顺序不能错！颜色必须放在最前面 -->
            <ResourceDictionary Source="Styles/01_Colors.xaml"/>
            <ResourceDictionary Source="Styles/02_Fonts.xaml"/>
            <ResourceDictionary Source="Styles/03_ButtonStyles.xaml"/>
            <ResourceDictionary Source="Styles/04_InputStyles.xaml"/>
            <ResourceDictionary Source="Styles/06_DataGridStyles.xaml"/>
        </ResourceDictionary.MergedDictionaries>
    </ResourceDictionary>
</Application.Resources>
```

## 问题二：如何在 WPF 中实现动态切换主题？

工业项目中最常用的是**浅色 / 深色主题切换**，适应白天 / 夜间不同的现场环境。下面是**工业级高性能主题切换方案**，切换时无卡顿，不影响生产流程。

------

### 2.1 实现原理

WPF 的`DynamicResource`会在运行时动态解析资源，我们通过**替换全局资源字典中的颜色资源**来实现主题切换。

------

### 2.2 分步实现

#### 第一步：准备主题资源文件

在`Styles/Themes`文件夹下创建两个主题文件：

plaintext

```xaml
Styles/
└── Themes/
    ├── LightTheme.xaml  # 浅色主题（默认）
    └── DarkTheme.xaml   # 深色主题
```

**LightTheme.xaml**（浅色主题）

xaml:

```
<ResourceDictionary xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
                    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml">
    <!-- 工业标准状态颜色 -->
    <SolidColorBrush x:Key="StatusRunning" Color="#4CAF50"/>
    <SolidColorBrush x:Key="StatusStopped" Color="#F44336"/>
    <SolidColorBrush x:Key="StatusIdle" Color="#FF9800"/>

    <!-- 中性色 -->
    <SolidColorBrush x:Key="White" Color="#FFFFFF"/>
    <SolidColorBrush x:Key="Gray100" Color="#F5F5F5"/>
    <SolidColorBrush x:Key="Gray300" Color="#E0E0E0"/>
    <SolidColorBrush x:Key="TextPrimary" Color="#212121"/>
</ResourceDictionary>
```

**DarkTheme.xaml**（深色主题）

xaml:

```xaml
<ResourceDictionary xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
                    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml">
    <!-- 工业标准状态颜色（深色主题下更鲜艳） -->
    <SolidColorBrush x:Key="StatusRunning" Color="#66BB6A"/>
    <SolidColorBrush x:Key="StatusStopped" Color="#EF5350"/>
    <SolidColorBrush x:Key="StatusIdle" Color="#FFCA28"/>

    <!-- 中性色 -->
    <SolidColorBrush x:Key="White" Color="#212121"/>
    <SolidColorBrush x:Key="Gray100" Color="#303030"/>
    <SolidColorBrush x:Key="Gray300" Color="#424242"/>
    <SolidColorBrush x:Key="TextPrimary" Color="#FFFFFF"/>
</ResourceDictionary>
```

#### 第二步：修改所有样式使用 DynamicResource

⚠️ **关键步骤**：将所有样式中的`StaticResource`改为`DynamicResource`，这样资源变化时会自动更新。

xaml:

```xaml
<!-- 修改前（静态资源，不支持动态切换） -->
<Setter Property="Background" Value="{StaticResource White}"/>

<!-- 修改后（动态资源，支持动态切换） -->
<Setter Property="Background" Value="{DynamicResource White}"/>
```

#### 第三步：实现主题管理器类

csharp:

```c#
using System;
using System.Windows;

namespace IndustrialVisionTemplate.Managers
{
    /// <summary>
    /// 主题管理器（单例）
    /// </summary>
    public class ThemeManager
    {
        private static ThemeManager _instance;
        public static ThemeManager Instance => _instance ??= new ThemeManager();

        private ThemeManager() { }

        /// <summary>
        /// 当前主题
        /// </summary>
        public string CurrentTheme { get; private set; } = "Light";

        /// <summary>
        /// 切换主题
        /// </summary>
        /// <param name="themeName">主题名称：Light/Dark</param>
        public void SwitchTheme(string themeName)
        {
            if (CurrentTheme == themeName) return;

            try
            {
                // 1. 清空现有主题资源
                var appResources = Application.Current.Resources.MergedDictionaries;
                for (int i = appResources.Count - 1; i >= 0; i--)
                {
                    if (appResources[i].Source != null && 
                        appResources[i].Source.OriginalString.Contains("Themes/"))
                    {
                        appResources.RemoveAt(i);
                    }
                }

                // 2. 加载新主题
                var themeUri = new Uri($"Styles/Themes/{themeName}Theme.xaml", UriKind.Relative);
                var themeDict = new ResourceDictionary { Source = themeUri };
                appResources.Insert(0, themeDict);

                // 3. 更新当前主题
                CurrentTheme = themeName;

                // 4. 保存主题设置到配置文件
                Config.App.CurrentTheme = themeName;
                Config.Save();

                Logger.LogCommucation.Info($"已切换到{themeName}主题");
            }
            catch (Exception ex)
            {
                Logger.LogApp.Error($"切换主题失败：{ex.Message}", ex);
            }
        }

        /// <summary>
        /// 加载保存的主题
        /// </summary>
        public void LoadSavedTheme()
        {
            if (!string.IsNullOrEmpty(Config.App.CurrentTheme))
            {
                SwitchTheme(Config.App.CurrentTheme);
            }
        }
    }
}
```

#### 第四步：在 App.xaml.cs 中初始化主题

csharp:

```c#
public partial class App : Application
{
    protected override void OnStartup(StartupEventArgs e)
    {
        base.OnStartup(e);
        
        // 加载保存的主题
        ThemeManager.Instance.LoadSavedTheme();
    }
}
```

### 2.3 工业场景注意事项

1. **性能优先**：只切换颜色资源，不要重新加载所有样式，避免卡顿
2. **状态颜色不变**：运行绿、停机红、空闲黄是工业标准，主题切换时不要改变这些颜色的语义
3. **高对比度**：深色主题下确保文本和背景的对比度符合标准，避免看不清
4. **持久化保存**：主题设置要保存到配置文件，程序重启后自动恢复

## 问题三：如何避免 WPF 全局样式的优先级问题？

全局样式不生效 99% 都是因为**优先级搞反了**。下面先讲清楚 WPF 的样式优先级顺序，然后针对每个常见坑给出解决方案。

------

### 3.1 WPF 样式优先级（从高到低）

⚠️ **记住这个顺序，所有优先级问题都能解决**：

1. **控件本地属性**（直接在控件上设置的属性）
2. **动画属性**
3. **本地样式**（控件内部定义的 Style）
4. **显式样式**（指定了`x:Key`的样式，通过`Style="{StaticResource Key}"`引用）
5. **隐式样式**（没有指定`x:Key`的全局样式，自动应用到所有同类型控件）
6. **继承的样式**（通过`BasedOn`继承的样式）
7. **默认样式**（控件自带的系统样式）

------

### 3.2 常见问题与解决方案

#### 问题 1：全局样式不生效，被本地属性覆盖

**错误代码**：

xaml:

```xaml
<!-- 全局样式设置背景为蓝色 -->
<Style TargetType="Button">
    <Setter Property="Background" Value="Blue"/>
</Style>

<!-- 本地设置背景为红色，优先级更高，全局样式被覆盖 -->
<Button Content="测试" Background="Red"/>
```

**解决方案**：

- 不要在控件上直接设置会被全局样式管理的属性
- 如果需要特殊样式，定义一个显式样式并通过`BasedOn`继承全局样式

**正确代码**：

xaml:

```xaml
<!-- 定义特殊按钮样式，继承全局样式 -->
<Style x:Key="RedButtonStyle" TargetType="Button" BasedOn="{StaticResource {x:Type Button}}">
    <Setter Property="Background" Value="Red"/>
</Style>

<!-- 显式引用 -->
<Button Content="测试" Style="{StaticResource RedButtonStyle}"/>
```

------

#### 问题 2：资源合并顺序错误，后面的样式覆盖前面的

**错误代码**：

xaml:

```xaml
<!-- 错误顺序：先合并按钮样式，再合并颜色资源 -->
<ResourceDictionary.MergedDictionaries>
    <ResourceDictionary Source="Styles/03_ButtonStyles.xaml"/>
    <ResourceDictionary Source="Styles/01_Colors.xaml"/>
</ResourceDictionary.MergedDictionaries>
```

**问题**：按钮样式中引用的颜色资源还没加载，会导致样式不生效。

**解决方案**：

- 严格按照**颜色→字体→基础样式→派生样式**的顺序合并
- 被依赖的资源必须放在前面

**正确代码**：

xaml:

```xaml
<ResourceDictionary.MergedDictionaries>
    <ResourceDictionary Source="Styles/01_Colors.xaml"/>
    <ResourceDictionary Source="Styles/02_Fonts.xaml"/>
    <ResourceDictionary Source="Styles/03_ButtonStyles.xaml"/>
</ResourceDictionary.MergedDictionaries>
```

------

#### 问题 3：隐式样式只在当前窗口生效，不全局生效

**原因**：如果在 Window 的 Resources 中定义了隐式样式，它只会在这个窗口内生效，不会影响其他窗口。

**解决方案**：

- 所有全局样式必须定义在`App.xaml`的 Resources 中，或者合并到 App.xaml 的资源字典中
- 不要在单个窗口中定义全局隐式样式

------

#### 问题 4：自定义控件的全局样式不生效

**常见原因**：

1. 忘记在静态构造函数中设置`DefaultStyleKey`
2. 样式的 TargetType 与控件类型不匹配
3. 控件的命名空间引用错误

**解决方案**：

- 确保自定义控件的静态构造函数中有这行代码：

  csharp:

  ```c#
  static IoIndicator()
  {
      DefaultStyleKeyProperty.OverrideMetadata(
          typeof(IoIndicator), 
          new FrameworkPropertyMetadata(typeof(IoIndicator)));
  }
  ```

  

- 确保样式的 TargetType 与控件类型完全一致，包括命名空间

------

### 3.3 工业项目最佳实践

1. **禁止在控件上直接设置全局样式管理的属性**：如 Background、Foreground、FontSize 等
2. **所有颜色、字体、尺寸都定义为资源**：禁止硬编码
3. **使用 BasedOn 实现样式继承**：避免重复代码，确保风格统一
4. **全局样式只定义通用属性**：特殊需求使用显式样式
5. **定期检查样式优先级**：使用 Snoop 工具查看控件的属性来源，快速定位问题

------

## 总结

1. **全局样式实现**：工业项目推荐使用资源字典拆分的方式，结构清晰，便于维护
2. **动态主题切换**：通过替换颜色资源字典实现，所有样式使用 DynamicResource
3. **优先级问题**：记住优先级顺序，避免本地属性覆盖全局样式，确保资源合并顺序正确
