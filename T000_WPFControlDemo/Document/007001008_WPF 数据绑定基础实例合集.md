## 前置准备：通用 ViewModel 基类

所有 MVVM 绑定都依赖属性变更通知，先封装一个通用基类，后续所有示例复用：

csharp:

```c#
using System.ComponentModel;
using System.Runtime.CompilerServices;
using System.Collections.Generic;

public class ViewModelBase : INotifyPropertyChanged
{
    // 属性变更事件
    public event PropertyChangedEventHandler PropertyChanged;

    // 触发变更通知
    protected void OnPropertyChanged([CallerMemberName] string propertyName = null)
    {
        PropertyChanged?.Invoke(this, new PropertyChangedEventArgs(propertyName));
    }

    // 简化属性赋值：值变化自动触发通知
    protected bool SetProperty<T>(ref T field, T value, [CallerMemberName] string propertyName = null)
    {
        if (EqualityComparer<T>.Default.Equals(field, value))
            return false;
        
        field = value;
        OnPropertyChanged(propertyName);
        return true;
    }
}
```

## 实例 1：基础单向绑定（文本显示）

### 场景

展示设备温度、设备名称这类**只读数据**，后台修改数据，UI 自动刷新。

### 视图模型

csharp:

```c#
public class MainViewModel : ViewModelBase
{
    private double _temperature = 26.8;
    /// <summary> 设备温度 </summary>
    public double Temperature
    {
        get => _temperature;
        set => SetProperty(ref _temperature, value);
    }

    private string _deviceName = "激光焊接工位";
    /// <summary> 设备名称 </summary>
    public string DeviceName
    {
        get => _deviceName;
        set => SetProperty(ref _deviceName, value);
    }

    // 模拟温度上升
    public void AddTemperature()
    {
        Temperature += 0.5;
    }
}
```

### 窗口后台（设置 DataContext）

csharp:

```c#
public partial class MainWindow : Window
{
    public MainViewModel Vm { get; } = new MainViewModel();

    public MainWindow()
    {
        InitializeComponent();
        // 关键：给窗口设置数据上下文，所有子控件自动继承
        this.DataContext = Vm;
    }

    private void BtnAddTemp_Click(object sender, RoutedEventArgs e)
    {
        Vm.AddTemperature();
    }
}
```

### XAML 绑定

xaml:

```xaml
<StackPanel Margin="30" Spacing="15">
    <!-- 绑定设备名称 -->
    <TextBlock FontSize="18" FontWeight="Bold" Text="{Binding DeviceName}"/>

    <!-- 绑定温度，StringFormat 格式化加单位 -->
    <TextBlock FontSize="16" Text="{Binding Temperature, StringFormat=当前温度：{0:F1} ℃}"/>

    <Button Content="温度 +0.5" Click="BtnAddTemp_Click" Width="120" Height="30"/>
</StackPanel>
```

### 效果

点击按钮，温度数值自动增加，界面实时刷新，全程不需要手动给 TextBlock 赋值。

## 实例 2：双向绑定（输入同步）

### 场景

参数配置、阈值设置等**用户可编辑**的场景，输入框修改内容，数据源自动更新；数据源变化，输入框也同步刷新。

### 视图模型新增属性

csharp:

```c#
private double _detectThreshold = 0.75;
/// <summary> 检测阈值 </summary>
public double DetectThreshold
{
    get => _detectThreshold;
    set => SetProperty(ref _detectThreshold, value);
}
```

### XAML 绑定

xaml:

```xaml
<StackPanel Margin="30" Spacing="15">
    <!-- 输入框：双向绑定，输入实时回写数据源 -->
    <StackPanel Orientation="Horizontal">
        <TextBlock VerticalAlignment="Center" Width="100">检测阈值：</TextBlock>
        <TextBox Width="200" 
                 Text="{Binding DetectThreshold, Mode=TwoWay, UpdateSourceTrigger=PropertyChanged}"/>
    </StackPanel>

    <!-- 同步显示当前值，验证双向绑定效果 -->
    <TextBlock Text="{Binding DetectThreshold, StringFormat=当前阈值：{0:F2}}"/>
</StackPanel>
```

### 效果

在输入框中修改数值，下方文本会实时同步变化；后台修改 `DetectThreshold`，输入框也会自动更新。

- `Mode=TwoWay`：开启双向同步
- `UpdateSourceTrigger=PropertyChanged`：输入内容一变就回写，不需要等输入框失焦

## 实例 3：控件间联动（ElementName）

### 场景

不需要 ViewModel，直接让两个控件互相联动，比如滑块控制图形大小、透明度。

### XAML 代码（无需后台逻辑）

xaml:

```xaml
<StackPanel Margin="30" Spacing="20">
    <!-- 滑块控件，命名为 opacitySlider -->
    <Slider x:Name="opacitySlider" Minimum="0" Maximum="1" Value="0.6" Width="300"/>

    <!-- 多边形透明度绑定滑块的值 -->
    <Polygon Points="150,20 20,180 280,180"
             Stroke="DarkCyan"
             StrokeThickness="2"
             Fill="#3300FFFF"
             Opacity="{Binding Value, ElementName=opacitySlider}"/>
</StackPanel>
```

### 效果

拖动滑块，三角形的透明度会实时变化，全程不需要写后台代码，纯 XAML 实现控件联动。

## 实例 4：列表集合绑定（批量生成 UI）

### 场景

批量展示缺陷记录、设备列表等，用集合数据自动生成一组 UI 元素，是数据绑定最常用的场景之一。

### 视图模型新增集合

csharp:

```c#
using System.Collections.ObjectModel;

public class MainViewModel : ViewModelBase
{
    /// <summary> 缺陷记录集合 </summary>
    public ObservableCollection<string> DefectList { get; set; } 
        = new ObservableCollection<string>();

    // 新增一条缺陷记录
    public void AddDefect()
    {
        DefectList.Add($"缺陷记录 {DateTime.Now:HH:mm:ss}");
    }
}
```

### XAML 列表绑定

xaml:

```xaml
<StackPanel Margin="30" Spacing="10">
    <!-- 列表控件，ItemsSource 绑定集合 -->
    <ItemsControl ItemsSource="{Binding DefectList}" Height="200" BorderBrush="#DDD" BorderThickness="1">
        <!-- 数据模板：定义每一条记录的外观 -->
        <ItemsControl.ItemTemplate>
            <DataTemplate>
                <Border Padding="8" Margin="2" Background="#F5F5F5" CornerRadius="3">
                    <TextBlock Text="{Binding}"/>
                </Border>
            </DataTemplate>
        </ItemsControl.ItemTemplate>
    </ItemsControl>

    <Button Content="新增缺陷记录" Click="BtnAddDefect_Click" Width="120" Height="30"/>
</StackPanel>
```

### 后台按钮事件

csharp:

```c#
private void BtnAddDefect_Click(object sender, RoutedEventArgs e)
{
    Vm.AddDefect();
}
```

### 效果

点击按钮，集合新增一条数据，界面自动多出一行记录，完全不需要手动操作控件集合。

> 关键：必须用 `ObservableCollection<T>`，普通 `List<T>` 新增元素界面不会自动刷新。

## 实例 5：值转换器（类型转换）

### 场景

数据源类型和 UI 属性类型不匹配时使用，最典型的：布尔状态 → 颜色、枚举 → 可见性。

### 示例：运行状态（bool）转指示灯颜色（Brush）

#### 第一步：实现转换器

csharp:

```c#
using System.Globalization;
using System.Windows.Data;
using System.Windows.Media;

/// <summary> 布尔值转颜色转换器：true=绿色运行，false=红色停机 </summary>
public class BoolToColorConverter : IValueConverter
{
    // 正向转换：数据源 → UI
    public object Convert(object value, Type targetType, object parameter, CultureInfo culture)
    {
        if (value is bool isRunning && isRunning)
            return Brushes.LimeGreen; // 运行中：绿色
        return Brushes.Red; // 停机：红色
    }

    // 反向转换：UI → 数据源，单向绑定不需要实现
    public object ConvertBack(object value, Type targetType, object parameter, CultureInfo culture)
        => throw new NotImplementedException();
}
```

#### 第二步：XAML 中声明为资源

xaml:

```xaml
<Window.Resources>
    <!-- 引入本地命名空间的转换器 -->
    <local:BoolToColorConverter x:Key="BoolToColorConverter"/>
</Window.Resources>
```

#### 第三步：绑定中使用

xaml:

```xaml
<StackPanel Margin="30" Spacing="15">
    <!-- 状态指示灯：填充色绑定运行状态 -->
    <Ellipse Width="60" Height="60" 
             Fill="{Binding IsRunning, Converter={StaticResource BoolToColorConverter}}"/>

    <!-- 切换状态开关 -->
    <ToggleButton Content="切换运行状态" 
                  IsChecked="{Binding IsRunning, Mode=TwoWay}"
                  Width="120" Height="30"/>
</StackPanel>
```

#### 视图模型新增属性

csharp:

```c#
private bool _isRunning = true;
public bool IsRunning
{
    get => _isRunning;
    set => SetProperty(ref _isRunning, value);
}
```

### 效果

切换开关，圆形指示灯会在绿色 / 红色之间自动切换，实现了布尔值到颜色的自动转换。

## 实例 6：图形控件绑定（工业 ROI 场景）

### 场景

数据驱动图形形状，比如视觉检测的 ROI 区域，算法修改顶点坐标，界面图形自动更新。

### 视图模型新增图形属性

csharp:

```c#
using System.Windows.Media;
using System.Windows.Shapes;

public class MainViewModel : ViewModelBase
{
    private PointCollection _roiPoints;
    /// <summary> 检测区域顶点集合 </summary>
    public PointCollection RoiPoints
    {
        get => _roiPoints;
        set => SetProperty(ref _roiPoints, value);
    }

    public MainViewModel()
    {
        // 初始化四边形 ROI
        RoiPoints = new PointCollection
        {
            new Point(80, 80),
            new Point(220, 80),
            new Point(250, 180),
            new Point(50, 180)
        };
    }

    // 模拟算法更新 ROI 形状
    public void UpdateRoiShape()
    {
        RoiPoints = new PointCollection
        {
            new Point(100, 60),
            new Point(240, 70),
            new Point(230, 200),
            new Point(70, 190)
        };
    }
}
```

### XAML 绑定多边形

xaml:

```xaml
<StackPanel Margin="30" Spacing="15">
    <Canvas Width="300" Height="250" Background="#1E1E1E">
        <!-- 多边形形状完全由数据驱动 -->
        <Polygon Points="{Binding RoiPoints}"
                 Stroke="Cyan"
                 StrokeThickness="2"
                 Fill="#2200FFFF"
                 StrokeLineJoin="Round"/>
    </Canvas>

    <Button Content="更新ROI形状" Click="BtnUpdateRoi_Click" Width="120" Height="30"/>
</StackPanel>
```

### 后台按钮事件

csharp:

```c#
private void BtnUpdateRoi_Click(object sender, RoutedEventArgs e)
{
    Vm.UpdateRoiShape();
}
```

### 效果

点击按钮，检测区域的形状会自动变形，全程不需要操作 Polygon 控件，纯数据驱动。

## 场景选型总结

| 场景                       | 绑定方式     | 核心关键字                             |
| :------------------------- | :----------- | :------------------------------------- |
| 只读数据展示               | 单向绑定     | `{Binding 属性名}`                     |
| 用户输入、参数配置         | 双向绑定     | `Mode=TwoWay`                          |
| 两个控件直接联动           | 控件名绑定   | `ElementName=xxx`                      |
| 批量列表、重复元素         | 集合绑定     | `ItemsSource` + `ObservableCollection` |
| 类型不匹配（状态转颜色等） | 值转换器     | `Converter` + `IValueConverter`        |
| 图形、ROI 形状控制         | 图形属性绑定 | 直接绑定 `Points`/`Data` 等依赖属性    |
