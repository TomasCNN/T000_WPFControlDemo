# 003009001_Canvas控件（绝对布局）的类定义，使用方法，使用注意点及具体的使用案例

Canvas 是 WPF 中最基础的**绝对定位布局面板**，核心特点是：**子元素通过坐标（Left/Top/Right/Bottom）精确固定位置，不随窗口缩放自动调整**。

------

## 一、Canvas 类定义详细解析

### 1. 继承关系

csharp：

```c#
public class Canvas : Panel
```

- 继承自 `Panel` 基类，拥有 `Children` 子元素集合、布局测量 / 排列核心逻辑。

### 2. 核心依赖属性

| 属性名         | 类型                  | 说明                                           |
| :------------- | :-------------------- | :--------------------------------------------- |
| `Background`   | `Brush`               | 背景画刷（默认透明）                           |
| `Children`     | `UIElementCollection` | 子元素集合（继承自 Panel）                     |
| `ClipToBounds` | `bool`                | 是否裁剪超出 Canvas 边界的子元素（默认 false） |

### 3. 核心附加属性（Canvas 灵魂）

附加属性是 WPF 特有的机制，允许子元素 “借用” 父容器的属性来定位。

| 附加属性名      | 类型     | 说明                                                  |
| :-------------- | :------- | :---------------------------------------------------- |
| `Canvas.Left`   | `double` | 子元素左边缘到 Canvas 左边缘的距离                    |
| `Canvas.Top`    | `double` | 子元素上边缘到 Canvas 上边缘的距离                    |
| `Canvas.Right`  | `double` | 子元素右边缘到 Canvas 右边缘的距离（优先级低于 Left） |
| `Canvas.Bottom` | `double` | 子元素下边缘到 Canvas 下边缘的距离（优先级低于 Top）  |
| `Canvas.ZIndex` | `int`    | 子元素层级（数值越大越靠上，默认 0）                  |

------

## 二、Canvas 使用方法

### 1. XAML 中使用（最常用）

通过附加属性直接定位子元素：

xaml:

```xaml
<Canvas Width="400" Height="300" Background="LightGray">
    <!-- 矩形：距离左50、上50 -->
    <Rectangle Canvas.Left="50" Canvas.Top="50" Width="100" Height="80" Fill="Blue"/>
    
    <!-- 圆形：距离左200、上100，层级更高（ZIndex=1） -->
    <Ellipse Canvas.Left="200" Canvas.Top="100" Width="80" Height="80" Fill="Red" Canvas.ZIndex="1"/>
    
    <!-- 文本：距离右50、下50 -->
    <TextBlock Canvas.Right="50" Canvas.Bottom="50" Text="Hello Canvas" FontSize="16"/>
</Canvas>
```

### 2. 后台代码中使用

通过 `Canvas.SetLeft()` / `Canvas.GetLeft()` 等静态方法操作附加属性：

csharp:

```c#
// 创建 Canvas
Canvas canvas = new Canvas { Width = 400, Height = 300, Background = Brushes.LightGray };

// 创建矩形
Rectangle rect = new Rectangle { Width = 100, Height = 80, Fill = Brushes.Blue };
// 设置附加属性：Left=50, Top=50
Canvas.SetLeft(rect, 50);
Canvas.SetTop(rect, 50);
// 设置层级
Canvas.SetZIndex(rect, 1);

// 添加到 Canvas
canvas.Children.Add(rect);
```

### 3. 层级控制（ZIndex）

xaml:

```xaml
<Canvas>
    <!-- 底层（默认 ZIndex=0） -->
    <Rectangle Canvas.Left="50" Canvas.Top="50" Width="100" Height="100" Fill="Blue"/>
    <!-- 中层（ZIndex=1） -->
    <Ellipse Canvas.Left="80" Canvas.Top="80" Width="100" Height="100" Fill="Red" Canvas.ZIndex="1"/>
    <!-- 顶层（ZIndex=2） -->
    <TextBlock Canvas.Left="110" Canvas.Top="110" Text="Top" FontSize="20" Canvas.ZIndex="2"/>
</Canvas>
```

## 三、Canvas 使用注意点

### 1. 绝对定位，不随窗口缩放自动调整

Canvas 子元素位置固定，窗口变大 / 变小时不会自动居中或调整，适合**固定尺寸界面**（如工业设备操作面板、绘图工具），不适合响应式布局。

### 2. 性能注意事项

- Canvas 本身不做复杂布局计算，性能很高，但**子元素数量过多（>1000）时仍会卡顿**。
- 大量动态元素建议结合 `VirtualizingStackPanel` 或使用 `WriteableBitmap` 直接绘图。

### 3. 子元素重叠处理

默认按添加顺序重叠（后添加的在上），需通过 `Canvas.ZIndex` 显式控制层级。

### 4. 尺寸处理

- Canvas 本身默认尺寸为 `0x0`，需显式设置 `Width` / `Height` 或通过父容器约束。
- 子元素超出 Canvas 边界时，默认不裁剪（`ClipToBounds=false`），可设为 `true` 裁剪。

### 5. 不适合复杂布局

Canvas 仅做绝对定位，没有对齐、均分、换行等功能，复杂布局建议用 `Grid` 或 `StackPanel`。

## 四、具体使用案例：工业设备操作面板

### 需求

做一个固定尺寸的工业设备操作面板，包含：

1. 背景图
2. 启动 / 停止按钮（固定位置）
3. 状态指示灯（固定位置）
4. 实时数据显示（固定位置）

### 完整代码

xaml:

```xaml
<Window x:Class="CanvasIndustrialPanelDemo.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        Title="工业设备操作面板" Width="800" Height="600" ResizeMode="NoResize">
    <Grid>
        <!-- Canvas：固定尺寸，不随窗口缩放 -->
        <Canvas Width="800" Height="600" Background="#F0F0F0">
            <!-- 1. 背景图 -->
            <Image Canvas.Left="0" Canvas.Top="0" Width="800" Height="600" Source="bg_panel.png" Stretch="Fill"/>
            
            <!-- 2. 状态指示灯（红色=停止，绿色=运行） -->
            <Ellipse x:Name="ellipseStatus" Canvas.Left="50" Canvas.Top="50" Width="60" Height="60" Fill="Red"/>
            <TextBlock Canvas.Left="120" Canvas.Top="65" Text="设备状态" FontSize="18" FontWeight="Bold"/>
            
            <!-- 3. 实时数据显示 -->
            <TextBlock Canvas.Left="50" Canvas.Top="150" Text="当前温度：" FontSize="16"/>
            <TextBlock x:Name="txtTemperature" Canvas.Left="160" Canvas.Top="150" Text="25.5℃" FontSize="16" Foreground="Blue"/>
            
            <TextBlock Canvas.Left="50" Canvas.Top="200" Text="当前转速：" FontSize="16"/>
            <TextBlock x:Name="txtSpeed" Canvas.Left="160" Canvas.Top="200" Text="1500 rpm" FontSize="16" Foreground="Blue"/>
            
            <!-- 4. 操作按钮 -->
            <Button x:Name="btnStart" Canvas.Left="50" Canvas.Top="500" Width="120" Height="50" Content="启动" FontSize="18" Background="Green" Foreground="White" Click="BtnStart_Click"/>
            <Button x:Name="btnStop" Canvas.Left="200" Canvas.Top="500" Width="120" Height="50" Content="停止" FontSize="18" Background="Red" Foreground="White" Click="BtnStop_Click"/>
            <Button x:Name="btnReset" Canvas.Left="350" Canvas.Top="500" Width="120" Height="50" Content="复位" FontSize="18" Background="Gray" Foreground="White" Click="BtnReset_Click"/>
        </Canvas>
    </Grid>
</Window>
```

csharp:

```c#
using System.Windows;
using System.Windows.Media;
using System.Windows.Threading;

namespace CanvasIndustrialPanelDemo
{
    public partial class MainWindow : Window
    {
        private DispatcherTimer _timer;
        private Random _random = new Random();

        public MainWindow()
        {
            InitializeComponent();
            InitTimer();
        }

        // 初始化定时器：模拟实时数据更新
        private void InitTimer()
        {
            _timer = new DispatcherTimer();
            _timer.Interval = TimeSpan.FromSeconds(1);
            _timer.Tick += Timer_Tick;
            _timer.Start();
        }

        // 定时器回调：更新温度、转速
        private void Timer_Tick(object sender, EventArgs e)
        {
            double temperature = 25 + _random.NextDouble() * 10;
            int speed = 1500 + _random.Next(-100, 100);
            
            txtTemperature.Text = $"{temperature:F1}℃";
            txtSpeed.Text = $"{speed} rpm";
        }

        // 启动按钮点击
        private void BtnStart_Click(object sender, RoutedEventArgs e)
        {
            ellipseStatus.Fill = Brushes.Green;
            MessageBox.Show("设备已启动");
        }

        // 停止按钮点击
        private void BtnStop_Click(object sender, RoutedEventArgs e)
        {
            ellipseStatus.Fill = Brushes.Red;
            MessageBox.Show("设备已停止");
        }

        // 复位按钮点击
        private void BtnReset_Click(object sender, RoutedEventArgs e)
        {
            txtTemperature.Text = "25.0℃";
            txtSpeed.Text = "1500 rpm";
            MessageBox.Show("设备已复位");
        }
    }
}
```

------

## 五、案例说明

1. **固定尺寸**：Canvas 设为 `800x600`，窗口 `ResizeMode="NoResize"`，符合工业设备操作面板场景。
2. **绝对定位**：所有控件通过 `Canvas.Left` / `Canvas.Top` 固定位置，布局稳定。
3. **层级控制**：背景图在最底层（默认 ZIndex=0），按钮在最上层（后添加）。
4. **实时更新**：通过定时器模拟数据更新，不影响 Canvas 布局。

------

## 六、总结

Canvas 是 WPF 中最简单、最灵活的绝对布局面板，适合**固定尺寸、需要精确控制位置**的场景（如工业面板、绘图工具、游戏界面），但不适合响应式布局。使用时需注意：

1. 显式设置 Canvas 尺寸。
2. 通过 `Canvas.ZIndex` 控制层级。
3. 大量元素时注意性能优化。
