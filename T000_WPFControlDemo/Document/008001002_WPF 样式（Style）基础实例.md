# 008001002_WPF 样式（Style）基础实例

以下是一套可直接运行的 WPF 样式基础实例代码，覆盖**静态属性复用、交互触发器、隐式全局样式、数据触发器、样式继承、列表容器样式**6 个最核心的基础场景，贴合工业上位机常用控件。

------

## 一、后台 C# 代码

先创建两个基础类，用于支撑数据绑定和数据触发器演示。

### 1. 属性通知基类 `ViewModelBase.cs`

csharp:

```c#
using System.Collections.Generic;
using System.ComponentModel;
using System.Runtime.CompilerServices;

public abstract class ViewModelBase : INotifyPropertyChanged
{
    public event PropertyChangedEventHandler PropertyChanged;

    protected void OnPropertyChanged([CallerMemberName] string propertyName = null)
    {
        PropertyChanged?.Invoke(this, new PropertyChangedEventArgs(propertyName));
    }

    protected bool SetProperty<T>(ref T field, T value, [CallerMemberName] string propertyName = null)
    {
        if (EqualityComparer<T>.Default.Equals(field, value))
            return false;

        field = value;
        OnPropertyChanged(propertyName);
        return true;
    }
}
```

### 2. 主视图模型 `MainViewModel.cs`

csharp:

```c#
using System.Collections.ObjectModel;

public class MainViewModel : ViewModelBase
{
    private bool _isRunning = true;
    /// <summary> 设备运行状态 </summary>
    public bool IsRunning
    {
        get => _isRunning;
        set => SetProperty(ref _isRunning, value);
    }

    private bool _isAlarming;
    /// <summary> 设备告警状态 </summary>
    public bool IsAlarming
    {
        get => _isAlarming;
        set => SetProperty(ref _isAlarming, value);
    }

    /// <summary> 缺陷列表数据 </summary>
    public ObservableCollection<string> DefectList { get; set; } = new ObservableCollection<string>
    {
        "缺陷记录_001",
        "缺陷记录_002",
        "缺陷记录_003"
    };
}
```

### 3. 窗口后台 `MainWindow.xaml.cs`

csharp:

```c#
public partial class MainWindow : Window
{
    public MainViewModel Vm { get; } = new MainViewModel();

    public MainWindow()
    {
        InitializeComponent();
        this.DataContext = Vm;
    }
}
```

## 二、XAML 样式与界面代码

以下是 `MainWindow.xaml` 完整代码，所有样式定义在 `Window.Resources` 资源区，界面直接引用样式即可。

> 注意：将 `x:Class` 中的命名空间替换为你自己项目的命名空间。

xaml:

```xaml
<Window x:Class="WpfStyleDemo.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        Title="WPF样式基础实例" Height="600" Width="550">

    <!-- ===================== 样式资源区 ===================== -->
    <Window.Resources>

        <!-- 实例1：基础按钮基样式（静态属性复用）
             核心：用Setter批量统一定义公共属性，减少重复代码 -->
        <Style x:Key="BaseButtonStyle" TargetType="Button">
            <Setter Property="Width" Value="120"/>
            <Setter Property="Height" Value="32"/>
            <Setter Property="FontSize" Value="14"/>
            <Setter Property="BorderThickness" Value="0"/>
            <Setter Property="Cursor" Value="Hand"/>
            <Setter Property="Margin" Value="0 0 10 0"/>
        </Style>

        <!-- 实例2：主按钮样式（属性触发器 + 样式继承）
             核心：Trigger监听控件自身状态，实现悬停/按下/禁用交互效果 -->
        <Style x:Key="PrimaryButtonStyle" TargetType="Button" 
               BasedOn="{StaticResource BaseButtonStyle}">
            <Setter Property="Background" Value="#2E7DFF"/>
            <Setter Property="Foreground" Value="White"/>
            <Style.Triggers>
                <!-- 鼠标悬停状态 -->
                <Trigger Property="IsMouseOver" Value="True">
                    <Setter Property="Background" Value="#5597FF"/>
                </Trigger>
                <!-- 鼠标按下状态 -->
                <Trigger Property="IsPressed" Value="True">
                    <Setter Property="Background" Value="#1A66E0"/>
                </Trigger>
                <!-- 控件禁用状态 -->
                <Trigger Property="IsEnabled" Value="False">
                    <Setter Property="Background" Value="#CCCCCC"/>
                    <Setter Property="Foreground" Value="#999999"/>
                </Trigger>
            </Style.Triggers>
        </Style>

        <!-- 实例3：危险按钮样式（样式继承扩展）
             核心：BasedOn继承基础样式，只修改差异化的颜色属性 -->
        <Style x:Key="DangerButtonStyle" TargetType="Button" 
               BasedOn="{StaticResource BaseButtonStyle}">
            <Setter Property="Background" Value="#F53F3F"/>
            <Setter Property="Foreground" Value="White"/>
            <Style.Triggers>
                <Trigger Property="IsMouseOver" Value="True">
                    <Setter Property="Background" Value="#FF6B6B"/>
                </Trigger>
            </Style.Triggers>
        </Style>

        <!-- 实例4：全局文本框隐式样式
             核心：无x:Key，自动应用到当前窗口所有TextBox，全局统一样式 -->
        <Style TargetType="TextBox">
            <Setter Property="Width" Value="250"/>
            <Setter Property="Height" Value="28"/>
            <Setter Property="Padding" Value="6 4"/>
            <Setter Property="FontSize" Value="14"/>
            <Setter Property="BorderBrush" Value="#CCCCCC"/>
            <Setter Property="BorderThickness" Value="1"/>
            <Setter Property="VerticalContentAlignment" Value="Center"/>
            <Style.Triggers>
                <!-- 获得焦点时边框变色 -->
                <Trigger Property="IsFocused" Value="True">
                    <Setter Property="BorderBrush" Value="#2E7DFF"/>
                </Trigger>
            </Style.Triggers>
        </Style>

        <!-- 实例5：状态指示灯样式（数据触发器）
             核心：DataTrigger绑定业务数据，数据变化自动更新UI，符合MVVM架构 -->
        <Style x:Key="StatusLightStyle" TargetType="Ellipse">
            <Setter Property="Width" Value="20"/>
            <Setter Property="Height" Value="20"/>
            <Setter Property="Fill" Value="Gray"/> <!-- 默认：离线灰色 -->
            <Style.Triggers>
                <!-- 运行中显示绿色 -->
                <DataTrigger Binding="{Binding IsRunning}" Value="True">
                    <Setter Property="Fill" Value="LimeGreen"/>
                </DataTrigger>
                <!-- 告警显示橙色（写在后面，优先级更高） -->
                <DataTrigger Binding="{Binding IsAlarming}" Value="True">
                    <Setter Property="Fill" Value="Orange"/>
                </DataTrigger>
            </Style.Triggers>
        </Style>

        <!-- 实例6：列表项容器样式
             核心：自定义列表行的选中、悬停效果，替代系统默认深蓝色高亮 -->
        <Style x:Key="DefectListItemStyle" TargetType="ListBoxItem">
            <Setter Property="Padding" Value="8 6"/>
            <Setter Property="Foreground" Value="#333333"/>
            <Setter Property="Background" Value="Transparent"/>
            <Style.Triggers>
                <!-- 鼠标悬停效果 -->
                <Trigger Property="IsMouseOver" Value="True">
                    <Setter Property="Background" Value="#F0F7FF"/>
                </Trigger>
                <!-- 选中高亮效果 -->
                <Trigger Property="IsSelected" Value="True">
                    <Setter Property="Background" Value="#E6F0FF"/>
                    <Setter Property="Foreground" Value="#2E7DFF"/>
                    <Setter Property="FontWeight" Value="Bold"/>
                </Trigger>
            </Style.Triggers>
        </Style>

    </Window.Resources>

    <!-- ===================== 界面演示区 ===================== -->
    <StackPanel Margin="30" Spacing="20">

        <!-- 1. 按钮样式演示 -->
        <GroupBox Header="1. 按钮样式（静态属性 + 交互触发器）">
            <StackPanel Orientation="Horizontal" Margin="10" Spacing="10">
                <Button Content="主按钮" Style="{StaticResource PrimaryButtonStyle}"/>
                <Button Content="危险按钮" Style="{StaticResource DangerButtonStyle}"/>
                <Button Content="禁用按钮" Style="{StaticResource PrimaryButtonStyle}" IsEnabled="False"/>
            </StackPanel>
        </GroupBox>

        <!-- 2. 文本框隐式样式演示 -->
        <GroupBox Header="2. 全局文本框样式（隐式自动应用，无需逐个引用）">
            <StackPanel Margin="10" Spacing="10">
                <TextBox Text="设备参数输入框1"/>
                <TextBox Text="设备参数输入框2"/>
            </StackPanel>
        </GroupBox>

        <!-- 3. 状态指示灯数据触发器演示 -->
        <GroupBox Header="3. 状态指示灯（数据触发器，数据驱动UI）">
            <StackPanel Orientation="Horizontal" Margin="10" Spacing="10">
                <Ellipse Style="{StaticResource StatusLightStyle}"/>
                <TextBlock Text="设备运行状态" VerticalAlignment="Center"/>
                <CheckBox Content="切换运行" IsChecked="{Binding IsRunning, Mode=TwoWay}" Margin="20 0 0 0" VerticalAlignment="Center"/>
                <CheckBox Content="切换告警" IsChecked="{Binding IsAlarming, Mode=TwoWay}" VerticalAlignment="Center"/>
            </StackPanel>
        </GroupBox>

        <!-- 4. 列表项样式演示 -->
        <GroupBox Header="4. 列表项样式（自定义选中/悬停效果）">
            <ListBox Width="300" Height="120" Margin="10"
                     ItemsSource="{Binding DefectList}"
                     ItemContainerStyle="{StaticResource DefectListItemStyle}"/>
        </GroupBox>

    </StackPanel>
</Window>
```

## 三、各实例核心知识点总结

| 实例         | 核心用法                        | 应用场景                               |
| :----------- | :------------------------------ | :------------------------------------- |
| 基础静态样式 | `Setter` 批量设置属性           | 统一控件基础外观，减少重复代码         |
| 属性触发器   | `Trigger` 监听控件自身依赖属性  | 鼠标悬停、按下、禁用等交互反馈         |
| 样式继承     | `BasedOn` 派生扩展样式          | 基础样式复用，多套差异化主题           |
| 隐式样式     | 无 `x:Key`，自动匹配类型        | 全局统一样式规范，无需逐个引用         |
| 数据触发器   | `DataTrigger` 绑定业务数据      | MVVM 架构下，业务状态驱动 UI 变化      |
| 列表容器样式 | `ItemContainerStyle` 定制行样式 | 自定义列表选中、悬停效果，统一交互风格 |
