### 3.1 继承自 RangeBase 的核心属性

`Slider`继承了`RangeBase`的所有核心值属性，这些属性的行为完全由`RangeBase`实现：

| :------------ | :--------- | :----------- | :------------------------------------------------------ |

| `Maximum`     | `1.0`      | 范围最大值   | 根据工艺参数设置，如温度 200℃                           |
| `Value`       | `0.0`      | 当前值       | 永远在 [Minimum, Maximum] 范围内，由 RangeBase 自动强制 |

### 3.2 Slider 自身定义的属性

#### 1. 基础布局属性

csharp:

```c#
public Orientation Orientation { get; set; }
public bool IsDirectionReversed { get; set; }
```

- **`Orientation`**：控制滑块方向
  - 默认值：`Orientation.Horizontal`（水平）
  - 枚举值：`Horizontal`/`Vertical`
  - 工业应用：常规参数用水平，速度 / 液位用垂直（更符合直觉）
- **`IsDirectionReversed`**：反转值增加的方向
  - 默认值：`false`
    - 水平滑块：向右拖动→值增加
    - 垂直滑块：向下拖动→值增加
  - 设为`true`时：
    - 水平滑块：向左拖动→值增加
    - 垂直滑块：向上拖动→值增加
  - 工业应用：液位调节、高度调节通常需要设为`true`

#### 2. 刻度相关属性（工业参数调节核心）

csharp:

```c#
public TickPlacement TickPlacement { get; set; }
public double TickFrequency { get; set; }
public DoubleCollection Ticks { get; set; }
public bool IsSnapToTickEnabled { get; set; }
```

- **`TickPlacement`**：控制刻度的显示位置

  - 默认值：`TickPlacement.None`（不显示刻度）

  - 枚举值：

    | 枚举值        | 显示位置                    | 适用场景     |
    | :------------ | :-------------------------- | :----------- |
    | `None`        | 不显示                      | 简单调节     |
    | `TopLeft`     | 水平滑块上方 / 垂直滑块左侧 | 标准参数调节 |
    | `BottomRight` | 水平滑块下方 / 垂直滑块右侧 | 标准参数调节 |
    | `Both`        | 两侧都显示                  | 高精度调节   |

- **`TickFrequency`**：自动生成刻度的间隔

  - 默认值：`1.0`
  - 示例：`Minimum=0`、`Maximum=100`、`TickFrequency=10` → 生成 0,10,20,...,100 刻度

- **`Ticks`**：自定义刻度位置

  - 默认值：`null`
  - 优先级：高于`TickFrequency`，如果设置了`Ticks`则忽略`TickFrequency`
  - 工业应用：非均匀刻度，如温度关键节点`0,25,50,75,100,150,200`

- **`IsSnapToTickEnabled`**：拖动时自动对齐到最近的刻度

  - 默认值：`false`
  - ⚠️ **工业红线**：所有工艺参数调节必须开启此属性，确保参数只能取允许的刻度值，避免无效参数

#### 3. 自动提示属性

csharp:

```c#

public int AutoToolTipPrecision { get; set; }
```

- **`AutoToolTipPlacement`**：拖动滑块时自动显示当前值的工具提示位置
  - 默认值：`AutoToolTipPlacement.None`（不显示）
  - 枚举值：`None`/`TopLeft`/`BottomRight`
  - 工业推荐：`BottomRight`（水平滑块下方显示）
- **`AutoToolTipPrecision`**：工具提示中数值的小数位数
  - 默认值：`0`（整数）
  - 工业应用：温度保留 1 位，压力保留 2 位，流量保留 3 位

#### 4. 交互属性

csharp:

```c#

public int Delay { get; set; }
public int Interval { get; set; }
```

- **`IsMoveToPointEnabled`**：点击轨道任意位置时，滑块直接跳转到该位置
  - 默认值：`false`（点击轨道时执行`LargeChange`步长调节）
  - 工业应用：快速调节场景开启，如音量、亮度调节
- **`Delay`**：按住箭头按钮时的重复触发延迟
  - 默认值：`500`（毫秒）
  - 工业优化：精细调节时增大到 1000ms，避免值变化过快
- **`Interval`**：按住箭头按钮时的重复触发间隔
  - 默认值：`33`（毫秒，约 30 次 / 秒）
  - 工业优化：精细调节时增大到 100ms

#### 5. 范围选择属性

public double SelectionEnd { get; set; }

- **`IsSelectionRangeEnabled`**：启用范围选择模式
  - 默认值：`false`
  - 启用后，轨道上会显示一个蓝色的选中范围
- **`SelectionStart`** / **`SelectionEnd`**：选择范围的起始和结束值
  - 默认值：`0.0` / `1.0`
  - 工业应用：温度上下限、压力范围、时间区间设置

## 四、核心方法逐行解析

### 4.1 公共方法

#### `OnApplyTemplate()`

csharp:

```c#
public override void OnApplyTemplate();
```

- **官方完整实现逻辑**：
  1. 调用基类`OnApplyTemplate()`
  2. 查找模板中的`PART_Track`部件
  3. 将`Slider`的所有属性双向绑定到`Track`的对应属性：
     - `Track.Minimum` ↔ `Slider.Minimum`
     - `Track.Maximum` ↔ `Slider.Maximum`
     - `Track.Value` ↔ `Slider.Value`
     - `Track.ViewportSize` ↔ 固定值 0（Slider 不需要视口概念）
     - `Track.Orientation` ↔ `Slider.Orientation`
     - `Track.IsDirectionReversed` ↔ `Slider.IsDirectionReversed`
  4. 订阅`Track.Thumb`的三个拖动事件：
     - `Thumb.DragStarted` → 调用`OnThumbDragStarted()`
     - `Thumb.DragDelta` → 调用`OnThumbDragDelta()`
     - `Thumb.DragCompleted` → 调用`OnThumbDragCompleted()`

## 六、官方内部工作原理

### 6.1 完整交互流程

从用户拖动滑块到值更新的完整官方流程：

plaintext:

```tex
用户按下鼠标左键拖动滑块
    ↓
Thumb.OnMouseLeftButtonDown()
    ↓
Thumb捕获鼠标，设置IsDragging=true
    ↓
触发Thumb.DragStarted事件
    ↓
Slider.OnThumbDragStarted()
    ↓
鼠标移动
    ↓
Thumb.OnMouseMove()
    ↓
计算拖动偏移量，触发Thumb.DragDelta事件
    ↓
Track接收DragDelta事件，计算新的Value
    ↓
Track.Value更新 → 绑定到Slider.Value
    ↓
Slider.Value更新（RangeBase自动强制到合法范围）
    ↓
触发Slider.ValueChanged事件
    ↓
Slider.OnValueChanged()
    ↓
用户释放鼠标左键
    ↓
Thumb.OnMouseLeftButtonUp()
    ↓
Thumb释放鼠标捕获，设置IsDragging=false
    ↓
触发Thumb.DragCompleted事件
    ↓
Slider.OnThumbDragCompleted()
    ↓
交互结束
```

## 七、官方设计思想总结

微软设计`Slider`的核心思想可以概括为三点：

1. **继承复用**：完全复用`RangeBase`的范围值管理逻辑，与`ScrollBar`保持行为一致性
2. **命令驱动**：所有交互通过路由命令实现，实现 UI 与逻辑的完全解耦
3. **分层设计**：
   - 底层：`Thumb`处理拖动操作
   - 中层：`Track`管理轨道和滑块布局
   - 上层：`Slider`提供参数调节的专用 API 和功能

这种设计使得`Slider`具有极高的可扩展性，开发者可以通过重写虚方法、替换模板来实现任何自定义的参数调节需求，同时保持与 WPF 标准控件的行为一致性。

## 八、工业开发核心启示

1. **永远开启`IsSnapToTickEnabled`**：这是工业参数调节的基本要求，确保参数只能取允许的刻度值
2. **合理使用命令系统**：优先使用标准路由命令，不要手动处理鼠标事件
3. **区分实时更新和最终保存**：拖动过程中实时更新设备参数，拖动结束后再保存到数据库
4. **利用官方扩展点**：通过重写`OnIncreaseSmall`等虚方法实现自定义调节逻辑，不要修改源码
5. **简化模板**：工业界面追求稳定和性能，不要给 Slider 添加复杂的视觉效果和动画:
