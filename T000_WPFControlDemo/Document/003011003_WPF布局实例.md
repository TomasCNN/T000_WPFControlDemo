# 003011003_WPF布局实例

全部**兼容 .NET 4.5+、无 Spacing、纯 XAML、可直接复制运行**，覆盖工业软件 90% 以上的布局场景，拿来就能改造成业务界面。

------

## 一、基础通用布局

### 案例 1：两列表单布局（参数配置专用）

**适用场景**：设备参数配置、系统设置、产品配方编辑

xaml:

```xaml
<Window Width="550" Height="450" Title="参数配置">
    <Grid Margin="20">
        <ScrollViewer VerticalScrollBarVisibility="Auto">
            <StackPanel>
                <TextBlock Text="相机参数配置" FontSize="18" FontWeight="Bold" Margin="0 0 0 20"/>
                
                <!-- 两列网格布局 -->
                <Grid>
                    <Grid.ColumnDefinitions>
                        <ColumnDefinition Width="120"/>
                        <ColumnDefinition Width="*"/>
                    </Grid.ColumnDefinitions>
                    <Grid.RowDefinitions>
                        <RowDefinition Height="40"/>
                        <RowDefinition Height="40"/>
                        <RowDefinition Height="40"/>
                        <RowDefinition Height="40"/>
                        <RowDefinition Height="40"/>
                        <RowDefinition Height="40"/>
                    </Grid.RowDefinitions>

                    <!-- 第一行 -->
                    <TextBlock Grid.Row="0" Grid.Column="0" VerticalAlignment="Center" Text="曝光时间(ms):"/>
                    <TextBox Grid.Row="0" Grid.Column="1" Height="28" Text="100"/>

                    <!-- 第二行 -->
                    <TextBlock Grid.Row="1" Grid.Column="0" VerticalAlignment="Center" Text="增益值:"/>
                    <TextBox Grid.Row="1" Grid.Column="1" Height="28" Text="1.0"/>

                    <!-- 第三行 -->
                    <TextBlock Grid.Row="2" Grid.Column="0" VerticalAlignment="Center" Text="触发模式:"/>
                    <ComboBox Grid.Row="2" Grid.Column="1" Height="28" SelectedIndex="0">
                        <ComboBoxItem>软触发</ComboBoxItem>
                        <ComboBoxItem>硬触发</ComboBoxItem>
                    </ComboBox>

                    <!-- 第四行 -->
                    <TextBlock Grid.Row="3" Grid.Column="0" VerticalAlignment="Center" Text="图像宽度:"/>
                    <TextBox Grid.Row="3" Grid.Column="1" Height="28" Text="1280"/>

                    <!-- 第五行 -->
                    <TextBlock Grid.Row="4" Grid.Column="0" VerticalAlignment="Center" Text="图像高度:"/>
                    <TextBox Grid.Row="4" Grid.Column="1" Height="28" Text="960"/>

                    <!-- 第六行 -->
                    <TextBlock Grid.Row="5" Grid.Column="0" VerticalAlignment="Center" Text="自动曝光:"/>
                    <CheckBox Grid.Row="5" Grid.Column="1" VerticalAlignment="Center" IsChecked="False"/>
                </Grid>

                <!-- 底部按钮 -->
                <StackPanel Orientation="Horizontal" HorizontalAlignment="Right" Margin="0 20 0 0">
                    <Button Content="保存" Width="80" Height="30" Margin="0 0 10 0"/>
                    <Button Content="恢复默认" Width="80" Height="30"/>
                </StackPanel>
            </StackPanel>
        </ScrollViewer>
    </Grid>
</Window>
```

## 二、数据展示布局

### 案例 3：数据表格布局（缺陷记录专用）

**适用场景**：生产记录、缺陷列表、报警历史

xaml:

```xaml
<Window Width="900" Height="500" Title="缺陷记录查询">
    <Grid Margin="10">
        <Grid.RowDefinitions>
            <RowDefinition Height="40"/>
            <RowDefinition Height="*"/>
            <RowDefinition Height="40"/>
        </Grid.RowDefinitions>

        <!-- 顶部查询栏 -->
        <Border Background="#F5F5F5" CornerRadius="4">
            <StackPanel Orientation="Horizontal" VerticalAlignment="Center" Margin="10 0">
                <TextBlock Text="时间范围:" VerticalAlignment="Center" Margin="0 0 5 0"/>
                <DatePicker Width="120" Height="25" Margin="0 0 10 0"/>
                <TextBlock Text="至" VerticalAlignment="Center" Margin="0 0 5 0"/>
                <DatePicker Width="120" Height="25" Margin="0 0 20 0"/>
                
                <TextBlock Text="产品条码:" VerticalAlignment="Center" Margin="0 0 5 0"/>
                <TextBox Width="150" Height="25" Margin="0 0 20 0"/>
                
                <Button Content="查询" Width="60" Height="25" Margin="0 0 10 0"/>
                <Button Content="导出" Width="60" Height="25"/>
            </StackPanel>
        </Border>

        <!-- 中间数据表格 -->
        <DataGrid Grid.Row="1" Margin="0 10 0 0" 
                  AutoGenerateColumns="False" 
                  CanUserAddRows="False" 
                  IsReadOnly="True"
                  GridLinesVisibility="Horizontal">
            <DataGrid.Columns>
                <DataGridTextColumn Header="序号" Width="60" Binding="{Binding Index}"/>
                <DataGridTextColumn Header="检测时间" Width="150" Binding="{Binding Time}"/>
                <DataGridTextColumn Header="产品条码" Width="150" Binding="{Binding Barcode}"/>
                <DataGridTextColumn Header="缺陷类型" Width="100" Binding="{Binding DefectType}"/>
                <DataGridTextColumn Header="缺陷位置" Width="100" Binding="{Binding Position}"/>
                <DataGridTextColumn Header="检测结果" Width="80" Binding="{Binding Result}"/>
                <DataGridTextColumn Header="工位" Width="80" Binding="{Binding Station}"/>
            </DataGrid.Columns>
        </DataGrid>

        <!-- 底部分页栏 -->
        <Border Grid.Row="2" Background="#F5F5F5" CornerRadius="4">
            <DockPanel Margin="10 0">
                <TextBlock DockPanel.Dock="Left" VerticalAlignment="Center" Text="共 1256 条记录"/>
                <StackPanel DockPanel.Dock="Right" Orientation="Horizontal">
                    <Button Content="上一页" Width="60" Height="25" Margin="0 0 5 0"/>
                    <TextBlock Text="1/13" VerticalAlignment="Center" Margin="0 0 5 0"/>
                    <Button Content="下一页" Width="60" Height="25"/>
                </StackPanel>
            </DockPanel>
        </Border>
    </Grid>
</Window>
```

        <TabControl Grid.Row="1" Margin="0 10 0 0">

## 使用说明

1. 所有案例都是完整的 Window 代码，直接新建窗口替换即可运行
2. 全部使用 Margin 控制间距，兼容所有 .NET 版本
3. 工业标准配色，简洁专业，适合设备上位机
4. 可根据实际需求修改颜色、文字、控件大小
