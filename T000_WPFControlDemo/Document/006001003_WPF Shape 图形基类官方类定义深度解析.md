# 006001003_WPF `Shape` 图形基类官方类定义深度解析

`Shape` 是 WPF 二维矢量图形体系的**核心抽象基类**，位于 `System.Windows.Shapes` 命名空间，是所有基础矢量图形（矩形、椭圆、直线、多边形等）的共同父类。它继承自 `FrameworkElement`，天然融入 WPF 布局系统、数据绑定、样式动画、路由事件等全部框架能力，是工业上位机中绘制检测框、运动轨迹、工位示意图、缺陷标记的核心 UI 组件。

------

## 一、基础定义与继承体系

### 1. 命名空间与程序集

- **命名空间**：`System.Windows.Shapes`
- **程序集**：`PresentationFramework.dll`（WPF 核心框架程序集）

### 2. 完整继承链

plaintext:

```tex
System.Object
  └─ System.Windows.Threading.DispatcherObject
     └─ System.Windows.DependencyObject
        └─ System.Windows.Media.Visual
           └─ System.Windows.UIElement
              └─ System.Windows.FrameworkElement
                 └─ System.Windows.Shapes.Shape
```

### 3. 类声明

csharp:

```c#
public abstract class Shape : FrameworkElement
```

- 抽象类：无法直接实例化，必须通过其派生类（`Rectangle`/`Ellipse`/`Line` 等）使用；
- 由于继承自 `FrameworkElement`，Shape 完全支持 WPF 标准布局、数据绑定、样式模板、路由事件、动画等所有控件能力，可直接放入 `Grid`/`Canvas`/`StackPanel` 等容器中。

------

## 二、核心依赖属性详解

Shape 的所有图形特性均通过**依赖属性**定义，原生支持数据绑定、样式继承、动画驱动，这是 WPF 矢量图形的核心优势。按功能可分为四大类：

### 1. 填充属性（内部区域）

| 属性   | 类型    | 依赖属性字段   | 默认值           | 官方说明                                                     |
| :----- | :------ | :------------- | :--------------- | :----------------------------------------------------------- |
| `Fill` | `Brush` | `FillProperty` | `null`（无填充） | 获取或设置用于填充图形封闭内部区域的画刷，支持纯色、线性渐变、径向渐变、图像、纹理等全部 WPF 画刷类型。⚠️ 注意：`Line`、`Polyline` 等非闭合图形没有内部区域，`Fill` 属性无效。 |

### 2. 描边属性族（轮廓线条）

工业场景最高频使用的属性组，控制线条粗细、端点、拐角、虚线样式等全部轮廓特性。

| 属性                 | 类型               | 默认值           | 官方说明                                                     |
| :------------------- | :----------------- | :--------------- | :----------------------------------------------------------- |
| `Stroke`             | `Brush`            | `null`（无轮廓） | 图形轮廓的绘制画刷。若为 `null`，即使设置了 `StrokeThickness` 也不会显示任何轮廓。 |
| `StrokeThickness`    | `double`           | `1.0`            | 轮廓线条的厚度，单位为**与设备无关的像素单位**（1/96 英寸），支持小数。工业高精度绘图需结合屏幕 DPI 做物理尺寸换算。 |
| `StrokeStartLineCap` | `PenLineCap` 枚举  | `Flat`           | 开放线条起点的端点样式，可选值：`Flat`（平端）、`Square`（方端）、`Round`（圆端）、`Triangle`（三角端）。 |
| `StrokeEndLineCap`   | `PenLineCap` 枚举  | `Flat`           | 开放线条终点的端点样式，同起点。工业刻度线、指示线常用 `Round` 避免尖锐毛刺。 |
| `StrokeLineJoin`     | `PenLineJoin` 枚举 | `Miter`          | 多段线条拐角的连接方式：- `Miter`：斜接尖角（默认）；- `Bevel`：斜切平角；- `Round`：圆角过渡。 |
| `StrokeMiterLimit`   | `double`           | `10.0`           | 斜接长度与线条半宽的最大比值，用于限制小角度拐角的尖刺延伸长度，防止出现超长尖角。 |
| `StrokeDashArray`    | `DoubleCollection` | 空集合（实线）   | 虚线样式序列，按「实线长度、空白长度」交替定义。例如 `2,2` 表示 2 单位实线 + 2 单位空白的短虚线。 |
| `StrokeDashOffset`   | `double`           | `0.0`            | 虚线起始位置的偏移量，配合动画可实现流动虚线效果，工业场景常用于表示扫描方向、传送带运动。 |
| `StrokeDashCap`      | `PenLineCap` 枚举  | `Flat`           | 虚线段每一小段的端点样式。                                   |

### 3. 布局拉伸属性

| 属性      | 类型           | 默认值 | 官方说明                                                     |
| :-------- | :------------- | :----- | :----------------------------------------------------------- |
| `Stretch` | `Stretch` 枚举 | `None` | 控制图形如何适配布局系统分配的可用空间，逻辑与 `Image.Stretch` 完全一致：- `None`：按图形原始尺寸渲染，不拉伸（默认）；- `Fill`：拉伸填满整个区域，宽高比可能失真；- `Uniform`：等比例缩放至完全容纳在区域内，不变形；- `UniformToFill`：等比例缩放至完全覆盖区域，超出部分裁剪。 |

### 4. 几何核心属性（底层本质）

Shape 的本质是对 `Geometry` 几何对象的高层封装，以下三个属性是渲染、命中测试的核心：

| 属性               | 访问级别   | 类型       | 官方说明                                                     |
| :----------------- | :--------- | :--------- | :----------------------------------------------------------- |
| `Geometry`         | 公开只读   | `Geometry` | 获取图形对应的原始几何对象，反映形状的定义本身，不包含描边厚度、变换的影响。 |
| `RenderedGeometry` | 公开只读   | `Geometry` | 获取**最终渲染后的几何对象**，包含描边厚度、虚线样式、变换等全部渲染参数的影响，主要用于精确命中测试与边界计算。 |
| `DefiningGeometry` | 受保护抽象 | `Geometry` | Shape 核心扩展点，所有派生类必须重写该属性，返回图形的原始定义几何。自定义 Shape 时只需实现此属性，即可复用全部布局、渲染逻辑。 |

### 5. 基类继承的关键属性

Shape 从 `UIElement`/`FrameworkElement` 继承了大量对工业绘图至关重要的属性：

- `SnapsToDevicePixels`：对齐物理像素，避免亚像素渲染导致的线条模糊，高精度绘图建议设为 `True`；
- `RenderTransform` / `LayoutTransform`：平移、旋转、缩放变换，适合绘制旋转检测框、角度可调的工位组件；
- `Opacity` / `OpacityMask`：透明度与遮罩，用于半透明标记、区域高亮；
- `Clip`：裁剪区域，限制图形显示范围。

## 三、核心方法与渲染原理

### 1. 布局核心：重写布局流程

Shape 重写了 `FrameworkElement` 的两个标准布局方法，完全融入 WPF 布局系统：

- `protected override Size MeasureOverride(Size availableSize)`

  

  根据图形自身几何尺寸、`Stretch模式`、可用空间，计算图形期望的布局尺寸（`DesiredSize`）；

- `protected override Size ArrangeOverride(Size finalSize)`

  

  确定图形在最终分配空间内的实际渲染区域，应用拉伸与对齐逻辑。

这也是 Shape 区别于低层 `Drawing` 的核心优势：它是标准布局元素，可以和按钮、文本框等控件一起参与容器自动布局。

### 2. 渲染入口：OnRender

csharp:

```c#
protected override void OnRender(DrawingContext drawingContext);
```

这是 Shape 渲染的核心回调，由 WPF 渲染系统自动触发，执行逻辑固定：

1. 读取 `DefiningGeometry` 原始几何，应用拉伸、变换；
2. 调用 `drawingContext.DrawGeometry(Fill, pen, geometry)`，先用 `Fill` 画刷填充内部区域；
3. 再根据 `Stroke`、`StrokeThickness`、虚线等参数构造 `Pen` 对象，绘制图形轮廓；
4. 整个渲染过程由 WPF 可视化层托管，支持 DirectX 硬件加速。

### 3. 精确命中测试

Shape 重写了 `HitTestCore` 方法，**基于几何图形做精确命中判断**，而非简单的矩形边界命中：

- 例如点击 `Ellipse` 四角的空白区域不会触发命中，只有点击椭圆实体区域才会响应；
- 工业场景中点击缺陷标记、检测框交互时，精准命中体验远优于矩形控件。

### 4. 完整渲染流程

1. 布局系统调用 `MeasureOverride`，计算图形所需尺寸；
2. 布局系统调用 `ArrangeOverride`，确定最终渲染区域；
3. 渲染系统触发 `OnRender` 回调，传入 `DrawingContext`；
4. 内部应用拉伸、变换，计算最终几何；
5. 依次绘制填充、描边，完成渲染输出。

## 四、内置派生类（6 种标准图形）

WPF 内置 6 个常用 Shape 派生类，覆盖绝大多数工业绘图场景：

| 派生类      | 核心定义属性                            | 图形特点                                                   | 典型工业场景                             |
| :---------- | :-------------------------------------- | :--------------------------------------------------------- | :--------------------------------------- |
| `Line`      | `X1`、`Y1`、`X2`、`Y2`                  | 两点定义的直线，无封闭区域，`Fill` 无效                    | 刻度线、辅助线、尺寸标注、运动轨迹       |
| `Rectangle` | `Width`、`Height`、`RadiusX`、`RadiusY` | 矩形，支持圆角                                             | 检测框、工位区域、产品外框、按钮背景     |
| `Ellipse`   | `Width`、`Height`                       | 椭圆，宽高相等时为正圆                                     | 焊点标记、圆形检测区域、状态指示灯       |
| `Polygon`   | `Points`（点集合）、`FillRule`          | 顶点定义的闭合多边形，自动首尾相连                         | 不规则工位轮廓、多边形检测区域、缺陷轮廓 |
| `Polyline`  | `Points`（点集合）                      | 顶点定义的折线，不自动闭合，`Fill` 无效                    | 运动轨迹、温度曲线、扫描路径             |
| `Path`      | `Data`（`Geometry` 类型）               | 最灵活的图形，支持贝塞尔曲线、组合几何，可绘制任意复杂形状 | 复杂机械轮廓、自定义图标、矢量工位示意图 |

> 性能提示：`Path` + `StreamGeometry` 是复杂图形的性能最优方案，代码动态构造路径无 XAML 解析开销，适合缺陷轮廓、扫描路径等复杂场景。

## 五、工业上位机场景应用要点与避坑

### 1. 典型应用场景

- **检测结果可视化**：将缺陷坐标、尺寸绑定到 `Rectangle`/`Ellipse` 的位置与大小，MVVM 模式下无需跨线程操作 UI；
- **工位状态展示**：用 Shape 组合绘制气缸、传感器、工位轮廓，通过颜色绑定直观展示设备状态；
- **运动轨迹监控**：用 `Polyline` 实时追加坐标点，绘制伺服轴运动轨迹、温度曲线；
- **动态扫描效果**：通过动画修改 `StrokeDashOffset`，实现流动虚线、扫描线效果。

### 2. 性能注意事项

- **少量图形优先用 Shape**：几十以内的图形，Shape 开发效率高、易维护，性能完全满足工业场景；
- **大量高频刷新慎用 Shape**：上百个动态图形同时刷新时，每个 Shape 都是独立的 `FrameworkElement`，有布局开销，高频刷新可能卡顿。此时建议改用 `DrawingVisual`、`WriteableBitmap` 等低层绘制方案；
- 动画优先用 `RenderTransform`：位置、角度的高频动画使用变换动画，避免触发布局重算。

### 3. 常见坑与解决方案

1. **线条模糊发虚**

   原因：WPF 默认亚像素渲染，坐标落在像素缝隙中。

   解决：设置 `SnapsToDevicePixels="True"` 对齐物理像素，使用整数坐标绘制。

2. **设置了 `StrokeThickness` 但线条不显示**

   原因：未设置 `Stroke` 属性（默认 `null`），或 `StrokeThickness` 为 0。

   解决：必须同时设置 `Stroke` 画刷和 `StrokeThickness` 厚度。

3. **`Polygon` 填充出现镂空**

   原因：`FillRule` 默认 `EvenOdd`，交叉区域按奇偶规则镂空。

   解决：设置 `FillRule="Nonzero"`，按非零环绕规则填充闭合区域。

4. **`Line` 设置 `Width`/`Height` 无效**

   原因：`Line` 的形状由 `X1/Y1/X2/Y2` 端点决定，`Width`/`Height` 是布局属性，不影响线条本身坐标。

   解决：通过端点坐标控制线条，或用 `Canvas.Left`/`Canvas.Top` 做整体定位。

------

## 总结

`Shape` 是 WPF 中易用性与功能平衡最好的矢量绘图方案，对于工业上位机绝大多数可视化需求，它既能快速开发，又能完美支持数据绑定、动画、交互，是 UI 层绘图的首选；只有在超大量、超高频刷新的极端场景下，才需要考虑更低层的绘制方案。
