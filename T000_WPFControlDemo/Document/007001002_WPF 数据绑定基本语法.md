# 007001002_WPF 数据绑定基本语法

WPF 数据绑定最常用的是 **XAML 标记扩展语法 `{Binding ...}`**，也支持 C# 后台代码创建绑定。核心遵循「**UI 目标属性 = {Binding 数据源路径，可选配置参数}**」的格式，下面从基础到进阶，结合你熟悉的图形控件场景逐一说明。

------

## 一、XAML 核心绑定语法

### 1. 最简格式：只绑定属性路径

这是日常开发最高频的写法，绑定到当前控件的 `DataContext`（数据上下文）中的指定属性。

xaml:

```xaml
<!-- 语法：{Binding 数据源属性名} -->
<TextBlock Text="{Binding DeviceTemperature}"/>
```

- 含义：将 `TextBlock` 的 `Text` 属性，绑定到数据源的 `DeviceTemperature` 属性上。
- 数据源来源：默认从当前控件的 `DataContext` 中查找属性，`DataContext` 会沿着可视化树向下继承。

#### 特殊简写：绑定整个数据源对象

如果只写 `{Binding}`（不写属性名），表示绑定当前的 `DataContext` 整体对象，常用于列表项模板、整个控件绑定一个完整对象的场景。

xaml:

```xaml
<!-- 整个 UserControl 绑定到当前 DataContext 对象 -->
<UserControl DataContext="{Binding}"/>
```

------

### 2. 完整格式：带配置参数

在路径后可以追加多个可选参数，用逗号分隔，精细控制绑定行为。

xaml:

```xaml
<!-- 语法：{Binding 路径, 参数1=值, 参数2=值, ...} -->
<TextBox Text="{Binding DetectThreshold, Mode=TwoWay, UpdateSourceTrigger=PropertyChanged}"/>
```

#### 最常用的配置参数

| 参数                  | 作用                                    | 可选值 / 说明                                                |
| :-------------------- | :-------------------------------------- | :----------------------------------------------------------- |
| `Mode`                | 绑定方向（数据流方向）                  | `OneWay`（默认，源→UI）、`TwoWay`（双向同步）、`OneTime`（仅初始化一次）、`OneWayToSource`（UI→源） |
| `UpdateSourceTrigger` | UI 修改后，回写数据源的时机             | `LostFocus`（默认，失焦时回写）、`PropertyChanged`（值一变就回写）、`Explicit`（手动调用更新） |
| `StringFormat`        | 字符串格式化，直接给显示值加格式 / 单位 | 写法：`StringFormat={}{0:格式}`                              |
| `Converter`           | 值转换器，解决源与目标类型不匹配的问题  | 绑定一个实现了 `IValueConverter` 的转换器对象                |
| `ConverterParameter`  | 传给转换器的额外参数                    | 任意对象，用于转换器逻辑分支                                 |
| `FallbackValue`       | 绑定失败时的兜底显示值                  | 绑定出错、值为 null 时显示的默认值                           |
| `TargetNullValue`     | 数据源为 null 时，UI 显示的值           | 专门处理 null 值的展示                                       |

##### 常用参数示例

1. **带单位的数值显示（StringFormat）**

   xaml:

   ```xaml
   <!-- 温度值后面加℃单位 -->
   <TextBlock Text="{Binding Temperature, StringFormat={}{0} ℃}"/>
   ```

   > 注意：开头的 `{}` 是 XAML 转义符，避免大括号被解析为标记扩展。

2. **双向实时绑定（TwoWay + PropertyChanged）**

   xaml:

   ```xaml
   <!-- 输入框内容变化立刻回写数据源，不用等失焦 -->
   <TextBox Text="{Binding ExposureTime, Mode=TwoWay, UpdateSourceTrigger=PropertyChanged}"/>
   ```

3. **状态转颜色（Converter）**

   xaml:

   ```xaml
   <!-- 设备状态枚举转背景色 -->
   <Rectangle Fill="{Binding StationStatus, Converter={StaticResource StatusToBrushConverter}}"/>
   ```

### 3. 指定绑定源的三种写法

默认绑定源是当前的 `DataContext`，如果需要绑定其他对象，可以通过以下三个参数指定源。

#### ① 绑定其他控件的属性：`ElementName`

直接绑定界面上另一个控件的属性，适合控件之间联动，比如滑块控制图形大小。

xaml:

```xaml
<StackPanel>
    <Slider x:Name="sizeSlider" Minimum="0" Maximum="300" Value="100"/>
    <!-- 矩形宽度绑定滑块的值，拖动滑块矩形实时变宽 -->
    <Rectangle Width="{Binding Value, ElementName=sizeSlider}"
               Height="50"
               Fill="RoyalBlue"/>
</StackPanel>
```

#### ② 绑定相对位置的元素：`RelativeSource`

绑定当前控件的父级、自身等相对关系的对象，不需要给控件起名，适合模板、样式中使用。

- 绑定自身：`RelativeSource Self`

  xaml:

  ```xaml
  <!-- 矩形高度绑定自身宽度，保持正方形 -->
  <Rectangle Width="100"
             Height="{Binding Width, RelativeSource={RelativeSource Self}}"
             Fill="Green"/>
  ```

- 绑定指定类型的父级：`RelativeSource AncestorType`

  xaml:

  ```xaml
  <!-- 绑定最近的父级 Window 的 Title 属性 -->
  <TextBlock Text="{Binding Title, RelativeSource={RelativeSource AncestorType=Window}}"/>
  ```

#### ③ 绑定静态资源 / 固定对象：`Source`

绑定一个静态资源、全局对象或常量。

xaml:

```xaml
<Window.Resources>
    <sys:Double x:Key="DefaultLineWidth">2</sys:Double>
</Window.Resources>

<!-- 线条厚度绑定静态资源中的默认值 -->
<Line Stroke="Black" StrokeThickness="{Binding Source={StaticResource DefaultLineWidth}}"/>
```

## 二、C# 后台代码绑定语法

动态创建控件、需要逻辑控制绑定时，可在 C# 代码中创建绑定，核心使用 `SetBinding` 方法。

### 基础语法

csharp:

```c#
// 1. 创建绑定对象
Binding binding = new Binding();
binding.Path = new PropertyPath("数据源属性名");
binding.Mode = BindingMode.TwoWay;
binding.Source = 数据源对象;

// 2. 把绑定应用到目标控件的目标属性上
targetControl.SetBinding(目标控件.目标属性, binding);
```

### 实战示例：动态创建矩形并绑定宽度

csharp:

```c#
using System.Windows.Data;

// 创建矩形
Rectangle rect = new Rectangle();
rect.Fill = Brushes.RoyalBlue;
rect.Height = 50;

// 创建绑定：绑定到 viewModel 的 RectWidth 属性
Binding widthBinding = new Binding("RectWidth");
widthBinding.Source = viewModel;
widthBinding.Mode = BindingMode.OneWay;

// 应用绑定到 Rectangle 的 WidthProperty 依赖属性
rect.SetBinding(Rectangle.WidthProperty, widthBinding);
```

> 注意：目标属性必须是**依赖属性**（DependencyProperty），这是 WPF 绑定的硬性要求。

## 三、结合图形控件的完整示例

### 示例 1：滑块控制多边形透明度（ElementName 双向联动）

xaml:

```xaml
<StackPanel Margin="20">
    <Slider x:Name="opacitySlider" Minimum="0" Maximum="1" Value="0.5" Margin="0 0 0 20"/>
    
    <!-- 多边形透明度绑定滑块的值 -->
    <Polygon Points="150,20 20,180 280,180"
             Stroke="DarkBlue"
             Fill="#334169E1"
             Opacity="{Binding Value, ElementName=opacitySlider}"/>
</StackPanel>
```

### 示例 2：MVVM 模式下的路径数据绑定（默认 DataContext）

这是工业上位机最常用的写法，视图模型提供数据，UI 纯绑定，后台不操作控件。

csharp:

```c#
// 视图模型
public class DetectViewModel : INotifyPropertyChanged
{
    private Geometry _roiGeometry;
    public Geometry RoiGeometry
    {
        get => _roiGeometry;
        set { _roiGeometry = value; OnPropertyChanged(nameof(RoiGeometry)); }
    }
}
```

xaml:

```xaml
<!-- XAML 界面：Path 的 Data 直接绑定视图模型属性 -->
<Canvas Background="#1E1E1E">
    <Path Data="{Binding RoiGeometry}"
          Stroke="Cyan"
          StrokeThickness="2"
          Fill="#2200FFFF"/>
</Canvas>
```

## 四、语法注意事项

1. **目标必须是依赖属性**

   只有依赖属性（DependencyProperty）才能作为绑定目标，普通 CLR 属性不能绑定。WPF 控件的绝大多数属性都是依赖属性，比如 `Text`、`Fill`、`Width`、`Points` 等。

2. **数据源要支持变更通知**

   想要数据源变化时 UI 自动更新，数据源类必须实现 `INotifyPropertyChanged` 接口，属性值变更时触发 `PropertyChanged` 事件。

3. **路径区分大小写**

   绑定的属性名和 C# 类中的属性名严格大小写一致，写错会导致绑定失败，不会报错但界面不显示。

4. **`StringFormat` 只对字符串类型目标生效**

   一般用在 `Text`、`Content` 这类字符串属性上，给数值加单位、格式化日期时间等。
