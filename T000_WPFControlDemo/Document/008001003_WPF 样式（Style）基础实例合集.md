# 008001003_WPF 样式（Style）基础实例合集

以下 6 个实例覆盖 WPF 样式最核心的基础能力，从静态属性复用、交互状态响应到业务数据驱动，全部围绕工业上位机常用控件设计，代码可直接复制运行。

所有样式统一写在 `Window.Resources` 窗口资源中，全局使用可放到 `App.xaml` 资源字典里。

------

## 前置：配套 ViewModel 代码（数据触发器用）

用于支撑「数据驱动 UI」的实例，实现属性变更通知：

csharp:

```c#
using System.ComponentModel;
using System.Runtime.CompilerServices;
using System.Collections.ObjectModel;

public class MainViewModel : INotifyPropertyChanged
{
    // 属性变更通知基础逻辑
    public event PropertyChangedEventHandler PropertyChanged;
    protected void OnPropertyChanged([CallerMemberName] string name = null)
        => PropertyChanged?.Invoke(this, new PropertyChangedEventArgs(name));

    // 设备状态属性
    private bool _isRunning = true;
    public bool IsRunning
    {
        get => _isRunning;
        set { _isRunning = value; OnPropertyChanged(); }
    }

    private bool _isAlarming;
    public bool IsAlarming
    {
        get => _isAlarming;
        set { _isAlarming = value; OnPropertyChanged(); }
    }

    // 缺陷列表数据
    public ObservableCollection<string> DefectList { get; set; } = new()
    {
        "缺陷记录_001", "缺陷记录_002", "缺陷记录_003"
    };
}
```

窗口后台设置数据源：

csharp:

```c#
public partial class MainWindow : Window
{
    public MainViewModel Vm { get; } = new MainViewModel();
    public MainWindow()
    {
        InitializeComponent();
        this.DataContext = Vm;
    }
}
```

## 实例 1：基础静态样式（属性复用）

### 场景

统一定义按钮的背景、字体、尺寸、内边距，多处按钮复用同一套外观，避免重复写属性。

### 样式定义

xaml:

```xaml
<Window.Resources>
    <!-- 主按钮样式：x:Key 命名，控件显式引用 -->
    <Style x:Key="PrimaryButtonStyle" TargetType="Button">
        <!-- 静态设置器：批量设置属性 -->
        <Setter Property="Background" Value="#2E7DFF"/>
        <Setter Property="Foreground" Value="White"/>
        <Setter Property="FontSize" Value="14"/>
        <Setter Property="Width" Value="120"/>
        <Setter Property="Height" Value="32"/>
        <Setter Property="BorderThickness" Value="0"/>
        <Setter Property="Cursor" Value="Hand"/>
    </Style>
</Window.Resources>
```

### 界面引用

xaml:

```xaml
<StackPanel Orientation="Horizontal" Margin="30" Spacing="10">
    <Button Content="确认下发" Style="{StaticResource PrimaryButtonStyle}"/>
    <Button Content="保存参数" Style="{StaticResource PrimaryButtonStyle}"/>
</StackPanel>
```

### 核心要点

- `Setter` 是样式的基础单元，用于设置控件的依赖属性默认值；
- 带 `x:Key` 的样式必须手动引用，适合差异化的专用样式。

## 实例 2：隐式样式（全局自动应用）

### 场景

整个窗口所有文本输入框自动应用统一样式，不需要逐个控件加 `Style`，用于全局规范界面风格。

### 样式定义

xaml:

```xaml
<Window.Resources>
    <!-- 隐式样式：无 x:Key，自动应用到所有 TextBox -->
    <Style TargetType="TextBox">
        <Setter Property="Width" Value="250"/>
        <Setter Property="Height" Value="28"/>
        <Setter Property="Padding" Value="6 4"/>
        <Setter Property="FontSize" Value="14"/>
        <Setter Property="BorderBrush" Value="#CCCCCC"/>
        <Setter Property="BorderThickness" Value="1"/>
        <Setter Property="VerticalContentAlignment" Value="Center"/>
    </Style>
</Window.Resources>
```

### 界面使用

xaml:

```xaml
<StackPanel Margin="30" Spacing="10">
    <TextBox Text="曝光时间参数"/>
    <TextBox Text="增益值参数"/>
    <TextBox Text="触发延迟参数"/>
</StackPanel>
```

### 核心要点

- 不写 `x:Key`，仅通过 `TargetType` 匹配，同类型控件自动生效；
- 适合全局基础控件的风格统一，是大型项目的标准做法。

## 实例 3：属性触发器（交互状态响应）

### 场景

按钮鼠标悬停变色、按下加深、禁用变灰，实现基础交互反馈，完全由样式实现，无需后台事件代码。

### 样式定义

xaml:

```xaml
<Window.Resources>
    <Style x:Key="InteractiveButtonStyle" TargetType="Button">
        <!-- 默认状态 -->
        <Setter Property="Background" Value="#2E7DFF"/>
        <Setter Property="Foreground" Value="White"/>
        <Setter Property="Width" Value="120"/>
        <Setter Property="Height" Value="32"/>
        <Setter Property="BorderThickness" Value="0"/>
        <Setter Property="Cursor" Value="Hand"/>

        <!-- 触发器集合：监听控件自身属性变化 -->
        <Style.Triggers>
            <!-- 鼠标悬停 -->
            <Trigger Property="IsMouseOver" Value="True">
                <Setter Property="Background" Value="#5597FF"/>
            </Trigger>
            <!-- 鼠标按下 -->
            <Trigger Property="IsPressed" Value="True">
                <Setter Property="Background" Value="#1A66E0"/>
            </Trigger>
            <!-- 控件禁用 -->
            <Trigger Property="IsEnabled" Value="False">
                <Setter Property="Background" Value="#CCCCCC"/>
                <Setter Property="Foreground" Value="#999999"/>
                <Setter Property="Cursor" Value="No"/>
            </Trigger>
        </Style.Triggers>
    </Style>
</Window.Resources>
```

### 界面引用

xaml:

```xaml
<StackPanel Orientation="Horizontal" Margin="30" Spacing="10">
    <Button Content="可点击按钮" Style="{StaticResource InteractiveButtonStyle}"/>
    <Button Content="禁用按钮" Style="{StaticResource InteractiveButtonStyle}" IsEnabled="False"/>
</StackPanel>
```

### 核心要点

- `Trigger` 监听**控件自身的依赖属性**，条件满足时自动应用属性；
- 触发器是「自动生效、自动恢复」的，条件消失后自动回到默认值，不需要写反向逻辑。

## 实例 4：数据触发器（业务数据驱动 UI）

### 场景

设备状态指示灯，根据 ViewModel 中的运行、告警属性自动切换颜色，是工业场景最常用的样式用法，完全符合 MVVM 架构。

### 样式定义

xaml:

```xaml
<Window.Resources>
    <Style x:Key="StatusLightStyle" TargetType="Ellipse">
        <!-- 默认：离线灰色 -->
        <Setter Property="Width" Value="20"/>
        <Setter Property="Height" Value="20"/>
        <Setter Property="Fill" Value="Gray"/>

        <Style.Triggers>
            <!-- 数据触发器：绑定数据源的 IsRunning 属性 -->
            <DataTrigger Binding="{Binding IsRunning}" Value="True">
                <Setter Property="Fill" Value="LimeGreen"/>
            </DataTrigger>
            <!-- 告警状态：写在后面，优先级更高 -->
            <DataTrigger Binding="{Binding IsAlarming}" Value="True">
                <Setter Property="Fill" Value="Orange"/>
            </DataTrigger>
        </Style.Triggers>
    </Style>
</Window.Resources>
```

### 界面引用

xaml:

```xaml
<StackPanel Orientation="Horizontal" Margin="30" Spacing="10">
    <Ellipse Style="{StaticResource StatusLightStyle}"/>
    <TextBlock Text="设备运行状态" VerticalAlignment="Center"/>
    
    <!-- 切换状态，验证数据驱动 -->
    <CheckBox Content="切换运行" IsChecked="{Binding IsRunning, Mode=TwoWay}" Margin="20 0 0 0" VerticalAlignment="Center"/>
    <CheckBox Content="切换告警" IsChecked="{Binding IsAlarming, Mode=TwoWay}" VerticalAlignment="Center"/>
</StackPanel>
```

### 核心要点

- `DataTrigger` 绑定**数据源（DataContext）的属性**，数据变化自动触发 UI 变化；
- 多个触发器同时满足时，写在后面的优先级更高，高优先级状态放在后面定义。

## 实例 5：样式继承（BasedOn 扩展）

### 场景

基于基础按钮样式，派生出主按钮、危险按钮、次要按钮，复用公共属性，只修改差异化的颜色，避免重复代码。

### 样式定义

xaml:

```xaml
<Window.Resources>
    <!-- 基础按钮：公共属性 -->
    <Style x:Key="BaseButtonStyle" TargetType="Button">
        <Setter Property="Width" Value="120"/>
        <Setter Property="Height" Value="32"/>
        <Setter Property="FontSize" Value="14"/>
        <Setter Property="BorderThickness" Value="0"/>
        <Setter Property="Cursor" Value="Hand"/>
    </Style>

    <!-- 主按钮：继承基础样式，只改颜色 -->
    <Style x:Key="PrimaryButtonStyle" TargetType="Button"
           BasedOn="{StaticResource BaseButtonStyle}">
        <Setter Property="Background" Value="#2E7DFF"/>
        <Setter Property="Foreground" Value="White"/>
    </Style>

    <!-- 危险按钮：继承基础样式，改红色 -->
    <Style x:Key="DangerButtonStyle" TargetType="Button"
           BasedOn="{StaticResource BaseButtonStyle}">
        <Setter Property="Background" Value="#F53F3F"/>
        <Setter Property="Foreground" Value="White"/>
    </Style>

    <!-- 次要按钮：继承基础样式，改边框样式 -->
    <Style x:Key="SecondaryButtonStyle" TargetType="Button"
           BasedOn="{StaticResource BaseButtonStyle}">
        <Setter Property="Background" Value="White"/>
        <Setter Property="Foreground" Value="#333"/>
        <Setter Property="BorderBrush" Value="#DDD"/>
        <Setter Property="BorderThickness" Value="1"/>
    </Style>
</Window.Resources>
```

### 界面引用

xaml:

```xaml
<StackPanel Orientation="Horizontal" Margin="30" Spacing="10">
    <Button Content="确认" Style="{StaticResource PrimaryButtonStyle}"/>
    <Button Content="取消" Style="{StaticResource SecondaryButtonStyle}"/>
    <Button Content="删除" Style="{StaticResource DangerButtonStyle}"/>
</StackPanel>
```

### 核心要点

- `BasedOn` 实现样式的继承与扩展，符合开闭原则；
- 修改基础样式的公共属性，所有派生样式会同步生效，维护成本极低。

## 实例 6：列表项容器样式（自定义选中效果）

### 场景

自定义列表行的悬停、选中高亮样式，替代系统默认的深蓝色选中效果，适配工业软件的配色风格。

### 样式定义

xaml:

```xaml
<Window.Resources>
    <!-- 列表项容器样式：作用于每一行的 ListBoxItem -->
    <Style x:Key="DefectListItemStyle" TargetType="ListBoxItem">
        <Setter Property="Padding" Value="8 6"/>
        <Setter Property="Foreground" Value="#333333"/>
        <Setter Property="Background" Value="Transparent"/>

        <Style.Triggers>
            <!-- 鼠标悬停 -->
            <Trigger Property="IsMouseOver" Value="True">
                <Setter Property="Background" Value="#F0F7FF"/>
            </Trigger>
            <!-- 选中状态 -->
            <Trigger Property="IsSelected" Value="True">
                <Setter Property="Background" Value="#E6F0FF"/>
                <Setter Property="Foreground" Value="#2E7DFF"/>
                <Setter Property="FontWeight" Value="Bold"/>
            </Trigger>
        </Style.Triggers>
    </Style>
</Window.Resources>
```

### 界面引用

xaml:

```xaml
<ListBox Width="300" Height="120" Margin="30"
         ItemsSource="{Binding DefectList}"
         ItemContainerStyle="{StaticResource DefectListItemStyle}"/>
```

### 核心要点

- 列表项样式通过 `ItemContainerStyle` 属性赋值，作用于每行的容器控件；
- 只能控制行的外观属性，要修改行的内部结构需要用 `ItemTemplate` 数据模板。

## 基础注意事项总结

1. **本地值优先级更高**：如果控件上直接写了 `Background="Red"`，样式中同名的属性会失效，因为本地值优先级高于样式。
2. **触发器顺序决定优先级**：多个触发器同时满足条件时，定义在后面的触发器会覆盖前面的同名属性。
3. **样式密封不可修改**：样式被应用后，运行时无法修改内部的 Setter 和 Trigger，动态变化请用触发器实现。
4. **作用域规则**：样式定义在哪个层级的资源里，就只能在该层级及子元素中使用，全局样式放在 `App.xaml` 中。
5. **属性触发器 vs 数据触发器**：监听控件自身状态用 `Trigger`，监听业务数据状态用 `DataTrigger`。
