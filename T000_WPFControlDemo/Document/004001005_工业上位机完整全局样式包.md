# 004001005_工业上位机完整全局样式包

## 一、项目结构与部署步骤

### 1.1 完整项目结构

在你的项目根目录下创建`Styles`文件夹，包含以下文件：

plaintext:

```tex
IndustrialVisionTemplate/
└── Styles/
    ├── 01_Colors.xaml          # 工业标准颜色体系（核心）
    ├── 02_Fonts.xaml           # 字体与尺寸规范
    ├── 03_ButtonStyles.xaml    # 按钮样式（含工业专用按钮）
    ├── 04_InputStyles.xaml     # 输入控件样式（文本框/下拉框/复选框）
    ├── 05_TextStyles.xaml      # 文本与标签样式
    ├── 06_DataGridStyles.xaml  # 数据表格样式（生产记录专用）
    ├── 07_ContainerStyles.xaml # 容器与分组样式
    ├── 08_StatusStyles.xaml    # 状态显示样式（指示灯/进度条）
    └── 09_CustomControls.xaml  # 自定义控件样式（IoIndicator等）
```

### 1.2 部署步骤

1. 将上述 9 个文件全部复制到你的项目`Styles`文件夹中
2. 右键每个文件 → 属性 → 生成操作：`Page`，复制到输出目录：`不复制`
3. 修改`App.xaml`，按顺序合并所有资源字典（顺序不能错！）

------

## 五、工业项目使用注意事项

1. **颜色不可随意修改**：工业现场操作人员已经形成条件反射，绿运行红停机是行业标准
2. **字体大小不小于 12 号**：确保操作人员在 3 米外也能看清关键信息
3. **按钮最小尺寸不小于 80×32**：触摸屏操作时防止误触
4. **禁用复杂动画**：工业软件追求稳定和性能，避免不必要的视觉效果
5. **高 DPI 适配**：所有尺寸使用独立像素单位，确保在 4K 显示器上正常显示
6. **数据表格开启虚拟化**：当数据量超过 1000 条时，虚拟化能显著提升性能
