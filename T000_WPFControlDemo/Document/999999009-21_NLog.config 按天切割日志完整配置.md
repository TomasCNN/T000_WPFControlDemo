# 999999009-21_NLog.config 按天切割日志完整配置

## 核心属性说明（实现按天切割的关键）

### 1. 核心归档属性（File Target 内配置）

| 属性                                      | 取值           | 作用                                                      |
| :---------------------------------------- | :------------- | :-------------------------------------------------------- |
| `archiveEvery="Day"`                      | Day            | 按自然天切割，每天凌晨自动生成新日志文件                  |
| `archiveNumbering="Date"`                 | Date           | 归档文件名使用日期后缀，格式 `app-20260623.log`           |
| `maxArchiveDays="30"`                     | 数字           | 自动删除超过 N 天的旧日志，防止磁盘爆满（工控推荐 30~90） |
| `maxArchiveFiles="100"`                   | 数字           | 兜底最大归档文件数量，双重防护                            |
| `fileName="D:/Logs/app-${shortdate}.log"` | `${shortdate}` | 当天日志文件名自带日期，当天所有日志写入同一个文件        |

### 补充说明

- `${shortdate}` = `yyyy-MM-dd`，当天文件固定名称，次日自动新建；
- `archiveEvery="Day"` 会在每日 0 点自动切换文件，不需要程序重启；
- `maxArchiveDays` 会自动清理过期日志，7×24 小时工控必备。

## 方案 1：最简标准配置（推荐，全局异步 + 按天切割）

xaml:

```xaml
<?xml version="1.0" encoding="utf-8" ?>
<nlog xmlns="http://www.nlog-project.org/schemas/NLog.xsd"
      xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
      autoReload="true"
      internalLogLevel="Warn"
      internalLogFile="D:/Logs/nlog-internal.log">

  <!-- 全局异步写入，不阻塞相机/PLC实时线程 -->
  <targets async="true" queueLimit="5000" overflowAction="Discard">

    <!-- 主日志：按天切割，保留30天 -->
    <target xsi:type="File"
            name="MainLog"
            encoding="utf-8"
            keepFileOpen="true"
            concurrentWrites="false"
            fileName="D:/Logs/app-${shortdate}.log"
            archiveEvery="Day"
            archiveNumbering="Date"
            maxArchiveDays="30"
            maxArchiveFiles="100">

      <layout>${longdate} | ${level:uppercase=true:padding=-5} | 线程${threadid} | ${event-properties:item=Module} | ${message} ${exception:format=ToString}</layout>
    </target>

    <!-- 错误独立日志：单独按天切割，保存更久90天 -->
    <target xsi:type="File"
            name="ErrorLog"
            encoding="utf-8"
            keepFileOpen="true"
            fileName="D:/Logs/error-${shortdate}.log"
            archiveEvery="Day"
            archiveNumbering="Date"
            maxArchiveDays="90">
      <layout>${longdate} | ${level:uppercase=true} | 线程${threadid} | ${event-properties:item=Module} | ${message}
${exception:format=ToString,StackTrace}
=========================================================================</layout>
    </target>

    <!-- 开发控制台输出，生产可注释 -->
    <target xsi:type="ColoredConsole" name="ConsoleLog" layout="${time:format=HH\:mm\:ss.fff} | ${level} | ${event-properties:item=Module} | ${message}" />
  </targets>

  <rules>
    <logger name="*" minlevel="Info" writeTo="MainLog" />
    <logger name="*" minlevel="Error" writeTo="ErrorLog" />
    <logger name="*" minlevel="Debug" writeTo="ConsoleLog" />
  </rules>
</nlog>
```

## 生成文件效果

日志目录 `D:/Logs` 自动生成：

plaintext:

```tex
app-2026-06-22.log
app-2026-06-23.log
error-2026-06-22.log
error-2026-06-23.log
nlog-internal.log
```

每日 0 点自动新建当天日志，超过 30 天的 app-xxx.log、超过 90 天的 error-xxx.log 自动删除。

## 方案 2：旧版序号归档（不推荐工业使用，仅作了解）

`archiveNumbering="Sequence"` 数字序号命名，缺点：无法直观看出日期，清理不方便：

xaml:

```xaml
<target xsi:type="File"
        fileName="D:/Logs/app.log"
        archiveFileName="D:/Logs/archive/app-{#}.log"
        archiveEvery="Day"
        archiveNumbering="Sequence"
        maxArchiveFiles="30"/>
```

生成文件：`app.log`（当天）、`archive/app-1.log`、`archive/app-2.log`

## 工业场景配套优化参数

1. `keepFileOpen="true"`

   长期持有文件句柄，避免高频日志反复打开关闭文件，降低 IO 耗时，不影响相机取图 CT。

2. `concurrentWrites="false"`

   单进程单文件写入，关闭多进程并发锁，减少性能损耗。

3. `encoding="utf-8"`

   防止中文日志在工控机英文系统乱码。

4. `autoReload="true"`

   修改日志级别、切割配置无需重启上位机，自动生效。

## 常见问题排查

1. 不按天切割

   - 确认 `archiveEvery="Day"` 写在 `<target xsi:type="File">` 内部，不要写到 targets 根节点；
   - 程序跨零点必须保持运行，NLog 会自动检测日期切换文件，无需重启。

2. 旧日志不自动删除

   - 必须配置 `maxArchiveDays`，仅写 maxArchiveFiles 只会限制文件总数，不会按天数清理；

3. 日志文件名没有日期

   - `fileName` 必须包含 `${shortdate}`，如果写成固定 `app.log`，当日不会自动区分文件。

4. 中文乱码

   增加 `encoding="utf-8"`到 File 节点。
