### 1.1 新增接口实现详解

Image 实现了两个重要的内部接口，这是理解其相对路径解析和属性回退机制的关键：

#### `IUriContext` 接口

csharp:

```c#
public interface IUriContext
{
    Uri BaseUri { get; set; }
}
```

- **官方作用**：提供一个上下文，用于解析相对 URI
- **Image 中的实现**：`BaseUri` 属性存储 XAML 文件的基 URI，用于解析相对路径的图像源
- **关键行为**：
  - 当你在 XAML 中写 `<Image Source="Images/icon.png"/>` 时，WPF 会使用 `BaseUri` 将相对路径转换为绝对路径
  - 如果 `BaseUri` 为 null，会使用应用程序的基 URI
- **工业场景意义**：解决动态加载 XAML 时相对路径解析失败的问题

#### `IProvidePropertyFallback` 接口

csharp:

```c#
public interface IProvidePropertyFallback
{
    object ProvidePropertyFallback(string propertyName, object value);
}
```

- **官方作用**：为无效的属性值提供回退值
- **Image 中的实现**：当 `Source` 属性设置为无效值（如不存在的文件路径）时，返回 `null` 而不是抛出异常
- **关键行为**：这就是为什么 Image 加载失败时不会崩溃，只会显示空白

### 2.2 受保护方法

#### `OnDpiChanged(DpiScale oldDpi, DpiScale newDpi)` 方法

csharp:

```c#
protected override void OnDpiChanged(DpiScale oldDpi, DpiScale newDpi);
```

- **官方作用**：当 DPI 发生变化时调用
- **官方默认实现**：
  - 重新计算图像的渲染尺寸
  - 触发 `MeasureOverride` 和 `ArrangeOverride` 重新布局
  - 触发 `OnRender` 重新渲染
- **工业场景扩展点**：
  - 重写此方法可以实现自定义 DPI 适配逻辑
  - 加载不同分辨率的图像资源（如 @1x、@2x、@3x）

**工业级 DPI 适配示例**：

csharp:

```c#
protected override void OnDpiChanged(DpiScale oldDpi, DpiScale newDpi)
{
    base.OnDpiChanged(oldDpi, newDpi);
    
    // 根据新的 DPI 加载对应分辨率的图像
    if (Source is BitmapImage bitmap)
    {
        string basePath = bitmap.UriSource.LocalPath.Replace("@2x", "").Replace("@3x", "");
        string suffix = newDpi.DpiScaleX >= 2.0 ? "@2x" : "";
        string highResPath = Path.ChangeExtension(basePath, suffix + Path.GetExtension(basePath));
        
        if (File.Exists(highResPath))
        {
            Source = new BitmapImage(new Uri(highResPath));
        }
    }
}
```

## 三、完整官方行为流程

### 3.1 图像加载完整流程

结合最新类定义，当你设置 `Image.Source` 属性时，WPF 内部执行以下步骤：

1. **URI 解析**：使用 `BaseUri` 将相对路径转换为绝对路径
2. **有效性检查**：通过 `IProvidePropertyFallback` 检查值是否有效，无效则返回 `null`
3. **异步加载**：在后台线程加载图像数据
4. **解码**：将图像数据解码为原始像素格式
5. **DPI 适配**：根据当前显示器的 DPI 缩放图像
6. **上传 GPU**：将解码后的像素数据上传到 GPU 显存
7. **布局更新**：触发 `MeasureOverride` 和 `ArrangeOverride`
8. **渲染**：触发 `OnRender` 将图像绘制到屏幕
9. **异常处理**：如果任何步骤失败，触发 `ImageFailed` 事件

### 3.2 DPI 变更处理流程

当 Image 被拖动到不同 DPI 的显示器时：

1. 系统触发 `DpiChanged` 事件
2. 调用 `OnDpiChanged` 方法
3. 重新计算图像的渲染尺寸
4. 重新布局和渲染图像
5. 如果支持，加载更高分辨率的图像资源

## 四、工业场景常见问题与解决方案

### 4.1 多显示器不同 DPI 下图像模糊

**问题**：将窗口从 100% 缩放的显示器拖动到 200% 缩放的显示器时，图像变得模糊

**根本原因**：Image 默认只加载一次图像，不会根据 DPI 变更重新加载更高分辨率的版本

**解决方案**：重写 `OnDpiChanged` 方法，动态加载对应分辨率的图像：

csharp:

```c#
public class DpiAwareImage : Image
{
    protected override void OnDpiChanged(DpiScale oldDpi, DpiScale newDpi)
    {
        base.OnDpiChanged(oldDpi, newDpi);
        
        if (Source is BitmapImage bitmap && bitmap.UriSource != null)
        {
            // 提取基础路径
            string originalPath = bitmap.UriSource.OriginalString;
            string basePath = originalPath.Contains("@") 
                ? originalPath.Substring(0, originalPath.LastIndexOf('@')) 
                : Path.GetFileNameWithoutExtension(originalPath);
            string extension = Path.GetExtension(originalPath);
            
            // 根据 DPI 选择对应的分辨率
            string suffix = newDpi.DpiScaleX >= 2.0 ? "@2x" : "";
            string newPath = $"{basePath}{suffix}{extension}";
            
            // 加载新图像
            try
            {
                Source = new BitmapImage(new Uri(newPath, UriKind.RelativeOrAbsolute));
            }
            catch
            {
                // 加载失败时保持原图像
            }
        }
    }
}
```

### 4.2 图像加载失败无提示

**问题**：图像文件不存在或损坏时，Image 显示空白，没有任何提示

**解决方案**：监听 `ImageFailed` 事件，显示默认占位图和错误提示：

xaml:

```xaml
<Style TargetType="Image">
    <Setter Property="Template">
        <Setter.Value>
            <ControlTemplate TargetType="Image">
                <Grid>
                    <Image x:Name="PART_Image"
                           Source="{TemplateBinding Source}"
                           Stretch="{TemplateBinding Stretch}"
                           StretchDirection="{TemplateBinding StretchDirection}"
                           ImageFailed="Image_ImageFailed"/>
                    
                    <!-- 加载失败占位图 -->
                    <Border x:Name="PART_ErrorPlaceholder"
                            Background="#F5F5F5"
                            BorderBrush="#E0E0E0"
                            BorderThickness="1"
                            Visibility="Collapsed">
                        <StackPanel HorizontalAlignment="Center" VerticalAlignment="Center">
                            <TextBlock Text="❌" FontSize="24" HorizontalAlignment="Center"/>
                            <TextBlock Text="图像加载失败" FontSize="12" Foreground="Gray" Margin="0,5,0,0"/>
                        </StackPanel>
                    </Border>
                </Grid>
                
                <ControlTemplate.Triggers>
                    <Trigger Property="Tag" Value="Error">
                        <Setter TargetName="PART_Image" Property="Visibility" Value="Collapsed"/>
                        <Setter TargetName="PART_ErrorPlaceholder" Property="Visibility" Value="Visible"/>
                    </Trigger>
                </ControlTemplate.Triggers>
            </ControlTemplate>
        </Setter.Value>
    </Setter>
</Style>
```

csharp:

```c#
private void Image_ImageFailed(object sender, ExceptionRoutedEventArgs e)
{
    ((Image)((FrameworkElement)sender).TemplatedParent).Tag = "Error";
}
```

### 4.3 动态加载 XAML 时相对路径解析失败

**问题**：通过 `XamlReader.Load()` 动态加载包含 Image 的 XAML 时，相对路径的图像无法加载

**根本原因**：动态加载的 XAML 没有设置 `BaseUri`

**解决方案**：手动设置 Image 的 `BaseUri` 属性：

csharp:

```c#
// 动态加载 XAML
var xaml = @"<Image Source=""Images/icon.png""/>";
var image = (Image)XamlReader.Parse(xaml);

// 设置基 URI
image.BaseUri = new Uri("pack://application:,,,/YourAssembly;component/");

// 添加到界面
grid.Children.Add(image);
```

## 五、工业级 Image 控件完整实现

以下是整合了**DPI 适配、错误处理、加载状态显示**的工业级 Image 控件完整代码：

csharp:

```c#
using System;
using System.IO;
using System.Windows;
using System.Windows.Controls;
using System.Windows.Media;
using System.Windows.Media.Imaging;

namespace Industrial.Controls
{
    /// <summary>
    /// 工业级 Image 控件
    /// 支持：DPI 自动适配、图像加载失败处理、加载状态显示
    /// </summary>
    public class IndustrialImage : Image
    {
        #region 依赖属性
        /// <summary>
        /// 加载失败占位图依赖属性
        /// </summary>
        public static readonly DependencyProperty ErrorPlaceholderProperty = DependencyProperty.Register(
            nameof(ErrorPlaceholder),
            typeof(ImageSource),
            typeof(IndustrialImage),
            new PropertyMetadata(null));

        /// <summary>
        /// 是否显示加载状态依赖属性
        /// </summary>
        public static readonly DependencyProperty ShowLoadingProperty = DependencyProperty.Register(
            nameof(ShowLoading),
            typeof(bool),
            typeof(IndustrialImage),
            new PropertyMetadata(true));
        #endregion

        #region CLR 属性
        /// <summary>
        /// 获取或设置加载失败占位图
        /// </summary>
        public ImageSource ErrorPlaceholder
        {
            get => (ImageSource)GetValue(ErrorPlaceholderProperty);
            set => SetValue(ErrorPlaceholderProperty, value);
        }

        /// <summary>
        /// 获取或设置是否显示加载状态
        /// </summary>
        public bool ShowLoading
        {
            get => (bool)GetValue(ShowLoadingProperty);
            set => SetValue(ShowLoadingProperty, value);
        }
        #endregion

        #region 私有字段
        private bool _isLoading;
        #endregion

        #region 构造函数
        public IndustrialImage()
        {
            // 监听图像加载失败事件
            ImageFailed += IndustrialImage_ImageFailed;
        }
        #endregion

        #region 重写方法
        protected override void OnSourceChanged(DependencyPropertyChangedEventArgs e)
        {
            base.OnSourceChanged(e);
            
            if (e.NewValue != null && e.NewValue != e.OldValue)
            {
                _isLoading = true;
                InvalidateVisual();
            }
        }

        protected override void OnDpiChanged(DpiScale oldDpi, DpiScale newDpi)
        {
            base.OnDpiChanged(oldDpi, newDpi);
            
            // 自动加载对应分辨率的图像
            if (Source is BitmapImage bitmap && bitmap.UriSource != null)
            {
                LoadHighResImage(bitmap.UriSource, newDpi.DpiScaleX);
            }
        }

        protected override void OnRender(DrawingContext dc)
        {
            base.OnRender(dc);
            
            // 显示加载状态
            if (_isLoading && ShowLoading)
            {
                var text = new FormattedText(
                    "加载中...",
                    System.Globalization.CultureInfo.CurrentCulture,
                    FlowDirection.LeftToRight,
                    new Typeface("Arial"),
                    12,
                    Brushes.Gray,
                    VisualTreeHelper.GetDpi(this).PixelsPerDip);
                
                dc.DrawText(text, new Point(
                    (ActualWidth - text.Width) / 2,
                    (ActualHeight - text.Height) / 2));
            }
        }
        #endregion

        #region 私有方法
        private void IndustrialImage_ImageFailed(object sender, ExceptionRoutedEventArgs e)
        {
            _isLoading = false;
            
            // 显示加载失败占位图
            if (ErrorPlaceholder != null)
            {
                Source = ErrorPlaceholder;
            }
            
            InvalidateVisual();
        }

        private void LoadHighResImage(Uri originalUri, double dpiScale)
        {
            try
            {
                string originalPath = originalUri.OriginalString;
                string basePath = originalPath.Contains("@") 
                    ? originalPath.Substring(0, originalPath.LastIndexOf('@')) 
                    : Path.GetFileNameWithoutExtension(originalPath);
                string extension = Path.GetExtension(originalPath);
                
                string suffix = dpiScale >= 2.0 ? "@2x" : "";
                string newPath = $"{basePath}{suffix}{extension}";
                
                if (newPath != originalPath)
                {
                    Source = new BitmapImage(new Uri(newPath, UriKind.RelativeOrAbsolute));
                }
            }
            catch
            {
                // 加载失败时保持原图像
            }
        }
        #endregion
    }
}
```

**使用示例**：

xml:

```xaml
<local:IndustrialImage Source="product.jpg"
                       ErrorPlaceholder="/Images/default.png"
                       ShowLoading="True"
                       Stretch="Uniform"
                       ClipToBounds="True"/>
```

## 六、总结

.NET 8 版本的 Image 控件相比旧版本增加了很多重要功能，特别是 **DPI 变更支持**和**图像加载失败事件**，完美解决了工业系统中多显示器和高 DPI 场景的常见问题。

### 核心新增功能价值

1. **`ImageFailed` 事件**：终于可以优雅地处理图像加载异常，避免界面空白
2. **`DpiChanged` 事件**：支持动态 DPI 变更，解决多显示器不同缩放比例下的模糊问题
3. **`IUriContext` 接口**：明确了相对 URI 的解析机制，解决动态加载 XAML 时的路径问题

### 工业场景最佳实践

1. 永远监听 `ImageFailed` 事件，显示默认占位图
2. 重写 `OnDpiChanged` 方法，实现多分辨率图像自动加载
3. 动态加载 XAML 时手动设置 `BaseUri` 属性
4. 对于相机实时画面，仍然使用 `WriteableBitmap` 获得最高性能
