### 2. 日志配置 Configs/NLog.config

xaml:

```xaml
<?xml version="1.0" encoding="utf-8" ?>
<nlog xmlns="http://www.nlog-project.org/schemas/NLog.xsd"
      xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
      autoReload="true"
      internalLogLevel="Error"
      internalLogFile="Logs/nlog-internal.log">

  <targets>
    <!-- 文件日志 -->
    <target xsi:type="File" 
            name="file" 
            fileName="Logs/${shortdate}.log"
            layout="${longdate} | ${level:uppercase=true} | ${logger} | ${message} ${exception:format=ToString}"
            archiveAboveSize="10485760"
            archiveNumbering="Sequence"
            maxArchiveFiles="30"/>

    <!-- 控制台日志 -->
    <target xsi:type="Console" 
            name="console" 
            layout="${longdate} | ${level:uppercase=true} | ${message}"/>
  </targets>

  <rules>
    <logger name="*" minlevel="Debug" writeTo="file,console" />
  </rules>
</nlog>
```

### 5. 数据库上下文 08_Data/DatabaseContext.cs

csharp:

```c#
using System.Data.SQLite;
using Dapper;

namespace IndustrialVisionTemplate.Data
{
    public class DatabaseContext
    {
        private readonly string _connectionString;

        public DatabaseContext(string connectionString)
        {
            _connectionString = connectionString;
            InitializeDatabase();
        }

        private void InitializeDatabase()
        {
            using var conn = new SQLiteConnection(_connectionString);
            conn.Open();
            
            conn.Execute(@"
                CREATE TABLE IF NOT EXISTS ProductRecords (
                    Id INTEGER PRIMARY KEY AUTOINCREMENT,
                    Barcode TEXT NOT NULL,
                    IsOk INTEGER NOT NULL,
                    DefectCount INTEGER NOT NULL,
                    CreateTime TEXT NOT NULL,
                    ImagePath TEXT
                )");
        }

        public SQLiteConnection GetConnection()
        {
            return new SQLiteConnection(_connectionString);
        }
    }
}
```

## 三、一键下载与运行步骤

### 1. 创建解决方案

1. 打开 Visual Studio 2022
2. 新建项目 → 选择 "WPF 应用 (.NET)" → 名称输入`IndustrialVisionTemplate`
3. 按照上面的结构创建所有文件夹和文件
4. 复制上面的代码到对应文件中

### 2. 还原 NuGet 包

- 右键解决方案 → 选择 "还原 NuGet 包"
- 等待所有包下载完成

### 3. 首次运行测试

- 按 F5 运行项目
- 你会看到一个完整的工业上位机主界面
- 点击 "开始" 按钮，系统会模拟运行检测流程
- 底部状态栏会显示运行状态和统计数据

## 五、已集成的工业级特性

✅ **完整分层架构**：严格遵循依赖倒置原则

✅ **硬件抽象层**：换硬件只需要改实现类

✅ **CT 最优检测流程**：分级等待 + 提前发 PLC 信号

✅ **生产级日志系统**：NLog 日志，自动归档

✅ **SQLite 数据库**：自动创建表，保存检测记录

✅ **配置管理系统**：JSON 配置文件，支持热重载

✅ **完整异常处理**：所有硬件操作都有异常保护

✅ **资源自动释放**：IDisposable 模式，防止内存泄漏

✅ **MVVM+Prism**：依赖注入 + 事件聚合 + 区域导航

## 六、下一步开发建议

1. **先跑通模拟流程**：不接硬件的情况下，先让模拟流程正常运行
2. **逐步接入硬件**：先接 PLC，再接相机，最后接算法
3. **添加 IO 监控界面**：使用我之前给你的 IO 监控布局代码
4. **添加产线拓扑图**：使用我之前给你的拓扑图布局代码
5. **添加报警系统**：实现声光报警和报警记录功能
