# 006007001_WPF `Path` 路径类官方深度解析 + 实战案例

`Path` 是 WPF 矢量图形体系中 `Shape` 抽象基类的**密封派生类**，也是整个 Shape 体系中功能最强大、灵活度最高的图形控件。它不局限于单一基础形状，支持直线、折线、多边形、贝塞尔曲线、圆弧、布尔组合等任意 2D 几何图形，是自定义图标、不规则轮廓、复杂工件边界、平滑曲线的标准实现方案。

简单来说：前面介绍的 `Line`、`Rectangle`、`Ellipse`、`Polyline`、`Polygon` 能实现的所有图形，`Path` 全部可以实现；而它们实现不了的复杂曲线、组合图形、布尔运算，`Path` 同样可以完成。

------

## 一、官方类定义与继承体系

### 1. 基础元信息

- **命名空间**：`System.Windows.Shapes`
- **程序集**：`PresentationFramework.dll`（WPF 核心框架程序集）
- **类修饰符**：`public sealed`（公共密封类，禁止被其他类继承）
- **设计定位**：通用矢量路径容器，承载任意 2D 几何图形，是 Shape 体系的集大成者

### 2. 完整继承链

plaintext:

```tex
System.Object
  └─ System.Windows.Threading.DispatcherObject
     └─ System.Windows.DependencyObject
        └─ System.Windows.Media.Visual
           └─ System.Windows.UIElement
              └─ System.Windows.FrameworkElement
                 └─ System.Windows.Shapes.Shape
                    └─ System.Windows.Shapes.Path
```

- 继承 `Shape`：所有填充、描边、拉伸、命中测试能力全部原生复用；
- `Path` 自身：仅新增一个 `Data` 依赖属性作为几何数据容器，通过承载不同的几何对象实现任意形状。

### 3. 官方类核心成员声明

csharp:

```c#
public sealed class Path : Shape
{
    // 核心依赖属性标识符
    public static readonly DependencyProperty DataProperty;

    // 公共无参构造函数
    public Path();

    // 核心属性：路径几何数据
    public Geometry Data { get; set; }

    // 重写 Shape 抽象属性
    protected override Geometry DefiningGeometry { get; }
}
```

#### 关键结构解读

1. **极简的类结构**：整个类仅新增 1 个核心依赖属性，所有外观、布局、交互逻辑全部复用基类；
2. **数据驱动形状**：形状完全由 `Data` 属性的几何对象决定，`Path` 本身只是几何数据的渲染载体；
3. **极高灵活度**：`Data` 接受所有 `Geometry` 子类，从基础矩形到复杂贝塞尔曲线、组合几何均可承载；
4. **密封类设计**：禁止继承，保证渲染逻辑稳定，便于框架做性能优化。

## 二、核心属性深度解析

### 1. 灵魂属性：Data

这是 `Path` 最核心、唯一新增的属性，决定了路径的形状与轮廓。

| 属性项       | 详细说明                                                     |
| :----------- | :----------------------------------------------------------- |
| **类型**     | `System.Windows.Media.Geometry`（所有几何类的抽象基类）      |
| **默认值**   | `null`（无几何数据，图形不可见）                             |
| **依赖属性** | 基于 `DataProperty` 注册，原生支持数据绑定、动画、变更自动重绘 |
| **核心作用** | 作为几何数据容器，传入不同的 Geometry 子类即可呈现不同形状   |

#### Geometry 主要子类体系

`Geometry` 是所有 2D 几何数据的抽象基类，常用子类分为 5 大类：

| 分类         | 代表类                                             | 用途说明                                                     |
| :----------- | :------------------------------------------------- | :----------------------------------------------------------- |
| **基础几何** | `RectangleGeometry``EllipseGeometry``LineGeometry` | 对应矩形、椭圆、直线等基础形状，功能等同于对应 Shape 控件    |
| **路径几何** | `PathGeometry`                                     | 最灵活的几何类，支持任意组合的直线、贝塞尔曲线、圆弧，是复杂形状的首选 |
| **组合几何** | `GeometryGroup`                                    | 将多个几何组合为一个整体，共用 FillRule，适合多部分拼接的图形 |
| **布尔几何** | `CombinedGeometry`                                 | 对两个几何执行布尔运算：合并、相交、排除、异或，实现挖洞、裁剪效果 |
| **轻量几何** | `StreamGeometry`                                   | 只读轻量版 PathGeometry，内存占用更低、渲染更快，适合静态复杂图形 |

### 2. 继承自 Shape 的全部属性

`Path` 完整继承 `Shape` 基类的所有外观属性，闭合与开放图形均支持：

- **填充类**：`Fill`、`FillRule`（影响组合几何的填充效果）
- **描边类**：`Stroke`、`StrokeThickness`、`StrokeLineJoin`、`StrokeStartLineCap`、`StrokeEndLineCap`、`StrokeDashArray`、`StrokeDashOffset`、`StrokeMiterLimit`
- **布局类**：`Stretch`、`RenderedGeometry`、`GeometryTransform`

> 注意：开放路径（未闭合）设置 `Fill` 后，会自动连接起点与终点形成闭合区域再填充，行为与 `Polyline` 一致。

### 3. 核心重写属性：DefiningGeometry

csharp:

```c#
protected override Geometry DefiningGeometry { get; }
```

- 官方实现非常简单：直接返回 `Data` 属性的值；如果 `Data` 为 `null`，则返回 `Geometry.Empty`；
- 设计思想：**形状完全交由几何数据定义**，`Path` 只负责作为 UI 元素承接渲染与交互，职责单一。

## 三、核心功能与底层原理

### 1. 核心能力

1. **绘制任意 2D 矢量图形**：从基础的点、线、面，到三次贝塞尔曲线、圆弧、椭圆弧，再到复杂的组合图形、布尔运算图形，全部支持；
2. **开放 / 闭合图形通吃**：既可以绘制开放的曲线、轨迹，也可以绘制闭合的填充区域；
3. **矢量无损缩放**：所有图形均为矢量数据，任意放大缩小无锯齿、不失真；
4. **精确命中测试**：基于几何边界精确判断点击，空白区域不会误触发；
5. **完全数据驱动**：`Data` 是依赖属性，可绑定、可动画、可动态替换，完美适配 MVVM 架构；
6. **高性能渲染**：底层走 WPF 可视化层 DirectX 硬件加速，复杂图形性能远优于多个基础 Shape 拼接。

### 2. 渲染流程

`Path` 没有重写布局渲染方法，完全复用 `Shape` 基类标准流水线：

1. 测量阶段：读取 `Data` 几何的边界，结合描边厚度、拉伸模式计算期望尺寸；
2. 排列阶段：根据布局空间计算缩放变换，生成 `GeometryTransform`；
3. 渲染阶段：应用变换后，依次执行填充、描边绘制，硬件加速输出；
4. 属性变更：`Data` 或描边填充属性变化时，自动触发重绘。

## 四、两种核心使用方法

### 方法一：几何对象组合法

通过显式声明 `Geometry` 子类对象组合出形状，适合结构化、动态生成、需要程序控制的场景，可读性强，便于代码操作。

#### XAML 示例（GeometryGroup 组合）

xaml:

```xaml
<Canvas Width="200" Height="200">
    <Path Stroke="Black" StrokeThickness="2" Fill="LightBlue">
        <Path.Data>
            <!-- 几何组：包含一个矩形 + 一个圆形 -->
            <GeometryGroup FillRule="EvenOdd">
                <RectangleGeometry Rect="20,20 160,160" RadiusX="10" RadiusY="10"/>
                <EllipseGeometry Center="100,100" RadiusX="50" RadiusY="50"/>
            </GeometryGroup>
        </Path.Data>
    </Path>
</Canvas>
```

#### C# 动态生成示例

csharp:

```c#
Path path = new Path();
path.Stroke = Brushes.Red;
path.StrokeThickness = 2;
path.Fill = Brushes.Transparent;

// 创建路径几何
PathGeometry geo = new PathGeometry();
PathFigure figure = new PathFigure();
figure.StartPoint = new Point(0, 100);
figure.Segments.Add(new LineSegment(new Point(100, 0), true));
figure.Segments.Add(new LineSegment(new Point(200, 100), true));
figure.IsClosed = true;
geo.Figures.Add(figure);

path.Data = geo;
```

### 方法二：路径标记语法（迷你语言）

WPF 提供了一套简洁的字符串语法来描述路径，直接赋值给 `Data` 属性，**是静态复杂图形最常用的写法**，语法简洁、代码量少，设计软件（如 Blend、Figma）导出的矢量图通常都是这种格式。

#### 常用命令速查表

| 命令                             | 全称             | 功能说明                       | 示例                    |
| :------------------------------- | :--------------- | :----------------------------- | :---------------------- |
| `M x,y`                          | Move             | 移动起点，不绘制线条           | `M 10,10`               |
| `L x,y`                          | Line             | 从当前点画直线到目标点         | `L 100,10`              |
| `H x`                            | Horizontal       | 画水平线                       | `H 200`                 |
| `V y`                            | Vertical         | 画垂直线                       | `V 50`                  |
| `C x1,y1 x2,y2 x,y`              | Cubic Bezier     | 画三次贝塞尔曲线（两个控制点） | `C 10,10 50,100 100,50` |
| `Q x1,y1 x,y`                    | Quadratic Bezier | 画二次贝塞尔曲线（一个控制点） | `Q 50,0 100,50`         |
| `A rx,ry rot largeArc sweep x,y` | Arc              | 画椭圆圆弧                     | `A 50,50 0 0 1 100,50`  |
| `Z`                              | Close            | 闭合路径，自动连接起点与终点   | `Z`                     |

> 语法规则：
>
> - 命令**大写**表示绝对坐标，**小写**表示相对当前点的偏移量；
>
> - 多个命令用空格分隔，坐标逗号分隔；
>
>   示例：`M 0,50 L 50,0 L 100,50 Z`表示一个三角形。

#### 路径语法示例

xaml:

```xaml
<!-- 心形图案：纯路径语法实现 -->
<Path Data="M 50,20 C 20,0 0,30 50,70 C 100,30 80,0 50,20 Z"
      Fill="Red"
      Stroke="DarkRed"
      StrokeThickness="1"/>
```

## 五、实战场景案例

### 案例 1：基础几何组合（带孔矩形）

利用 `CombinedGeometry` 的排除运算，实现矩形挖圆孔的效果，是工件镂空、视窗开孔的常用手法。

xaml:

```xaml
<Canvas Width="200" Height="200" Background="#F5F5F5">
    <Path Stroke="SteelBlue" StrokeThickness="2" Fill="#334682B4">
        <Path.Data>
            <!-- 布尔运算：大矩形 排除 小圆，形成带孔矩形 -->
            <CombinedGeometry GeometryCombineMode="Exclude">
                <CombinedGeometry.Geometry1>
                    <RectangleGeometry Rect="20,20 160,160" RadiusX="8" RadiusY="8"/>
                </CombinedGeometry.Geometry1>
                <CombinedGeometry.Geometry2>
                    <EllipseGeometry Center="100,100" RadiusX="40" RadiusY="40"/>
                </CombinedGeometry.Geometry2>
            </CombinedGeometry>
        </Path.Data>
    </Path>
</Canvas>
```

> `GeometryCombineMode` 支持 4 种模式：`Union`（合并）、`Intersect`（相交）、`Exclude`（排除）、`Xor`（异或）。

### 案例 2：三次贝塞尔平滑曲线

绘制平滑的运动轨迹、工艺曲线，是 Polyline 折线的升级方案，曲线更自然、更贴合真实物理轨迹。

xaml:

```xaml
<Canvas Width="500" Height="200" Background="#1E1E1E">
    <!-- 平滑贝塞尔轨迹 -->
    <Path Data="M 30,150 C 100,50 200,200 300,100 S 450,30 470,120"
          Stroke="#00FF7F"
          StrokeThickness="2"
          Fill="Transparent"
          StrokeLineJoin="Round"/>
</Canvas>
```

> `S` 命令是平滑三次贝塞尔简写，自动镜像前一个控制点，实现连续平滑的多段曲线。

### 案例 3：工业自定义箭头（实心方向标）

用闭合路径实现实心箭头，比 Line+Polygon 拼接更简洁，描边填充统一，适合物料流向、工序流转指示。

xaml:

```xaml
<Canvas Width="200" Height="80">
    <!-- 向右实心箭头 -->
    <Path Data="M 0,25 L 100,25 L 100,10 L 160,40 L 100,70 L 100,55 L 0,55 Z"
          Fill="#32CD32"
          Stroke="#228B22"
          StrokeThickness="1.5"
          StrokeLineJoin="Round"/>
</Canvas>
```

用路径语法绘制异形工件轮廓，配合半透明填充作为检测 ROI，比 Polygon 更灵活，可包含圆弧段。

### 案例 5：自定义状态图标（工位指示灯底座）

组合多个基础几何，实现复杂的自定义 UI 元素，完全矢量缩放，适配任意 DPI。

xaml:

```xaml

    <!-- 指示灯底座 -->
    <Path Stroke="#555" StrokeThickness="1" Fill="#DDD">
        <Path.Data>
            <GeometryGroup>
                <RectangleGeometry Rect="15,40 30,35" RadiusX="3" RadiusY="3"/>

</Canvas>
```

### 案例 6：C# 动态生成波形路径

适合算法输出曲线、实时波形的场景，用 `StreamGeometry` 实现高性能绘制。

csharp:

```c#
/// <summary>
/// 生成正弦波形 Path
/// </summary>
public Path CreateSinePath(double amplitude, double period, double length)
{
    Path path = new Path();
    path.Stroke = Brushes.RoyalBlue;
    path.StrokeThickness = 2;
    path.Fill = Brushes.Transparent;

    StreamGeometry geo = new StreamGeometry();
    using (StreamGeometryContext ctx = geo.Open())
    {
        ctx.BeginFigure(new Point(0, amplitude), false, false);
        
        for (double x = 0; x <= length; x += 2)
        {
            double y = amplitude * Math.Sin(x * 2 * Math.PI / period) + amplitude;
            ctx.LineTo(new Point(x, y), true, false);
        }
        
        geo.Freeze(); // 冻结提升性能
    }

    path.Data = geo;
    return path;
}
```

## 六、选型对比与最佳实践

### 1. Path 与其他 Shape 控件的选型

| 场景                             | 推荐控件                  | 原因                               |
| :------------------------------- | :------------------------ | :--------------------------------- |
| 简单矩形、椭圆、直线             | 对应基础 Shape            | 语义清晰，代码简洁，开销更低       |
| 连续折线、轨迹                   | `Polyline`                | 顶点集合驱动，适合直线段连续轨迹   |
| 闭合多边形                       | `Polygon`                 | 语义明确，自动闭合，适合纯直线选区 |
| 含曲线、圆弧、布尔组合的复杂图形 | `Path`                    | 唯一选择，灵活度最高，功能最全     |
| 静态大量顶点的复杂图形           | `Path` + `StreamGeometry` | 性能最优，内存占用最低             |

### 2. 避坑与优化

1. **路径语法大小写**：大写命令是绝对坐标，小写是相对坐标，混用容易导致形状异常，建议统一风格。
2. **填充与闭合**：需要填充的图形务必用 `Z` 命令显式闭合，避免填充异常；开放路径设置 Fill 会自动隐式闭合。
3. **性能优化**：
   - 静态复杂图形优先使用 `StreamGeometry` 并调用 `Freeze()` 冻结，性能比 `PathGeometry` 高 30%+；
   - 能用单个 Path 组合实现的图形，不要用多个 Shape 拼接，渲染次数更少，性能更优。
4. **布尔运算注意**：`CombinedGeometry` 只能组合两个几何，多个几何运算请嵌套使用。
5. **拉伸适配**：配合 `Stretch="Uniform"` 可让复杂图标自适应容器大小，保持宽高比不变形。
