# 999999004_工业级多服务批量启动脚本

专为**工业上位机 / 服务器集群**设计，支持**按顺序启动、重复启动检查、自动等待、详细日志、错误处理**，解决手动逐个启动服务的麻烦，可直接设置为开机自启。

------

## 完整脚本（直接复制使用）

batch：

```bat
@echo off
chcp 65001 >nul
setlocal enabledelayedexpansion

:: ==============================================
:: 【配置区】只需要修改这里，下面逻辑不用动
:: ==============================================
title 多服务批量启动器
set "LOG_FILE=%~dp0service_start.log"  :: 日志文件路径（脚本所在目录）
set "GLOBAL_WAIT=3"  :: 每个服务启动后的默认等待时间（秒）
set "RETRY_COUNT=2"  :: 启动失败重试次数

:: 服务列表配置（按启动顺序排列，依赖的服务放前面）
:: 格式："服务名称|进程名|启动路径|启动参数|等待时间"
:: 注意：用 | 分隔，路径有空格必须加双引号
set "SERVICES[0]=MySQL数据库|mysqld.exe|D:\MySQL\bin\mysqld.exe|--defaults-file=D:\MySQL\my.ini|5"
set "SERVICES[1]=Redis缓存|redis-server.exe|D:\Redis\redis-server.exe|D:\Redis\redis.conf|3"
set "SERVICES[2]=RabbitMQ消息队列|erl.exe|D:\RabbitMQ\sbin\rabbitmq-server.bat||5"
set "SERVICES[3]=业务服务1|BusinessService1.exe|D:\Services\BusinessService1.exe||3"
set "SERVICES[4]=业务服务2|BusinessService2.exe|D:\Services\BusinessService2.exe||3"
set "SERVICES[5]=日志服务|LogService.exe|D:\Services\LogService.exe||2"

:: ==============================================
:: 【初始化】
:: ==============================================
call :LOG "=============================================="
call :LOG "多服务批量启动器 开始执行"
call :LOG "启动时间：%date% %time%"
call :LOG "=============================================="
echo.

:: ==============================================
:: 【检查管理员权限】（可选，需要管理员权限时打开）
:: ==============================================
:: fltmc >nul 2>&1 || (
::     call :LOG "请求管理员权限..."
::     powershell -Command "Start-Process cmd -ArgumentList '/c ""%~f0""' -Verb RunAs"
::     exit /b
:: )

:: ==============================================
:: 【核心逻辑：按顺序启动所有服务】
:: ==============================================
set "SUCCESS_COUNT=0"
set "FAIL_COUNT=0"
set "SKIP_COUNT=0"

:: 遍历服务列表
for /l %%i in (0,1,5) do (
    :: 解析服务配置
    for /f "tokens=1-5 delims=|" %%a in ("!SERVICES[%%i]!") do (
        set "SERVICE_NAME=%%a"
        set "PROCESS_NAME=%%b"
        set "EXE_PATH=%%c"
        set "PARAMS=%%d"
        set "WAIT_TIME=%%e"
        
        :: 如果没有指定等待时间，使用全局默认值
        if "!WAIT_TIME!"=="" set "WAIT_TIME=%GLOBAL_WAIT%"
        
        call :LOG "----------------------------------------------"
        call :LOG "正在启动：!SERVICE_NAME!"
        call :LOG "进程名：!PROCESS_NAME!"
        call :LOG "启动路径：!EXE_PATH!"
        if not "!PARAMS!"=="" call :LOG "启动参数：!PARAMS!"
        
        :: 检查服务是否已经在运行
        call :CHECK_PROCESS "!PROCESS_NAME!"
        if !errorlevel! equ 0 (
            call :LOG "⚠️  服务已在运行，跳过启动"
            set /a SKIP_COUNT+=1
            continue
        )
        
        :: 检查启动文件是否存在
        if not exist !EXE_PATH! (
            call :LOG "❌ 启动文件不存在：!EXE_PATH!"
            set /a FAIL_COUNT+=1
            continue
        )
        
        :: 启动服务（带重试）
        set "START_SUCCESS=false"
        for /l %%r in (1,1,%RETRY_COUNT%) do (
            call :LOG "  第%%r次尝试启动..."
            
            :: 后台启动服务，不显示窗口
            start /b /min "" !EXE_PATH! !PARAMS! >nul 2>&1
            
            :: 等待服务启动
            ping -n !WAIT_TIME! 127.0.0.1 >nul
            
            :: 检查是否启动成功
            call :CHECK_PROCESS "!PROCESS_NAME!"
            if !errorlevel! equ 0 (
                set "START_SUCCESS=true"
                goto :START_OK
            )
        )
        
        :START_OK
        if "!START_SUCCESS!"=="true" (
            call :LOG "✅ 启动成功"
            set /a SUCCESS_COUNT+=1
        ) else (
            call :LOG "❌ 启动失败（重试%RETRY_COUNT%次）"
            set /a FAIL_COUNT+=1
        )
    )
)

:: ==============================================
:: 【启动结果汇总】
:: ==============================================
echo.
call :LOG "=============================================="
call :LOG "所有服务启动完成！"
call :LOG "成功：%SUCCESS_COUNT% 个"
call :LOG "失败：%FAIL_COUNT% 个"
call :LOG "跳过：%SKIP_COUNT% 个"
call :LOG "详细日志：%LOG_FILE%"
call :LOG "=============================================="
echo.
echo 按任意键退出...
pause >nul

endlocal
exit /b 0

:: ==============================================
:: 【工具函数：检查进程是否存在】
:: ==============================================
:CHECK_PROCESS
set "PROC_NAME=%~1"
tasklist /fi "imagename eq %PROC_NAME%" 2>nul | find /i "%PROC_NAME%" >nul
if %errorlevel% equ 0 (
    exit /b 0  :: 进程存在
) else (
    exit /b 1  :: 进程不存在
)

:: ==============================================
:: 【工具函数：统一日志输出】
:: ==============================================
:LOG
echo %~1
echo [%date% %time%] %~1 >> "%LOG_FILE%"
exit /b 0
```

## 🔥 核心功能说明

### 1. 按顺序启动（支持依赖关系）

服务按配置列表的顺序启动，依赖的服务（如数据库、缓存）放在前面，后面的服务会等前面的完全启动后再启动。

### 2. 自动防重复启动

启动前会检查进程是否已经在运行，如果已经运行则直接跳过，避免重复启动导致端口冲突或数据异常。

### 3. 启动失败自动重试

如果某个服务启动失败，会自动重试指定次数（默认 2 次），提高启动成功率。

### 4. 可配置等待时间

每个服务可以单独设置启动后的等待时间，确保服务完全初始化后再启动下一个。

### 5. 详细日志记录

自动生成日志文件，记录每个服务的启动时间、状态、错误信息，方便排查问题。

### 6. 后台启动

所有服务都在后台启动，不会弹出多个黑窗口，桌面更整洁。

## 使用方法

### 1. 修改配置区

只需要修改脚本开头的 **SERVICES 数组**，按照格式添加你自己的服务：

batch：

```bat
:: 格式："服务名称|进程名|启动路径|启动参数|等待时间"
set "SERVICES[0]=我的服务|MyService.exe|D:\MyService\MyService.exe||3"
```

- **服务名称**：自定义的显示名称
- **进程名**：任务管理器中显示的进程名称（带.exe 后缀）
- **启动路径**：服务可执行文件的完整路径
- **启动参数**：启动时需要传递的参数（没有就留空）
- **等待时间**：启动后等待的秒数（没有就留空，使用全局默认值）

### 2. 运行脚本

- 将脚本保存为 `start_services.bat`
- 双击运行即可
- 脚本会在当前目录生成 `service_start.log` 日志文件

### 3. 设置开机自启

1. 右键脚本 → 发送到 → 桌面快捷方式
2. 按下 `Win+R`，输入 `shell:startup`，打开启动文件夹
3. 将桌面快捷方式拖到启动文件夹中

## 常见问题解决

### 1. 服务启动失败

- 检查启动路径是否正确，路径有空格必须加双引号
- 检查服务是否需要管理员权限，打开脚本中的管理员权限检查代码
- 查看日志文件，看具体的错误信息
- 增加该服务的等待时间，确保有足够的时间初始化

### 2. 进程检查不准确

- 确保进程名填写正确（区分大小写吗？不，脚本用了 /find/i，不区分大小写）
- 如果有多个同名进程，脚本会认为服务已经在运行

### 3. 不想后台启动

将 `start /b /min ""` 改为 `start ""`，这样每个服务都会弹出自己的窗口。

### 4. 需要停止所有服务

可以配套使用这个停止脚本：

batch：

```bat
@echo off
chcp 65001 >nul
title 多服务批量停止器

set "SERVICES=mysqld.exe redis-server.exe erl.exe BusinessService1.exe BusinessService2.exe LogService.exe"

echo 正在停止所有服务...
for %%p in (%SERVICES%) do (
    taskkill /f /im %%p >nul 2>&1
    if %errorlevel% equ 0 (
        echo ✅ 已停止：%%p
    ) else (
        echo ⚠️  未运行：%%p
    )
)

echo.
echo 所有服务已停止
pause
```

## 扩展功能（可选）

### 1. 启动前先停止旧服务

在启动服务前添加这段代码，确保先停止旧的进程：

batch：

```bat
:: 先停止旧进程
call :LOG "  停止旧进程..."
taskkill /f /im "!PROCESS_NAME!" >nul 2>&1
ping -n 1 127.0.0.1 >nul
```

### 2. 启动完成后打开监控页面

在脚本最后添加：

batch：

```bat
:: 启动完成后打开监控页面
start "" "http://localhost:8080/monitor"
```

### 3. 发送邮件通知

如果需要启动失败时发送邮件通知，可以在失败分支添加：

batch：

```bat
:: 发送邮件通知（需要配置SMTP）
powershell -Command "Send-MailMessage -From 'alert@company.com' -To 'admin@company.com' -Subject '服务启动失败' -Body '!SERVICE_NAME! 启动失败' -SmtpServer 'smtp.company.com'"
```
