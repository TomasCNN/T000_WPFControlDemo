## 一、BAT 脚本基础入门

### 1. 什么是 BAT 脚本？

BAT 是 Windows 系统自带的批处理脚本语言，本质是**多条 DOS 命令的集合**，可以自动执行一系列重复操作。

- 后缀名：`.bat` 或 `.cmd`（两者几乎无区别）
- 运行方式：双击文件，或在 CMD 中输入文件名执行
- 核心优势：无需安装任何软件，Windows 原生支持，速度极快

### 2. 第一个 BAT 脚本

新建一个文本文件，改名为 `test.bat`，写入以下内容：

batch：

```bat
@echo off
echo 你好，这是我的第一个 BAT 脚本！
pause
```

双击运行，会弹出一个黑窗口，显示文字并等待你按任意键关闭。

**逐行解释**：

- `@echo off`：关闭命令回显（不显示执行的命令本身，只显示输出内容），**所有脚本第一行都要写这个**
- `echo 内容`：在控制台打印文字
- `pause`：暂停脚本执行，显示 "请按任意键继续..."，防止窗口一闪而过

### 3. 基本规则

- 不区分大小写（`echo` 和 `ECHO` 效果一样）

- 每行一条命令

- 注释用 `REM` 或 `::`（推荐用 `::`，更简洁）

  batch：

  ```bat
  :: 这是注释
  REM 这也是注释
  ```

  

- 路径有空格时必须用**双引号**包裹（非常重要！）

  batch：

  ```bat
  :: 错误写法（路径有空格会报错）
  copy C:\Program Files\test.exe D:\
  
  :: 正确写法
  copy "C:\Program Files\test.exe" "D:\My Files\"
  ```

## 二、核心语法：变量

### 1. 定义和使用变量

用 `set` 命令定义变量，用 `%变量名%` 引用变量：

batch：

```bat
@echo off
:: 定义变量
set name=工业上位机系统
set version=1.0.0

:: 引用变量
echo 项目名称：%name%
echo 版本号：%version%
pause
```

### 2. 特殊变量（系统内置）

| 变量名         | 说明                 | 示例值             |
| :------------- | :------------------- | :----------------- |
| `%date%`       | 当前日期             | `2026/05/12 周二`  |
| `%time%`       | 当前时间             | `15:30:25.12`      |
| `%cd%`         | 当前工作目录         | `D:\MyProject`     |
| `%errorlevel%` | 上一条命令的执行结果 | `0=成功，非0=失败` |
| `%~dp0`        | 脚本自身所在的目录   | `D:\Scripts\`      |

**示例：自动生成带时间戳的备份文件名**

batch：

```bat
@echo off
set backup_file=backup_%date:~0,4%%date:~5,2%%date:~8,2%_%time:~0,2%%time:~3,2%.zip
echo 备份文件名：%backup_file%
pause
```

### 3. 延迟扩展（最容易踩的坑）

当变量在 `if` 或 `for` 循环内部定义和使用时，必须开启**延迟扩展**，否则变量值不会更新。

**错误写法（变量不更新）**：

batch：

```bat
@echo off
set count=0
for %%i in (1,2,3) do (
    set /a count+=1
    echo 计数：%count%  :: 永远输出 0
)
pause
```

**正确写法（开启延迟扩展）**：

batch：

```bat
@echo off
setlocal enabledelayedexpansion  :: 开启延迟扩展
set count=0
for %%i in (1,2,3) do (
    set /a count+=1
    echo 计数：!count!  :: 用 ! 代替 % 引用变量
)
endlocal  :: 结束延迟扩展
pause
```

**记住**：只要在括号内部使用变量，就必须开启 `enabledelayedexpansion`，并用 `!变量名!` 引用。

## 三、核心语法：条件判断 `if`

### 1. 字符串比较

batch：

```bat
@echo off
set status=running

if "%status%"=="running" (
    echo 设备正在运行
) else if "%status%"=="stopped" (
    echo 设备已停止
) else (
    echo 设备状态未知
)
pause
```

### 2. 文件 / 目录存在判断

batch：

```bat
@echo off
:: 判断文件是否存在
if exist "D:\test.exe" (
    echo 文件存在
) else (
    echo 文件不存在
)

:: 判断目录是否存在
if exist "D:\MyProject\" (
    echo 目录存在
)
pause
```

### 3. 错误码判断

batch：

```bat
@echo off
copy test.exe D:\
if %errorlevel% equ 0 (
    echo 拷贝成功
) else (
    echo 拷贝失败，错误码：%errorlevel%
)
pause
```

### 4. 数字比较

| 运算符 | 说明     |
| :----- | :------- |
| `equ`  | 等于     |
| `neq`  | 不等于   |
| `lss`  | 小于     |
| `leq`  | 小于等于 |
| `gtr`  | 大于     |
| `geq`  | 大于等于 |

batch：

```bat
@echo off
set num=10
if %num% gtr 5 (
    echo 数字大于5
)
pause
```

## 四、核心语法：循环 `for`

### 1. 遍历数字

batch：

```bat
@echo off
:: 遍历 1 到 5
for /l %%i in (1,1,5) do (
    echo 数字：%%i
)
pause
```

语法：`for /l %%变量 in (起始值,步长,结束值) do (命令)`

### 2. 遍历文件（最常用）

batch：

```bat
@echo off
:: 遍历当前目录下所有 .txt 文件
for %%f in (*.txt) do (
    echo 找到文件：%%f
)
pause
```

**常用变体**：

batch：

```bat
:: 遍历所有 .exe 和 .dll 文件
for %%ext in (exe dll) do (
    for %%f in (*.%%ext) do (
        echo 找到文件：%%f
    )
)

:: 递归遍历子目录下的所有文件
for /r %%f in (*.txt) do (
    echo 找到文件：%%f
)
```

### 3. 遍历字符串

batch：

```bat
@echo off
:: 用逗号分隔字符串
for %%s in (苹果,香蕉,橙子) do (
    echo 水果：%%s
)
pause
```

## 五、核心语法：跳转与函数

### 1. 跳转 `goto`

用 `:标签名` 定义标签，用 `goto 标签名` 跳转到标签位置：

batch：

```bat
@echo off
echo 1. 启动程序
echo 2. 停止程序
echo 3. 退出
set /p choice=请输入选项：

if "%choice%"=="1" goto start
if "%choice%"=="2" goto stop
if "%choice%"=="3" goto exit

:start
echo 正在启动程序...
goto end

:stop
echo 正在停止程序...
goto end

:exit
echo 退出程序
exit /b

:end
pause
```

### 2. 函数调用

BAT 没有真正的函数，但可以用 `goto` 和 `exit /b` 模拟：

batch：

```bat
@echo off
:: 调用函数，传递参数
call :LOG "这是一条日志信息"
call :ADD 10 20
pause
exit /b  :: 主程序结束

:: 定义日志函数
:LOG
echo [%date% %time%] %~1
exit /b 0

:: 定义加法函数
:ADD
set /a result=%1+%2
echo %1 + %2 = %result%
exit /b 0
```

- 用 `call :函数名 参数1 参数2` 调用函数
- 函数内部用 `%1`、`%2` 接收参数
- 用 `exit /b 返回值` 退出函数

## 六、工业开发最常用命令

### 1. 文件操作

| 命令    | 功能              | 常用参数                                      |
| :------ | :---------------- | :-------------------------------------------- |
| `copy`  | 拷贝文件          | `/y` 覆盖不提示                               |
| `xcopy` | 拷贝目录和文件    | `/s` 拷贝子目录`/e` 拷贝空目录`/y` 覆盖不提示 |
| `del`   | 删除文件          | `/f` 强制删除`/q` 安静模式（不提示）          |
| `rmdir` | 删除目录          | `/s` 删除子目录和文件`/q` 安静模式            |
| `mkdir` | 创建目录          | -                                             |
| `ren`   | 重命名文件 / 目录 | -                                             |

**示例**：

batch：

```bat
:: 拷贝单个文件
copy /y "D:\test.exe" "E:\Backup\"

:: 拷贝整个目录
xcopy /s /e /y "D:\MyProject" "E:\Backup\MyProject\"

:: 删除所有 .log 文件
del /f /q "D:\Logs\*.log"

:: 创建多级目录
mkdir "D:\Project\bin\Debug"
```

### 2. 网络操作

| 命令      | 功能           | 常用参数                       |
| :-------- | :------------- | :----------------------------- |
| `ping`    | 测试网络连通性 | `-n 次数` 发送指定次数的数据包 |
| `net use` | 映射网络驱动器 | -                              |

**示例**：

batch：

```bat
:: 测试远程机器是否连通
ping -n 3 192.168.1.100
if %errorlevel% equ 0 (
    echo 远程机器在线
) else (
    echo 远程机器离线
)
```

### 3. 其他常用命令

| 命令    | 功能         |
| :------ | :----------- |
| `echo`  | 打印文字     |
| `pause` | 暂停执行     |
| `exit`  | 退出脚本     |
| `cls`   | 清屏         |
| `title` | 设置窗口标题 |

## 七、实战案例：VS 生成后远程同步脚本

结合你之前的需求，我们用上面学的语法，一步步写出完整的远程同步脚本：

### 步骤 1：总开关和初始化

batch：

```bat
@echo off
setlocal enabledelayedexpansion

:: 配置区
set "REMOTE_DEBUG_ENABLED=$(RemoteDebugEnabled)"
set "LOCAL_TARGET_DIR=$(TargetDir)"
set "REMOTE_MACHINE=$(RemoteDebugMachine)"
set "LOG_FILE=$(TargetDir)\remote_sync.log"

:: 总开关
if /i "%REMOTE_DEBUG_ENABLED%"=="false" (
    echo [INFO] 远程调试已关闭，跳过同步
    goto :eof
)
```

### 步骤 2：路径处理和日志函数

batch：

```bat
:: 日志函数
:LOG
echo %~1
echo [%date% %time%] %~1 >> "%LOG_FILE%"
exit /b 0

:: 拼接远程路径
set "LOCAL_PATH_NO_DRIVE=%LOCAL_TARGET_DIR:~3%"
set "REMOTE_TARGET_DIR=\\%REMOTE_MACHINE%\D\%LOCAL_PATH_NO_DRIVE%"
call :LOG "本地目录：%LOCAL_TARGET_DIR%"
call :LOG "远程目录：%REMOTE_TARGET_DIR%"
```

### 步骤 3：创建远程目录

batch：

```bat
call :LOG "正在创建远程目录..."
mkdir "%REMOTE_TARGET_DIR%" 2>nul
if %errorlevel% neq 0 (
    call :LOG "[ERROR] 无法创建远程目录"
    goto :ERROR_EXIT
)
```

### 步骤 4：自动拷贝所有文件

batch：

```bat
call :LOG "正在同步文件..."
for %%ext in (exe dll pdb) do (
    for %%f in ("%LOCAL_TARGET_DIR%\*.%%ext") do (
        copy /y "%%f" "%REMOTE_TARGET_DIR%" >nul 2>&1
        if !errorlevel! equ 0 (
            call :LOG "  ✓ %%~nxf"
        ) else (
            call :LOG "  ❌ %%~nxf"
        )
    )
)
```

### 步骤 5：结果处理

batch：

```bat
call :LOG "✅ 远程同步完成！"
endlocal
goto :eof

:ERROR_EXIT
call :LOG "❌ 远程同步失败！"
endlocal
exit /b 1
```

## 八、常见问题与技巧

### 1. 中文乱码问题

在脚本第一行添加：

batch：

```bat
chcp 65001 >nul
```

将控制台编码设置为 UTF-8，解决中文显示乱码。

### 2. 隐藏黑窗口

如果不想让脚本运行时弹出黑窗口，可以创建一个 VBS 脚本：

vbscript：

```bat
Set WshShell = CreateObject("WScript.Shell")
WshShell.Run "your_script.bat", 0, False
```

双击 VBS 文件运行，脚本会在后台执行。

### 3. 管理员权限运行

在脚本开头添加：

batch：

```bat
@echo off
:: 检查是否有管理员权限
fltmc >nul 2>&1 || (
    echo 请求管理员权限...
    powershell -Command "Start-Process cmd -ArgumentList '/c ""%~f0""' -Verb RunAs"
    exit /b
)
```

脚本会自动请求管理员权限运行。

### 4. 调试脚本

在脚本开头去掉 `@echo off`，或者添加 `echo on`，可以看到每一条执行的命令，方便排查问题。

## 九、学习路径建议

1. **先掌握基础**：变量、if、for、常用文件命令
2. **多写小脚本**：比如自动备份、清理日志、批量重命名
3. **结合实际场景**：修改和优化你正在用的 VS 生成后脚本
4. **查官方文档**：遇到不认识的命令，在 CMD 中输入 `命令 /?` 查看帮助（比如 `copy /?`）

BAT 脚本不需要学得多深，只要能解决工作中的自动化问题就够了。你现在已经掌握了工业开发中 90% 以上会用到的 BAT 知识，剩下的就是在实际项目中多练多用。
