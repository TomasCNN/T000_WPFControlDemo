# 006001005_WPF Shape 抽象基类实战案例

`Shape` 作为抽象基类，实战分为两个维度：一是直接使用其 6 个内置派生类（`Rectangle`/`Ellipse`/`Line` 等）快速实现工业绘图需求；二是继承 `Shape` 重写 `DefiningGeometry`，自定义工业专属图形（十字对位标记、箭头指示线等），复用基类全部布局、描边、绑定能力。

以下案例全部贴合视觉检测、运动控制、工位可视化等工控场景，可直接复制到项目中使用。

------

## 一、内置派生类基础实战（6 种工业高频场景）

### 1. Rectangle：检测 ROI 区域框

**工业场景**：AOI 检测的感兴趣区域、产品定位框、缺陷外框。

xaml:

```xaml
<Canvas SnapsToDevicePixels="True">
    <!-- 实线检测框：红色2像素描边，无填充 -->
    <Rectangle Canvas.Left="100" Canvas.Top="80"
               Width="200" Height="150"
               Stroke="Red" StrokeThickness="2"
               StrokeDashArray="4,2" /> <!-- 虚线框 -->

    <!-- 圆角选中框：绿色高亮，半透明填充 -->
    <Rectangle Canvas.Left="350" Canvas.Top="120"
               Width="120" Height="120"
               RadiusX="8" RadiusY="8"
               Stroke="LimeGreen" StrokeThickness="3"
               Fill="#3300FF00" />
</Canvas>
```

**关键点**：

- `SnapsToDevicePixels="True"` 对齐物理像素，避免线条模糊；
- `StrokeDashArray` 实现虚线检测框，区分不同类型的 ROI；
- 半透明填充（`#3300FF00`）既高亮区域又不遮挡下方图像。

------

### 2. Ellipse：焊点 / 圆形缺陷标记

**工业场景**：圆形焊点检测、孔洞标记、状态指示灯、点缺陷标注。

xaml:

```xaml
<Canvas>
    <!-- OK焊点：绿色实心圆 -->
    <Ellipse Canvas.Left="200" Canvas.Top="200"
             Width="16" Height="16"
             Canvas.Left="-8" Canvas.Top="-8" <!-- 圆心对齐坐标 -->
             Fill="LimeGreen" Stroke="DarkGreen" StrokeThickness="1"/>

    <!-- NG缺陷：红色空心圆，标记缺陷位置 -->
    <Ellipse Canvas.Left="320" Canvas.Top="240"
             Width="24" Height="24"
             Canvas.Left="-12" Canvas.Top="-12"
             Stroke="Red" StrokeThickness="2"/>
</Canvas>
```

**工业技巧**：通过 `Left=-Width/2`、`Top=-Height/2` 让圆形的圆心对准坐标点，符合视觉检测 “坐标标记缺陷中心” 的习惯。

------

### 3. Line：刻度线 / 尺寸标注

**工业场景**：标尺刻度、尺寸辅助线、运动轴限位线。

xaml:

```xaml
<Canvas Height="60">
    <!-- 主刻度线：长刻度，粗线条 -->
    <Line X1="20" Y1="10" X2="20" Y2="50"
          Stroke="Black" StrokeThickness="2"
          StrokeStartLineCap="Flat" StrokeEndLineCap="Flat"/>

    <!-- 次刻度线：短刻度 -->
    <Line X1="50" Y1="20" X2="50" Y2="50"
          Stroke="Gray" StrokeThickness="1"/>

    <!-- 尺寸标注线 + 箭头（配合Path实现） -->
    <Line X1="100" Y1="30" X2="300" Y2="30"
          Stroke="Blue" StrokeThickness="1"/>
</Canvas>
```

**关键点**：`StrokeStartLineCap` / `StrokeEndLineCap` 可设置线端样式，刻度线常用 `Flat` 平端保证刻度精度。

------

### 4. Polygon：不规则工位轮廓

**工业场景**：异形工位区域、多边形检测区、机械零件轮廓。

xaml:

```xaml
<!-- 三角形工位区域：半透明蓝色填充，蓝色描边 -->
<Polygon Points="0,100 100,0 200,100 100,200"
         Stroke="RoyalBlue" StrokeThickness="2"
         Fill="#334169E1"
         FillRule="Nonzero"/>
```

**注意**：`FillRule` 默认 `EvenOdd`（奇偶镂空），复杂闭合区域建议设为 `Nonzero`（非零环绕），避免填充出现意外镂空。

------

### 5. Polyline：运动轨迹 / 趋势曲线

**工业场景**：伺服轴运动轨迹、温度趋势曲线、扫描路径。

xaml:

```xaml
<!-- 运动轨迹：红色折线，圆角平滑拐角 -->
<Polyline Points="10,100 50,80 100,120 150,90 200,130"
          Stroke="Crimson" StrokeThickness="1.5"
          StrokeLineJoin="Round"/>
```

**工业优化**：`StrokeLineJoin="Round"` 让折线拐角平滑过渡，更贴合真实运动轨迹的视觉效果。

------

### 6. Path：复杂机械轮廓 / 自定义图标

**工业场景**：复杂工位符号、气缸 / 传感器图标、矢量机械示意图，是功能最强的 Shape 派生类。

xaml:

```xaml
<!-- 气缸示意图：PathGeometry 绘制复杂形状 -->
<Path Stroke="Black" StrokeThickness="1.5" Fill="#FFE0E0E0">
    <Path.Data>
        <GeometryGroup>
            <RectangleGeometry Rect="0,10 60,30" RadiusX="5" RadiusY="5"/>
            <RectangleGeometry Rect="60,15 20,20"/>
            <LineGeometry StartPoint="80,25" EndPoint="100,25"/>
        </GeometryGroup>
    </Path.Data>
</Path>
```

**性能提示**：动态生成复杂路径时，优先使用 `StreamGeometry` 替代 `PathGeometry`，内存占用和渲染性能更优，适合高频刷新的缺陷轮廓、扫描路径。

## 二、自定义 Shape 进阶案例（基于抽象基类扩展）

当内置图形无法满足工业特殊需求时，继承 `Shape` 抽象类，重写 `DefiningGeometry` 即可自定义专属图形，自动复用基类所有描边、填充、布局、绑定能力。

### 案例 1：十字对位标记（CrosshairShape）

**工业场景**：视觉对位十字线、相机中心标记、坐标原点指示。

#### 完整 C# 实现

csharp:

```c#
using System.Windows;
using System.Windows.Media;
using System.Windows.Shapes;

/// <summary>
/// 自定义十字对位标记图形
/// 继承Shape抽象基类，仅需重写DefiningGeometry
/// </summary>
public class CrosshairShape : Shape
{
    // 十字线长度依赖属性：支持绑定、动画
    public static readonly DependencyProperty SizeProperty = DependencyProperty.Register(
        nameof(Size),
        typeof(double),
        typeof(CrosshairShape),
        new FrameworkPropertyMetadata(20.0, 
            FrameworkPropertyMetadataOptions.AffectsRender | 
            FrameworkPropertyMetadataOptions.AffectsMeasure));

    /// <summary>
    /// 十字线总长度（从中心到端点的距离×2）
    /// </summary>
    public double Size
    {
        get => (double)GetValue(SizeProperty);
        set => SetValue(SizeProperty, value);
    }

    // 核心：重写抽象属性DefiningGeometry，定义图形形状
    protected override Geometry DefiningGeometry
    {
        get
        {
            double half = Size / 2;
            // 用GeometryGroup组合两条互相垂直的直线
            var group = new GeometryGroup();
            group.Children.Add(new LineGeometry(new Point(0, half), new Point(Size, half)));
            group.Children.Add(new LineGeometry(new Point(half, 0), new Point(half, Size)));
            
            // 冻结几何对象，提升性能（不可变对象无需变更通知）
            group.Freeze();
            return group;
        }
    }
}
```

#### XAML 中使用

xaml:

```xaml
<Window x:Class="WpfApp1.MainWindow"
        xmlns:local="clr-namespace:WpfApp1"
        ...>
    <Canvas>
        <!-- 红色十字标记，中心对准(200,200) -->
        <local:CrosshairShape Canvas.Left="190" Canvas.Top="190"
                              Size="20"
                              Stroke="Red" StrokeThickness="1.5"/>
    </Canvas>
</Window>
```

**设计要点**：

1. 自定义属性注册时，标记 `AffectsRender`，属性变化自动触发重绘；
2. `DefiningGeometry` 中返回的几何对象建议调用 `Freeze()` 冻结，减少内存和性能开销；
3. 自动继承基类所有属性：`Stroke`、`StrokeThickness`、`StrokeDashArray`、`Opacity` 等全部可用。

### 案例 2：带箭头指示线（ArrowLineShape）

**工业场景**：物料流向指示、运动方向标注、工序流转箭头。

#### 完整 C# 实现

csharp:

```c#
using System.Windows;
using System.Windows.Media;
using System.Windows.Shapes;

public class ArrowLineShape : Shape
{
    // 起点X
    public static readonly DependencyProperty X1Property = DependencyProperty.Register(
        nameof(X1), typeof(double), typeof(ArrowLineShape),
        new FrameworkPropertyMetadata(0.0, 
            FrameworkPropertyMetadataOptions.AffectsRender | FrameworkPropertyMetadataOptions.AffectsMeasure));

    // 起点Y
    public static readonly DependencyProperty Y1Property = DependencyProperty.Register(
        nameof(Y1), typeof(double), typeof(ArrowLineShape),
        new FrameworkPropertyMetadata(0.0, 
            FrameworkPropertyMetadataOptions.AffectsRender | FrameworkPropertyMetadataOptions.AffectsMeasure));

    // 终点X
    public static readonly DependencyProperty X2Property = DependencyProperty.Register(
        nameof(X2), typeof(double), typeof(ArrowLineShape),
        new FrameworkPropertyMetadata(0.0, 
            FrameworkPropertyMetadataOptions.AffectsRender | FrameworkPropertyMetadataOptions.AffectsMeasure));

    // 终点Y
    public static readonly DependencyProperty Y2Property = DependencyProperty.Register(
        nameof(Y2), typeof(double), typeof(ArrowLineShape),
        new FrameworkPropertyMetadata(0.0, 
            FrameworkPropertyMetadataOptions.AffectsRender | FrameworkPropertyMetadataOptions.AffectsMeasure));

    // 箭头大小
    public static readonly DependencyProperty ArrowSizeProperty = DependencyProperty.Register(
        nameof(ArrowSize), typeof(double), typeof(ArrowLineShape),
        new FrameworkPropertyMetadata(8.0, 
            FrameworkPropertyMetadataOptions.AffectsRender));

    public double X1 { get => (double)GetValue(X1Property); set => SetValue(X1Property, value); }
    public double Y1 { get => (double)GetValue(Y1Property); set => SetValue(Y1Property, value); }
    public double X2 { get => (double)GetValue(X2Property); set => SetValue(X2Property, value); }
    public double Y2 { get => (double)GetValue(Y2Property); set => SetValue(Y2Property, value); }
    public double ArrowSize { get => (double)GetValue(ArrowSizeProperty); set => SetValue(ArrowSizeProperty, value); }

    protected override Geometry DefiningGeometry
    {
        get
        {
            StreamGeometry geo = new StreamGeometry();
            using (var ctx = geo.Open())
            {
                // 绘制主线
                ctx.BeginFigure(new Point(X1, Y1), false, false);
                ctx.LineTo(new Point(X2, Y2), true, false);

                // 计算箭头方向
                double dx = X2 - X1;
                double dy = Y2 - Y1;
                double angle = System.Math.Atan2(dy, dx);
                double arrowAngle = System.Math.PI / 6; // 30度箭头夹角

                // 箭头左线
                double xLeft = X2 - ArrowSize * System.Math.Cos(angle - arrowAngle);
                double yLeft = Y2 - ArrowSize * System.Math.Sin(angle - arrowAngle);
                ctx.LineTo(new Point(xLeft, yLeft), true, false);

                // 回到终点，画箭头右线
                ctx.BeginFigure(new Point(X2, Y2), false, false);
                double xRight = X2 - ArrowSize * System.Math.Cos(angle + arrowAngle);
                double yRight = Y2 - ArrowSize * System.Math.Sin(angle + arrowAngle);
                ctx.LineTo(new Point(xRight, yRight), true, false);
            }
            geo.Freeze();
            return geo;
        }
    }
}
```

#### XAML 使用

xaml:

```xaml
<local:ArrowLineShape X1="50" Y1="100" X2="250" Y2="100"
                      Stroke="Blue" StrokeThickness="2"
                      ArrowSize="10"/>
```

**优势**：相比用 `Line` + `Polygon` 拼接箭头，单一 `Shape` 元素布局更简单、描边样式统一、命中测试完整，性能更优。

## 三、工业场景综合应用案例

### 案例 1：AOI 缺陷检测结果可视化（MVVM 数据绑定）

**场景**：将算法输出的缺陷列表，通过 `ItemsControl` 绑定批量渲染缺陷标记，纯 MVVM 模式，无后台代码操作 UI。

#### 视图模型（简化版）

csharp:

```c#
public class DefectItem
{
    public double X { get; set; }
    public double Y { get; set; }
    public double Size { get; set; }
    public string Type { get; set; }
}
```

#### XAML 界面

xaml:

```xaml
<Canvas Width="800" Height="600" Background="#FFF0F0F0">
    <!-- 缺陷标记列表：数据绑定 -->
    <ItemsControl ItemsSource="{Binding DefectList}">
        <ItemsControl.ItemsPanel>
            <ItemsPanelTemplate>
                <Canvas/>
            </ItemsPanelTemplate>
        </ItemsControl.ItemsPanel>
        <ItemsControl.ItemContainerStyle>
            <Style TargetType="ContentPresenter">
                <Setter Property="Canvas.Left" Value="{Binding X}"/>
                <Setter Property="Canvas.Top" Value="{Binding Y}"/>
            </Style>
        </ItemsControl.ItemContainerStyle>
        <ItemsControl.ItemTemplate>
            <DataTemplate>
                <!-- 缺陷标记：圆形外框，中心对齐 -->
                <Ellipse Width="{Binding Size}" Height="{Binding Size}"
                         Stroke="Red" StrokeThickness="1.5"
                         Margin="{Binding Size, Converter={StaticResource HalfMarginConverter}}"/>
            </DataTemplate>
        </ItemsControl.ItemTemplate>
    </ItemsControl>
</Canvas>
```

**工业价值**：算法线程计算出缺陷后，只需更新集合属性，UI 自动渲染，完美符合 WPF 数据驱动理念，避免跨线程操作 UI 的问题。

### 案例 2：线扫相机动态扫描效果

**场景**：模拟线扫相机的扫描过程，通过虚线流动动画直观展示扫描进度和方向。

xaml:

```xaml
<Canvas>
    <!-- 扫描区域边框 -->
    <Rectangle Width="400" Height="300"
               Stroke="Gray" StrokeThickness="1"/>
    
    <!-- 流动虚线扫描线 -->
    <Line X1="0" Y1="150" X2="400" Y2="150"
          Stroke="LimeGreen" StrokeThickness="2"
          StrokeDashArray="8,4" StrokeDashCap="Round">
        <Line.Triggers>
            <EventTrigger RoutedEvent="Loaded">
                <BeginStoryboard>
                    <Storyboard RepeatBehavior="Forever">
                        <!-- 动画修改虚线偏移量，实现流动效果 -->
                        <DoubleAnimation Storyboard.TargetProperty="StrokeDashOffset"
                                         From="0" To="-12" Duration="0:0:0.5" />
                    </Storyboard>
                </BeginStoryboard>
            </EventTrigger>
        </Line.Triggers>
    </Line>
</Canvas>
```

**原理**：通过 `DoubleAnimation` 持续修改 `StrokeDashOffset`，让虚线产生单向流动的视觉效果，工业中常用于表示扫描方向、物料传送方向。

## 四、性能与避坑提示

1. **少量图形用 Shape，大量高频刷新换低层方案**

   几十以内的静态 / 低频更新图形，Shape 开发效率高、易维护；上百个图形同时高频刷新（如实时轨迹每秒几十次更新）时，每个 Shape 都是完整 `FrameworkElement`，有布局开销，建议改用 `DrawingVisual` 或 `WriteableBitmap`。

2. **几何对象能冻结就冻结**

   自定义 Shape 时，不变的 `Geometry` 对象调用 `Freeze()`，可减少内存占用和变更通知开销，提升渲染性能。

3. **避免在布局容器中大量使用绝对定位**

   Shape 虽然支持 Canvas 绝对定位，但动态布局优先用 `Stretch="Uniform"` 适配容器，适配不同分辨率工控屏更省心。

4. **线条模糊必开像素对齐**

   工业高精度绘图必须设置 `SnapsToDevicePixels="True"`，避免亚像素渲染导致的线条发虚、模糊。

5. **自定义属性勿忘标记 AffectsRender**

   新增影响图形形状的依赖属性时，必须在元数据中标记 `AffectsRender` 和 `AffectsMeasure`，否则属性变化后界面不会自动刷新。
