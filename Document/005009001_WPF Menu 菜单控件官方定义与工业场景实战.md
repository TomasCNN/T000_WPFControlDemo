# 005009001_WPF `Menu` 菜单控件官方定义与工业场景实战

`Menu` 是 WPF 原生的层级菜单控件，继承自 `MenuBase` → `ItemsControl` 体系，通过嵌套 `MenuItem` 实现多级下拉菜单，原生支持键盘导航、命令绑定、复选状态、图标与快捷键提示，是窗口顶部主菜单、控件右键上下文菜单的标准实现。

它是工业上位机软件的标配控件，用于承载系统操作、设备控制、视图切换、工具配置等全局功能，配合 `ContextMenu` 可实现设备右键快捷操作，大幅提升工控操作效率。

------

## 一、官方类定义总览与核心元数据

### 1.1 完整类签名（官方原生定义）

csharp:

```c#
namespace System.Windows.Controls
{
    [System.Windows.StyleTypedPropertyAttribute(Property = "ItemContainerStyle", StyleTargetType = typeof(System.Windows.Controls.MenuItem))]
    public class Menu : System.Windows.Controls.Primitives.MenuBase
    {
        // 核心依赖属性字段
        public static readonly System.Windows.DependencyProperty IsMainMenuProperty;

        // 构造函数
        public Menu();

        // 核心公共属性
        public bool IsMainMenu { get; set; }

        // 受保护重写方法
        protected override System.Windows.DependencyObject GetContainerForItemOverride();
        protected override bool IsItemItsOwnContainerOverride(object item);
        protected override System.Windows.Automation.Peers.AutomationPeer OnCreateAutomationPeer();
        protected override void OnKeyDown(System.Windows.Input.KeyEventArgs e);
    }
}
```

### 1.2 核心元数据（官方精确值）

| 项               | 官方精确值                                                   | 工业场景关键说明                                             |
| :--------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **命名空间**     | `System.Windows.Controls`                                    | WPF 标准控件命名空间                                         |
| **程序集**       | `PresentationFramework.dll`                                  | WPF 核心框架程序集                                           |
| **完整继承链**   | `Object → DispatcherObject → DependencyObject → Visual → UIElement → FrameworkElement → Control → ItemsControl → MenuBase → Menu` | 纯集合控件体系，条目容器为 `MenuItem`                        |
| **默认条目容器** | `MenuItem`                                                   | 菜单项载体，继承自 `HeaderedItemsControl`，自身也是集合容器，支持无限层级子菜单 |
| **同源控件**     | `ContextMenu`（右键菜单）                                    | 同继承自 `MenuBase`，交互逻辑与菜单项完全复用                |
| **核心设计**     | 层级嵌套 + 键盘导航 + 命令路由 + Popup 弹出                  | 支持多级下拉、纯键盘操作、MVVM 命令绑定                      |
| **工业核心场景** | 窗口顶部系统主菜单、设备右键快捷操作、视图切换、权限可控的动态菜单 | 所有全局功能、快捷操作的入口                                 |

### 1.3 类级特性解析

**`[StyleTypedProperty(Property = "ItemContainerStyle", StyleTargetType = typeof(MenuItem))]`**

- 向设计器声明 `ItemContainerStyle` 的目标类型为 `MenuItem`，提供样式智能提示与编译期校验；
- 与 `ListBox`、`TreeView` 遵循完全一致的 `ItemsControl` 体系约定。

## 二、核心类型深度解析

菜单体系的核心能力几乎都承载在 `MenuItem` 上，`Menu` 本身仅作为顶层容器与主菜单入口。

### 2.1 Menu 自身核心属性

#### IsMainMenu

csharp:

```c#
public bool IsMainMenu { get; set; }
```

- **类型**：`bool`，默认值 `true`
- **官方作用**：标识当前菜单是否为窗口主菜单。
- **底层联动效果**：
  1. 设为 `true` 时，按 `Alt` 键可自动激活菜单，进入键盘导航模式；
  2. 点击窗口其他区域、失去焦点时自动关闭所有展开的子菜单；
  3. 接收窗口的菜单键盘消息，支持 `Alt+字母` 快捷访问（如 `Alt+F` 打开文件菜单）。
- **工业最佳实践**：窗口顶部的系统菜单栏保持默认 `true`；用户控件内的局部菜单设为 `false`。

### 2.2 继承的高频属性

全部继承自 `ItemsControl`，与 `ListBox` 用法一致：

- `ItemsSource`：绑定菜单数据源，MVVM 动态生成菜单；
- `ItemTemplate` / `ItemContainerStyle`：自定义菜单项外观与样式；
- `Background` / `Foreground` / `FontSize`：控制菜单整体外观。

### 2.3 核心条目容器：MenuItem 类定义

`MenuItem` 是菜单的基本单元，继承自 `HeaderedItemsControl`，**自身也是集合容器**，可无限嵌套子菜单，同时集成了命令、复选、图标、快捷键等完整能力。

#### 官方精简类定义

csharp:

```c#
public class MenuItem : HeaderedItemsControl
{
    // 依赖属性字段
    public static readonly DependencyProperty IsCheckedProperty;
    public static readonly DependencyProperty IsCheckableProperty;
    public static readonly DependencyProperty IsSubmenuOpenProperty;
    public static readonly DependencyProperty CommandProperty;
    public static readonly DependencyProperty CommandParameterProperty;
    public static readonly DependencyProperty CommandTargetProperty;
    public static readonly DependencyProperty InputGestureTextProperty;
    public static readonly DependencyProperty IconProperty;
    public static readonly DependencyProperty StaysOpenOnClickProperty;

    // 核心属性
    public bool IsChecked { get; set; }
    public bool IsCheckable { get; set; }
    public bool IsSubmenuOpen { get; set; }
    public ICommand Command { get; set; }
    public object CommandParameter { get; set; }
    public IInputElement CommandTarget { get; set; }
    public string InputGestureText { get; set; }
    public object Icon { get; set; }
    public bool StaysOpenOnClick { get; set; }

    // 核心事件
    public event RoutedEventHandler Click;
    public event RoutedEventHandler Checked;
    public event RoutedEventHandler Unchecked;
    public event RoutedEventHandler SubmenuOpened;
    public event RoutedEventHandler SubmenuClosed;

    // 受保护方法
    protected virtual void OnClick();
    protected virtual void OnChecked(RoutedEventArgs e);
    protected virtual void OnUnchecked(RoutedEventArgs e);
}
```

#### 核心属性分类解析

| 分类         | 属性               | 官方作用                       | 工业场景价值                                     |
| :----------- | :----------------- | :----------------------------- | :----------------------------------------------- |
| **复选状态** | `IsCheckable`      | 菜单项是否显示复选框，支持勾选 | 视图切换、功能开关场景，如显示 / 隐藏工具栏      |
|              | `IsChecked`        | 当前是否处于勾选状态           | 可双向绑定到 ViewModel，持久化视图配置           |
| **命令绑定** | `Command`          | 点击时执行的命令               | MVVM 架构首选，替代 Click 事件，支持权限控制     |
|              | `CommandParameter` | 命令传递的参数                 | 右键菜单中传递当前设备对象，执行对应操作         |
|              | `CommandTarget`    | 命令的目标元素                 | 路由命令的目标控件，如文本框的复制粘贴           |
| **外观扩展** | `Icon`             | 菜单项左侧图标                 | 工业场景用图标区分操作类型（启动 / 停止 / 复位） |
|              | `InputGestureText` | 右侧快捷键提示文本             | 标注快捷键，提升键盘操作效率，仅显示不绑定功能   |
| **行为控制** | `StaysOpenOnClick` | 点击后是否保持菜单打开         | 复选菜单、批量操作场景开启，避免点击一次就关闭   |
|              | `IsSubmenuOpen`    | 子菜单是否展开                 | 代码控制子菜单展开 / 收起                        |

## 三、核心事件体系

### 3.1 MenuItem 核心事件

| 事件                              | 触发时机                | 典型用法                                         |
| :-------------------------------- | :---------------------- | :----------------------------------------------- |
| `Click`                           | 菜单项被点击时触发      | 简单场景的点击逻辑处理，MVVM 推荐用 Command 替代 |
| `Checked` / `Unchecked`           | 勾选状态发生变化时触发  | 复选菜单的状态变更逻辑，如切换视图显示           |
| `SubmenuOpened` / `SubmenuClosed` | 子菜单展开 / 收起时触发 | 子菜单懒加载，展开时才异步加载子菜单项           |

### 3.2 路由事件机制

所有菜单事件均为**冒泡路由事件**，可在 `Menu` 顶层统一监听处理，适合批量菜单操作的场景。

## 四、官方核心工作机制

### 4.1 主菜单键盘激活机制

1. 按下 `Alt` 键，主菜单进入激活状态，首个菜单项获得焦点；
2. 左右方向键切换顶级菜单，上下方向键切换子菜单项；
3. 按下字母键（如 `F`）直接打开对应下划线的菜单（通过 `Header` 中的 `_` 标记，如 `_文件` 对应 Alt+F）；
4. 回车执行当前菜单项，Esc 逐级关闭菜单；
5. 点击空白区域自动关闭所有菜单，失去焦点时自动收起。

### 4.2 层级嵌套与弹出机制

- 子菜单通过 `Popup` 控件承载，悬浮在父菜单右侧 / 下方；
- 鼠标悬浮到带箭头的父菜单项时，自动展开子菜单；
- 菜单项本身是 `HeaderedItemsControl`，可无限嵌套，理论上支持任意层级菜单；
- 菜单弹出时自动检测屏幕边界，空间不足时反向弹出，避免超出屏幕。

### 4.3 命令路由机制

`MenuItem` 完整支持 WPF 命令体系：

1. 点击菜单项时，执行 `Command` 绑定的命令；
2. 命令自动向上冒泡路由，直到找到对应命令绑定；
3. `CanExecute` 状态自动同步到菜单项的可用状态，命令不可用时菜单项自动灰显。

### 4.4 上下文菜单（ContextMenu）机制

`ContextMenu` 与 `Menu` 同继承自 `MenuBase`，菜单项逻辑完全一致，区别仅在于触发方式：

- 通过 `FrameworkElement.ContextMenu` 属性关联到目标控件；
- 右键点击目标元素时，在鼠标位置弹出菜单；
- 工业场景广泛用于设备列表、数据表格的右键快捷操作。

> ⚠️ 常见坑点：`ContextMenu` 位于独立 `Popup` 中，不在主视觉树内，无法直接继承父元素的 `DataContext`，MVVM 绑定时需通过 `PlacementTarget.DataContext` 中转。

## 五、基础使用方法

### 5.1 静态主菜单（固定菜单项）

适合菜单固定的场景，直接在 XAML 中嵌套 `MenuItem`。

xaml:

```xaml
<Menu>
    <MenuItem Header="_文件">
        <MenuItem Header="导出数据" InputGestureText="Ctrl+E"/>
        <MenuItem Header="打印报表"/>
        <Separator/>
        <MenuItem Header="退出系统"/>
    </MenuItem>
    <MenuItem Header="_视图">
        <MenuItem Header="显示工具栏" IsCheckable="True" IsChecked="True"/>
        <MenuItem Header="显示状态栏" IsCheckable="True" IsChecked="True"/>
    </MenuItem>
</Menu>
```

- `Header` 中 `_` 开头的字符为 Alt 快捷访问键；
- `<Separator/>` 生成分隔线，用于菜单分组；
- `IsCheckable` 开启复选模式。

### 5.2 控件右键上下文菜单

xaml:

```xaml
<Border Background="#F5F5F5">
    <Border.ContextMenu>
        <ContextMenu>
            <MenuItem Header="启动设备"/>
            <MenuItem Header="停止设备"/>
            <Separator/>
            <MenuItem Header="查看详情"/>
        </ContextMenu>
    </Border.ContextMenu>
</Border>
```

### 实例 2：设备列表右键快捷菜单

#### 场景说明

设备列表的每一项支持右键操作，弹出启动、停止、查看详情、导出记录等快捷菜单，是工业设备监控系统的高频交互方式。

#### 核心实现

xaml:

```xaml
<ListBox ItemsSource="{Binding DeviceList}"
         DisplayMemberPath="DeviceName"
         BorderBrush="#DDD" BorderThickness="1"
         Width="250" Margin="10">
    <ListBox.ItemContainerStyle>
        <Style TargetType="ListBoxItem">
            <Setter Property="Padding" Value="8 4"/>
            <!-- 每个列表项绑定右键菜单 -->
            <Setter Property="ContextMenu">
                <Setter.Value>
                    <ContextMenu>
                        <!-- 绑定ViewModel命令，通过PlacementTarget获取数据上下文 -->
                        <MenuItem Header="启动设备"
                                  Command="{Binding PlacementTarget.DataContext.StartDeviceCommand, RelativeSource={RelativeSource AncestorType=ContextMenu}}"
                                  CommandParameter="{Binding}"/>
                        <MenuItem Header="停止设备"
                                  Command="{Binding PlacementTarget.DataContext.StopDeviceCommand, RelativeSource={RelativeSource AncestorType=ContextMenu}}"
                                  CommandParameter="{Binding}"/>
                        <Separator/>
                        <MenuItem Header="查看详情"
                                  Command="{Binding PlacementTarget.DataContext.ViewDetailCommand, RelativeSource={RelativeSource AncestorType=ContextMenu}}"
                                  CommandParameter="{Binding}"/>
                        <MenuItem Header="导出运行记录"
                                  Command="{Binding PlacementTarget.DataContext.ExportRecordCommand, RelativeSource={RelativeSource AncestorType=ContextMenu}}"
                                  CommandParameter="{Binding}"/>
                    </ContextMenu>
                </Setter.Value>
            </Setter>
        </Style>
    </ListBox.ItemContainerStyle>
</ListBox>
```

> 💡 绑定关键说明：
>
> ContextMenu 不在主视觉树中，无法直接继承 DataContext，通过 `RelativeSource` 找到 ContextMenu 自身，再通过 `PlacementTarget.DataContext` 获取目标元素的数据上下文，是右键菜单 MVVM 绑定的标准方案。

### 实例 3：MVVM 动态权限菜单

#### 场景说明

根据登录用户的角色权限动态生成菜单项，管理员可见全部菜单，操作员仅可见操作与查询菜单，避免硬编码权限判断，适合多角色的工业管理系统。

#### 1. 菜单数据模型

csharp:

```c#
public class MenuItemModel : INotifyPropertyChanged
{
    public string MenuHeader { get; set; }
    public string MenuIcon { get; set; }
    public ICommand MenuCommand { get; set; }
    public ObservableCollection<MenuItemModel> Children { get; set; } = new ObservableCollection<MenuItemModel>();
}
```

#### 2. ViewModel 动态生成菜单

csharp:

```c#
public class MainViewModel
{
    public ObservableCollection<MenuItemModel> SystemMenus { get; set; }

    public MainViewModel(string userRole)
    {
        SystemMenus = new ObservableCollection<MenuItemModel>();
        
        // 根据角色动态构建菜单
        SystemMenus.Add(new MenuItemModel { MenuHeader = "_文件" });
        SystemMenus.Add(new MenuItemModel { MenuHeader = "_视图" });
        
        if (userRole == "操作员" || userRole == "管理员")
        {
            SystemMenus.Add(new MenuItemModel { MenuHeader = "_操作" });
        }
        
        if (userRole == "管理员")
        {
            SystemMenus.Add(new MenuItemModel { MenuHeader = "_工具" });
        }
        
        SystemMenus.Add(new MenuItemModel { MenuHeader = "_帮助" });
    }
}
```

#### 3. XAML 分层模板绑定

xaml:

```xaml
<Menu ItemsSource="{Binding SystemMenus}"
      DockPanel.Dock="Top">
    <Menu.ItemTemplate>
        <HierarchicalDataTemplate DataType="{x:Type local:MenuItemModel}"
                                  ItemsSource="{Binding Children}">
            <TextBlock Text="{Binding MenuHeader}"/>
        </HierarchicalDataTemplate>
    </Menu.ItemTemplate>
</Menu>
```

> 原理与 TreeView 分层绑定一致，通过 `HierarchicalDataTemplate` 递归渲染多级子菜单。

## 七、最佳实践与常见坑点

### 7.1 工业场景最佳实践

1. **优先使用命令绑定**

   所有菜单操作绑定 `ICommand`，不要用 `Click` 事件，保持 MVVM 架构整洁，便于统一权限控制与单元测试。

2. **高频操作下沉到右键菜单**

   设备启停、参数查看、数据导出等常用操作放到右键上下文菜单，减少操作路径，提升工控操作效率。

3. **标注快捷键，适配纯键盘操作**

   高频功能标注 `InputGestureText`，同时通过 `Window.InputBindings` 绑定实际快捷键，适配工控机无鼠标、触摸屏操作场景。

4. **权限控制动态生成菜单**

   多角色系统不要在 XAML 中硬编码 `IsEnabled` 权限判断，通过 ViewModel 动态构建菜单集合，权限逻辑集中管理。

5. **工业主题适配**

   深色工控主题下自定义菜单样式，避免默认白色菜单与深色界面反差过大，造成视觉疲劳。

### 7.2 常见坑点

1. **ContextMenu 绑定失效**
   - 现象：右键菜单命令绑定无反应、数据为空；
   - 原因：ContextMenu 在 Popup 中，不在主视觉树，无法继承父元素 DataContext；
   - 解决：通过 `PlacementTarget.DataContext` 中转绑定。
2. **快捷键只显示不生效**
   - 现象：`InputGestureText` 显示了快捷键，但按下没反应；
   - 原因：该属性仅为文本提示，不绑定实际功能；
   - 解决：在窗口 `InputBindings` 中添加对应快捷键与命令绑定。
3. **点击后菜单不关闭**
   - 现象：点击菜单项后菜单保持展开；
   - 原因：设置了 `StaysOpenOnClick="True"`；
   - 解决：普通操作项不要设置该属性，仅复选、批量操作场景开启。
4. **Alt 键无法激活主菜单**
   - 现象：按 Alt 键菜单无反应；
   - 原因：`IsMainMenu` 设为了 `false`；
   - 解决：窗口主菜单栏保持 `IsMainMenu="True"`。

## 总结

`Menu` 是 WPF 系统级交互的标准入口控件，基于 `ItemsControl` 体系构建，通过 `MenuItem` 的自嵌套特性实现无限层级菜单，同时集成了命令绑定、复选、键盘导航等完整能力。它与 `ContextMenu` 共同构成了工业软件「顶部全局菜单 + 右键快捷操作」的标准交互模式，是上位机界面开发的必备基础控件。
