# 999999010-2_手标定常见算法全解析（工业视角通俗版）

手眼标定的核心数学问题是求解经典方程 **AX = XB**，所有算法本质都是围绕「怎么解这个方程」展开 —— 区别在于拆分方式不同、数值稳定性不同、对噪声的鲁棒性不同、适用场景不同。

工业界通常把算法分为三大类：**经典闭式解法**（工业主流标配）、**迭代优化解法**（高精度场景）、**特殊场景算法**（非标工况）。下面逐一讲清原理、特点和适用场景。

------

## 一、经典闭式解法（工业最常用，无需初值、计算快）

闭式解法的特点是：通过数学推导把方程转化为线性方程组，代入数据直接算出唯一结果，不需要迭代、不需要初始值，计算速度极快，稳定性强，是所有工业视觉软件的标配。

这类算法基本都是围绕「旋转和平移怎么解」展开，分为**两步法**（先解旋转，再解平移）和**一步法**（旋转平移同时解）两大流派。

### 1. Tsai-Lenz 算法（开山鼻祖，行业基准）

- **提出时间**：1989 年，手眼标定领域的经典奠基算法
- **核心思路**：典型**两步法**
  1. 先用「轴角（旋转向量）」描述旋转，把非线性的旋转问题转化为线性方程组，先解出手眼矩阵的旋转部分；
  2. 把解出的旋转代回原方程，再线性求解平移向量。
- **通俗理解**：先把两张地图的方向对齐，方向对好了再挪原点位置。
- **优点**：
  - 计算速度极快，十几组数据毫秒级出结果；
  - 原理清晰，实现简单，是所有手眼标定工具的基准对比算法。
- **短板**：
  - 当每次采集的旋转角度很小时，方程容易出现病态，精度会明显下降；
  - 旋转的误差会传递给平移，旋转不准会导致平移偏差被放大。
- **适用场景**：常规工业抓取、检测，采集时能做到大角度旋转，数据质量较好的场景。

### 2. Park-Martin 算法（工业首选默认算法）

- **提出时间**：1994 年，目前工业软件最常用的默认算法

- **核心思路**：同样是**两步法**，但用更严谨的**李群李代数**数学工具处理旋转

  

  通过矩阵对数把旋转矩阵转化为旋转向量，构建更稳定的线性方程组求解旋转，再代入求解平移。

- **通俗理解**：和 Tsai-Lenz 思路一致，但数学工具更先进，方向对齐的精度更高、更稳。

- **优点**：

  - 数值稳定性远优于 Tsai-Lenz，尤其是**小角度旋转场景**精度更可靠；
  - 对图像噪声、机器人定位误差的容忍度更高，鲁棒性强。

- **适用场景**：绝大多数工业场景，是 Halcon、主流机器人视觉向导的默认算法。

### 3. Daniilidis 对偶四元数法（一步法代表）

- **提出时间**：1999 年，一步法的经典实现
- **核心思路**：用**对偶四元数**同时描述旋转和平移，把 AX=XB 方程整体转化为线性方程组，**一次性同时解出旋转和平移**，不再分两步。
- **通俗理解**：方向和位置同时对齐，不会出现「方向误差带偏位置」的问题。
- **优点**：
  - 彻底避免了两步法「旋转误差传递给平移」的缺陷；
  - 数据量越大、噪声越大，优势越明显，全局一致性更好。
- **短板**：计算量比两步法略大，但对现代工业计算机来说几乎可以忽略。
- **适用场景**：大噪声、大数据量、对平移精度要求高的场景。

### 4. 其他经典闭式解

- **Horaud 算法**：针对平面标定板场景优化，处理奇异位姿的能力更强；
- **Chen 算法**：基于四元数的两步法，在特定构型下数值稳定性更优。

## 二、迭代优化类解法（高精度场景，追求极致精度）

闭式解法的本质是「用线性方程近似求解非线性问题」，只利用了相邻位姿的运动增量，没有做全局最优拟合。在**高精度装配、微米级检测**等场景，会用闭式解做初始值，再通过非线性迭代做全局精修，进一步压缩误差。

### 1. 非线性最小二乘（LM 算法）

- **核心思路**：
  1. 先用 Tsai-Lenz/Park-Martin 等闭式解算出一个初始的手眼矩阵；
  2. 把所有采集的位姿数据统一纳入误差函数，以「所有运动的 AX 与 XB 偏差总和最小」为目标；
  3. 用**列文伯格 - 马夸尔特（LM）** 算法迭代优化，不断调整手眼矩阵，直到误差收敛到最小值。
- **通俗理解**：先大概对齐，再一点点微调，让所有位置的整体误差降到最低。
- **优点**：精度比闭式解更高，能充分利用所有采集数据的全局约束；
- **前提**：必须有合理的初值，否则容易陷入局部最优解。

### 2. 基于重投影误差的联合优化（最高精度方案）

- **核心思路**：

  传统手眼标定分两步：先从图像算出标定板位姿，再用位姿解手眼矩阵，每一步都会传递误差。

  联合优化跳过中间步骤，

  直接以图像上标定板角点的重投影误差为目标

  ，同时优化：相机内参、所有标定板位姿、手眼矩阵。

- **通俗理解**：从源头像素开始算误差，全程一起优化，不让中间步骤的误差累积。

- **优点**：精度是所有方案里最高的，误差链路最短；

- **代表工具**：Halcon 的 `calibrate_hand_eye` 算子本质就是这种思路，联合优化内参与手眼关系。

- **适用场景**：高精度装配、微米级定位、3C 电子精密加工等对精度要求极致的场景。

## 三、特殊场景手眼标定算法

标准 AX=XB 针对的是「单相机 + 单机器人 + 标定板 + 静态采集」的经典场景，工业现场还有很多非标工况，衍生出了专门的算法。

### 1. 手 - 眼 - 工具同步标定

- **场景**：眼在手上（Eye-in-Hand）构型，除了相机和法兰的关系，还需要知道抓取工具的 TCP（工具中心点）。
- **传统问题**：先做手眼标定，再单独做工具标定，两步分开做，误差会累积。
- **算法特点**：同时求解「相机→法兰」和「法兰→工具」两个变换矩阵，统一优化，减少误差传递。
- **适用场景**：高精度抓取、精密装配、眼在手上的点胶 / 焊接工位。

### 2. 无标定板自标定

- **场景**：工况特殊，无法放置专用标定板（比如狭小空间、高温环境）。
- **算法特点**：不需要棋盘格 / 圆点标定板，利用环境中的自然特征点、直线，或者机器人运动的刚性约束，自行求解手眼关系。
- **短板**：精度远低于标定板方案，鲁棒性差，工业场景极少使用，多用于科研、服务机器人。

### 3. 在线动态标定

- **场景**：传统标定需要机器人停稳再拍照，高速产线不能停机；或者设备运行中需要实时补偿手眼偏差。
- **算法特点**：机器人连续运动过程中，同步采集连续图像和机器人位姿，实时求解 / 修正手眼矩阵，对算法实时性、抗干扰能力要求极高。
- **适用场景**：高速动态抓取、不停机校准、长时运行的热漂移补偿。

### 4. 多相机 / 多机器人手眼标定

- **场景**：一条产线多台相机对应一台机器人，或者多台机器人协作共用一套视觉系统。
- **算法特点**：一次性求解所有相机、机器人之间的变换关系，保证全局坐标系统一，避免分步标定的误差累积。
- **适用场景**：大型汽车产线、多工位检测线、多机器人协作工作站。

## 四、工业常用工具与算法对应

| 工具 / 库                                                 | 内置算法                                      | 常用场景                   |
| :-------------------------------------------------------- | :-------------------------------------------- | :------------------------- |
| OpenCV `cv2.calibrateHandEye()`                           | Tsai-Lenz、Park-Martin、Daniilidis 三种可切换 | 开源项目、低成本方案       |
| Halcon `calibrate_hand_eye`                               | 闭式解初值 + 非线性联合优化                   | 工业高精度视觉项目主流选择 |

| 第三方视觉软件（VisionPro、HexSight）                     | 闭式解 + 迭代优化                             | 通用机器视觉平台           |

## 五、算法选型建议（工业现场实用原则）

1. **常规场景选默认就够**：普通抓取、检测工位，直接用 Halcon / 机器人向导的默认算法（一般是 Park-Martin 或其优化版），精度完全满足需求，不用纠结算法选型。
2. **小旋转场景选稳的**：如果工位受限，标定板只能小角度转动，优先选 Park-Martin 或 Daniilidis，避免 Tsai-Lenz 的病态问题。
3. **高精度场景选优化版**：微米级装配、精密检测，用闭式解做初值，叠加非线性优化精修，或者直接用 Halcon 的联合标定方案。
4. **绝对不要自己从零实现算法**：手眼标定涉及大量数值计算细节（奇异值处理、数值稳定性、归一化），自己写很容易出隐蔽问题，直接用成熟库即可。

------

## 最后一个关键结论

**算法对手眼精度的影响，远小于数据采集质量和机械刚性。**

采集位姿覆盖不全、标定板变形、相机支架松动、机器人重复定位差，这些问题带来的误差，远大于不同算法之间的精度差异。

标定的核心功夫在「数据采集」，算法选成熟的主流方案就足够，不要陷入「追求最新算法」的误区。
