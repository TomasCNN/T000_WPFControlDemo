# 999999009-35_NLog 常用日志目标 (Target) 大全 + 工业上位机完整配置

NLog 内置大量 Target，覆盖工控上位机所有输出场景：本地文件、控制台、数据库、网络 TCP、邮件、结构化 JSON、内存、事件日志等。下面按**工业项目高频使用程度**分类，附带可直接复制的完整配置，适配 PLC、视觉 AOI、MES 对接场景。

## 一、核心基础 Target（工控 100% 必用）

### 1. File 文件输出（最核心，生产持久化日志）

支持按天切割、自动清理、异步、独占文件句柄、双重切割，上位机主日志、错误日志、审计日志全部用它。

#### 关键属性说明

- `fileName`：日志路径，支持 `${shortdate}` 日期变量
- `archiveEvery="Day"`：按天切割
- `maxArchiveDays="30"`：自动删除过期日志
- `keepFileOpen="true"`：长期持有文件句柄，减少 IO 开销
- `encoding="utf-8"`：解决中文乱码

#### 完整配置（主运行日志）

xaml:

```xaml
<target xsi:type="File" name="MainFile"
        fileName="D:/DeviceLogs/ST01/run-${shortdate}.log"
        archiveEvery="Day"
        archiveNumbering="Date"
        maxArchiveDays="30"
        maxArchiveFiles="100"
        keepFileOpen="true"
        concurrentWrites="false"
        encoding="utf-8">
  <layout>${longdate} | ${level:uppercase=true:padding=-5} | 线程${threadid} | ${event-properties:item=Module} | ${message} ${onexception:${newline}${exception:format=ToString,StackTrace}}</layout>
</target>
```

#### 错误日志独立文件（单独留存 90 天）

xaml:

```xaml
<target xsi:type="File" name="ErrorFile"
        fileName="D:/DeviceLogs/ST01/error-${shortdate}.log"
        archiveEvery="Day"
        maxArchiveDays="90"
        keepFileOpen="true"
        encoding="utf-8">
  <layout>${longdate} | ${level} | ${event-properties:item=Module} | ${message}${newline}${exception:format=ToString}================================================================</layout>
</target>
```

### 2. ColoredConsole 彩色控制台（开发调试专用）

开发阶段实时看日志，生产环境可注释关闭，不写磁盘无 IO 开销。

xaml:

```xaml
<target xsi:type="ColoredConsole" name="ConsoleTarget"
        layout="${time:format=HH\:mm\:ss.fff} | ${level:uppercase=true} | ${event-properties:item=Module} | ${message}">
  <!-- 自定义颜色：ERROR红色、WARN黄色 -->
  <highlight-row condition="level >= LogLevel.Error" foregroundColor="Red"/>
  <highlight-row condition="level == LogLevel.Warn" foregroundColor="Yellow"/>
</target>
```

### 3. AsyncWrapper 异步包装器（不是输出，是包装其他 Target）

工业实时场景必备，给文件 / 数据库套一层异步队列，隔离磁盘 IO，不阻塞相机、PLC 线程。

全局异步简写（推荐）：

xaml:

```xaml
<targets async="true" queueLimit="5000" overflowAction="Discard" batchSize="100">
    <!-- 所有File、Console写在这里，自动异步 -->
</targets>
```

单 Target 独立异步（相机 / PLC 队列隔离）：

xaml:

```xaml
<target xsi:type="AsyncWrapper" name="CameraAsync" queueLimit="5000" overflowAction="Discard">
  <target xsi:type="File" name="CameraLog" fileName="D:/Logs/cam-${shortdate}.log"/>
</target>
```

## 二、结构化 / 数据分析类 Target（对接 MES、日志平台）

### 4. JsonLayout + File 单行 JSON 结构化日志

用于上传日志到 ELK、MES 数据分析系统，字段结构化可检索（批次、SN、工位、异常分开字段）。

xaml:

```xaml
<target xsi:type="File" name="JsonFile" fileName="D:/Logs/json-${shortdate}.log" encoding="utf-8">
  <layout xsi:type="JsonLayout" includeAllProperties="true" escapeUnicode="false" suppressSpaces="true">
    <attribute name="time" layout="${longdate}" />
    <attribute name="level" layout="${level:uppercase=true}" />
    <attribute name="threadId" layout="${threadid}" />
    <attribute name="module" layout="${event-properties:item=Module}" />
    <attribute name="batchNo" layout="${event-properties:item=BatchNo}" />
    <attribute name="msg" layout="${message}" />
    <attribute name="ex" layout="${exception:format=ToString}" />
  </layout>
</target>
```

### 5. Database 数据库写入（生产追溯、MES 日志入库）

将日志直接写入 SQLServer/MySQL/Oracle，适合需要数据库永久审计的产线（IATF16949/GMP）。

#### SQL Server 示例

xaml:

```xaml
<target xsi:type="Database" name="DbLog">
  <!-- 连接字符串 -->
  <connectionString>Data Source=.;Initial Catalog=DeviceDB;User ID=sa;Password=123456</connectionString>
  <commandText>
    INSERT INTO DeviceLog(LogTime,LogLevel,ThreadId,Module,Message,Exception,BatchNo)
    VALUES(@time,@level,@thread,@module,@msg,@ex,@batch)
  </commandText>
  <!-- 参数映射 -->
  <parameter name="@time" layout="${longdate}" dbType="DateTime"/>
  <parameter name="@level" layout="${level}"/>
  <parameter name="@thread" layout="${threadid}"/>
  <parameter name="@module" layout="${event-properties:item=Module}"/>
  <parameter name="@msg" layout="${message}"/>
  <parameter name="@ex" layout="${exception:format=ToString}"/>
  <parameter name="@batch" layout="${event-properties:item=BatchNo}"/>
</target>
```

> 工业建议：数据库 Target 外层必须套`AsyncWrapper`，避免数据库网络延迟阻塞控制线程。

## 三、网络远程传输 Target（多设备集中日志服务器）

### 6. TcpTarget TCP 网络日志（车间统一日志收集服务）

上位机实时推送日志到机房日志汇总服务器，多台设备统一查看，不用每台电脑拷贝日志。

xaml:

```xaml
<target xsi:type="AsyncWrapper" queueLimit="3000">
  <target xsi:type="TcpTarget" name="TcpLog" host="192.168.1.100" port="9999">
    <layout>${longdate} | ${machinename} | ${level} | ${event-properties:item=Module} | ${message}</layout>
  </target>
</target>
```

### 7. HttpTarget HTTP/POST 推送日志（对接 MES / 云平台）

通过 HTTP 接口把日志推送到 MES、云端工业平台，实现产线日志云端存储。

xaml:

```xaml
<target xsi:type="AsyncWrapper">
  <target xsi:type="HttpTarget" name="HttpLog" Url="http://192.168.1.50/api/log/report" Method="POST">
    <header name="Content-Type" value="application/json"/>
    <layout xsi:type="JsonLayout" includeAllProperties="true"/>
  </target>
</target>
```

## 四、运维告警类 Target（设备异常自动通知）

### 8. Mail 邮件告警（Error/Fatal 异常自动发运维邮箱）

PLC 通信断开、相机崩溃、程序致命异常自动推送邮件给设备工程师。

xaml:

```xaml
<target xsi:type="AsyncWrapper" overflowAction="Discard">
  <target xsi:type="Mail" name="MailAlert"
          smtpServer="smtp.qq.com"
          smtpPort="587"
          smtpUsername="xxx@qq.com"
          smtpPassword="xxxx"
          from="设备告警<xxx@qq.com>"
          to="admin@company.com"
          subject="【产线异常】${machinename} 出现故障">
    <layout>
      设备：${machinename}
      时间：${longdate}
      模块：${event-properties:item=Module}
      级别：${level}
      内容：${message}
      堆栈：${exception:format=ToString}
    </layout>
  </target>
</target>
```

配套 rules：只让 Error/Fatal 走邮件，避免大量 INFO 刷屏邮箱

xaml:

```xaml
<logger name="*" minlevel="Error" maxlevel="Fatal" writeTo="MailAlert" final="false"/>
```

## 五、系统内置轻量 Target（辅助调试、系统集成）

### 9. EventLog Windows 系统事件日志

写入 Windows 系统事件查看器，适合服务器上位机，运维远程查看系统级故障。

xaml:

```xaml
<target xsi:type="EventLog" name="WinEventLog" source="DeviceApp" log="Application">
  <layout>${longdate} ${event-properties:item=Module}: ${message} ${exception}</layout>
</target>
```

### 10. MemoryTarget 内存日志（软件内实时日志窗口）

WPF/WinForm 上位机内置日志面板，日志存内存，UI 实时展示，不读写磁盘。

xaml:

```xaml
<target xsi:type="Memory" name="MemLog" bufferSize="2000"/>
```

C# 读取内存日志展示 UI：

csharp:

```c#
var memTarget = (MemoryTarget)LogManager.Configuration.FindTargetByName("MemLog");
var logs = memTarget.Logs;
```

### 11. NullTarget 空输出（临时屏蔽日志）

调试时临时关闭所有日志，无任何输出，零性能开销。

xaml:

```xaml
<target xsi:type="Null" name="NullLog"/>
```

## 六、多 Target 组合路由规则 (rules) 示例（工业完整组合）

一套配置同时输出：本地文件 + 控制台 + 数据库 + 异常邮件告警

xaml:

```xaml
<rules>
  <!-- 所有INFO及以上写入本地运行日志 -->
  <logger name="*" minlevel="Info" writeTo="MainFile" />
  <!-- 所有ERROR单独归档错误文件、数据库、邮件告警 -->
  <logger name="*" minlevel="Error" writeTo="ErrorFile,DbLog,MailAlert" />
  <!-- 开发控制台全部日志输出，生产可注释 -->
  <logger name="*" minlevel="Debug" writeTo="ConsoleTarget" />
</rules>
```

## 七、工业上位机 Target 选型建议

1. **必选**：File（运行日志 + 错误日志双文件）+ 全局 AsyncWrapper
2. **开发调试**：ColoredConsole + MemoryTarget（UI 日志窗口）
3. **合规追溯产线 (IATF/GMP)**：新增 Database 数据库日志 + Audit 独立 File 审计文件
4. **多设备集中管理**：增加 TcpTarget 推送至日志服务器
5. **远程运维告警**：Mail 邮件告警（仅 Error/Fatal）
6. **云端 MES 对接**：HttpTarget + JsonLayout 结构化日志

## 八、通用避坑要点

1. 网络类 (Tcp/Http/Mail)、数据库 Target**必须外层套 AsyncWrapper**，网络卡顿绝不阻塞 PLC / 相机实时线程；
2. 所有持久化 File 开启`keepFileOpen="true"`减少磁盘 IO；
3. 邮件、TCP、HTTP 增加队列上限，防止瞬时大量异常撑爆内存；
4. 生产环境关闭 Console、NullTarget 等调试 Target 减少开销；
5. 数据库写入不要存储超大图像报文、长二进制数据，仅记录关键参数。
