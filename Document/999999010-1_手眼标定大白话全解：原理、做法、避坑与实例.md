# 999999010-1_手眼标定大白话全解：原理、做法、避坑与实例

## 一、先搞懂：手眼标定到底是干啥的？

### 通俗类比

你可以把工业机器人比作「蒙着眼睛的工人」，把工业相机比作「固定的监控 / 戴在手上的放大镜」：

- 相机能看清产品位置，算出缺陷 / 工件在**照片里的坐标**，但它不知道这个位置在机器人的「工作地图」里对应哪里；
- 机器人能精准移动，但它看不见产品，只认自己的「基座坐标系」（以机器人底座为原点的三维地图）。

手眼标定，**本质就是算出「相机地图」和「机器人地图」之间的换算规则**—— 以后相机拍到任意一个点，都能通过这个规则，精准换算成机器人能识别的坐标，让机器人准确走到对应位置抓取、检测、加工。

就像人用眼睛看到桌上的杯子，手能准确伸过去拿，大脑早就记住了「眼睛看到的位置」和「手能摸到的位置」之间的固定关系，手眼标定就是给机器人 + 相机的组合「校准这个大脑关系」。

### 两种最常见的安装结构

| 结构类型                    | 通俗说法         | 安装方式                                                     | 适用场景                                     |
| :-------------------------- | :--------------- | :----------------------------------------------------------- | :------------------------------------------- |
| **眼固定（Eye-to-Hand）**   | 上帝视角         | 相机固定在工作台 / 机架上方，不动；机器人带动工件 / 夹具动   | 传送带检测、固定工位抓取、大视野场景，最常用 |
| **眼在手上（Eye-in-Hand）** | 戴在手上的放大镜 | 相机装在机器人法兰 / 手臂末端，跟着机器人一起动；标定板固定在工作台上 | 精细装配、大工件局部检测、跟随式抓取         |

## 二、基本原理：核心就是「坐标系换算」

### 1. 核心逻辑：4 个坐标系的拼图游戏

手眼标定的本质，就是通过已知的坐标系关系，推算出未知的「相机 - 机器人」固定关系。

以最常用的**眼固定**为例：

- 已知 1：相机拍标定板，能算出「标定板在相机坐标系里的位置和角度」；
- 已知 2：机器人带动标定板，能从控制器读出「标定板在机器人基座坐标系里的位置和角度」；
- 未知：相机坐标系 和 机器人基座坐标系 之间的固定位置 / 角度关系（就是我们要求的手眼矩阵）。

通过采集**十几组不同位姿**的数据，就能通过数学计算，解出这个固定的换算关系。以后相机拍到任意工件，就能直接算出它在机器人地图里的精准坐标。

> 打个比方：
>
> 你知道 A 点到 B 点的距离方向，也知道 A 点到 C 点的距离方向，自然就能算出 B 点和 C 点的固定关系；多测几组不同位置的 A 点，结果就会更准。

### 2. 换算的核心：变换矩阵

最终算出来的「换算规则」，就是一个**4×4 的齐次变换矩阵**，不用深究数学，你只要知道它包含两部分：

- **旋转关系**：相机和机器人的角度差，比如相机装歪了 5 度，机器人要补偿回来；
- **平移关系**：相机原点和机器人原点的距离差，比如相机在机器人底座右上方 300mm 处。

所有坐标转换，本质就是「像素坐标 → 相机三维坐标 → 乘手眼矩阵 → 机器人基座坐标」三步。

## 三、实现方法：一步步做完标定

工业场景不用自己写算法，主流工具（Halcon、OpenCV、机器人厂商自带标定工具）都封装好了，只要按步骤采集数据就行。下面以 ** 最常用的眼固定（Eye-to-Hand）** 为例，讲通用步骤。

### 第一步：准备标定工具

1. **标定板**：最常用的是棋盘格标定板（黑白相间的方格，尺寸精度极高），优先选玻璃 / 陶瓷材质，平整不变形；不要用普通打印纸贴木板，容易翘曲导致误差。
2. **硬件就绪**：相机 + 镜头固定好，焦距、光圈调好，图像清晰；机器人能正常运动，重复定位精度达标。
3. **先做相机内参标定**：先标定相机自身的参数（焦距、镜头畸变、主点位置），就像先给相机「测视力」，校正镜头的变形。内参不准，手眼标定再怎么做都白搭。

### 第二步：采集标定数据（最影响精度的一步）

核心要求：**标定板带动到不同位置、不同角度，全程在相机视野内，每组数据对应一组机器人位姿 + 一张标定板照片**。

#### 眼固定采集规则（相机不动，标定板装在机器人法兰上）

1. 把标定板牢固装在机器人夹具上，和法兰相对位置固定；
2. 控制机器人，让标定板走到相机视野里，拍一张照，同时记录当前机器人的**法兰位姿**（XYZ + 旋转角度，机器人控制器直接可读）；
3. 改变机器人的位置和角度，重复拍照 + 记录位姿，一般采集 **15~25 组** 最合适。

#### 采集位姿的黄金原则（直接决定精度）

- **要有平移变化**：上下左右前后都要走到，覆盖你实际工作的全部范围；
- **要有旋转变化**：俯仰、左右摆、自转都要有一定角度（每轴转 15~30 度），不能只平移不旋转；
- **不要离工作区太远**：标定范围必须覆盖实际生产的区域，只在中间标定、边缘干活，误差会急剧放大；
- **停稳再拍照**：机器人到位后等 0.5~1 秒再拍，避免抖动模糊、位姿不准。

### 第三步：计算手眼矩阵

把采集到的「N 组机器人位姿」和「N 组标定板在相机下的位姿」，输入标定工具：

- Halcon：`calibrate_hand_eye` 算子
- OpenCV：`cv2.calibrateHandEye` 函数
- 机器人厂商：发那科、ABB、汇川等都有自带的视觉标定向导，跟着界面点就行

工具会自动计算出最终的**手眼变换矩阵**，也就是相机坐标系到机器人基座坐标系的转换规则。

### 第四步：验证精度（必做！）

标定完绝对不能直接上线，必须验证：

1. 把标定板放在工作区域的四角、中心等 5~10 个位置；
2. 相机识别标定板中心，用手眼矩阵转换成机器人坐标；
3. 让机器人走到这个坐标，看机器人尖端和标定板中心的偏差；
4. 工业抓取一般要求误差 ≤ 0.1~0.5mm（根据工艺要求），超了就重新采集数据标定。

## 四、避坑指南：90% 的标定误差都来自这些问题

### 1. 标定板本身不合格

- ❌ 坑：用 A4 纸打印棋盘格贴在木板上，纸张翘曲、尺寸不准；
- ✅ 正确：用工业级陶瓷 / 玻璃标定板，精度 μm 级，平整不变形。

### 2. 采集位姿太 “单调”

- ❌ 坑：只平移不旋转，或者都在一个平面上小范围移动；
- ✅ 正确：三个轴的平移、三个轴的旋转都要有变化，角度变化越大，计算越准（别转出视野就行）。

### 3. 标定范围和工作范围不匹配

- ❌ 坑：只在视野中心一小块标定，实际生产要用到边缘；
- ✅ 正确：标定范围要≥实际工作范围，工作区域的边角都要覆盖到。

### 4. 机器人没停稳就拍照

- ❌ 坑：机器人刚到位就触发拍照，机械抖动导致位姿不准、图像模糊；
- ✅ 正确：加延时，或者用到位信号稳定后再拍照。

### 5. 忽略镜头畸变

- ❌ 坑：不做内参标定，直接用像素坐标换算，广角镜头边缘畸变很大，越靠边误差越大；
- ✅ 正确：先标定相机内参，校正畸变后再做手眼标定。

### 6. 光源不稳定、图像模糊

- ❌ 坑：光源忽明忽暗、对焦不准，标定板角点检测误差大；
- ✅ 正确：用稳定的工业光源，对焦清晰，保证角点检测精度。

### 7. 机械结构松动

- ❌ 坑：相机支架晃、标定板装歪、夹具松动，标定完一碰就变；
- ✅ 正确：所有结构刚性固定，标定完不要碰相机和镜头。

## 五、完整实例：传送带抓取工位手眼标定

### 场景说明

- 结构：眼固定（Eye-to-Hand），相机装在传送带上方 1 米处，固定不动；
- 设备：六轴工业机器人 + 500 万像素工业相机 + 8mm 镜头 + 12×9 棋盘格标定板（方格边长 10mm）；
- 需求：相机拍到传送带上的工件，换算成机器人坐标，机器人精准抓取。

### 步骤 1：相机内参标定（先给相机 “测视力”）

1. 固定相机和镜头，调好焦距光圈，锁死；
2. 拿标定板在相机视野里，不同角度、不同位置拍 20 张照片；
3. 用 Halcon 内参标定工具计算，得到相机内参（焦距、主点、畸变系数），后续所有图像都先用这个内参校正畸变。

### 步骤 2：采集 20 组手眼数据

1. 把标定板牢牢装在机器人法兰的夹具上，确认不松动；
2. 手动操控机器人，让标定板进入相机视野中心，位置 1：
   - 记录机器人法兰位姿：`X=500, Y=300, Z=200, Rx=0, Ry=0, Rz=0`（单位 mm / 度）
   - 相机拍 1 张图，识别出标定板在相机坐标系的位姿
3. 移动机器人，变换位置和角度，依次采集位置 2~ 位置 20：
   - 覆盖：X 方向 ±100mm，Y 方向 ±100mm，Z 方向 ±50mm
   - 旋转：Rx/Ry/Rz 各偏转 ±20 度
   - 保证所有位置标定板都完整在视野内
4. 最终得到 20 组「机器人法兰位姿 + 对应标定板相机位姿」的数据对。

### 步骤 3：计算手眼矩阵

把 20 组数据导入 Halcon 手眼标定算子，选择「眼固定（stationary camera）」模式，运行计算，得到最终的手眼变换矩阵：

- 简化理解：相机原点在机器人基座坐标系的位置为 `X=400mm, Y=200mm, Z=1000mm`，三个轴角度完全对齐（实际会有微小偏差）。

### 步骤 4：精度验证

1. 把标定板放在工作区左上角，相机识别中心像素坐标，换算成相机三维坐标 `(20, 30, 100)`（单位 mm）；
2. 乘手眼矩阵，得到机器人基座坐标：
   - X = 400 + 20 = 420mm
   - Y = 200 + 30 = 230mm
   - Z = 1000 - 100 = 900mm
3. 让机器人移动到这个坐标，观察法兰中心和标定板中心的偏差；
4. 测试 5 个不同位置，平均偏差 0.08mm，最大 0.12mm，满足抓取精度要求，标定完成。

### 步骤 5：上线使用

实际生产时：

1. 相机拍到工件，识别中心像素坐标；
2. 通过内参把像素坐标转成相机坐标系下的三维坐标；
3. 乘手眼变换矩阵，得到机器人基座坐标系下的坐标；
4. 把坐标发给机器人，机器人移动到对应位置完成抓取。

## 六、补充：眼在手上和眼固定的核心区别

| 对比项     | 眼固定（Eye-to-Hand）         | 眼在手上（Eye-in-Hand）       |
| :--------- | :---------------------------- | :---------------------------- |
| 标定板位置 | 装在机器人法兰上，随机器人动  | 固定在工作台上，不动          |
| 求的关系   | 相机坐标系 → 机器人基座坐标系 | 相机坐标系 → 机器人法兰坐标系 |
| 优点       | 视野固定，全程监控，结构简单  | 靠近工件精度高，可随动检测    |
| 缺点       | 工作范围受视野限制            | 线缆容易随手臂缠绕            |
| 适用       | 传送带、固定工位检测抓取      | 精细装配、大工件局部检测      |

------

## 一句话总结

手眼标定不是什么高深玄学，就是**通过多组已知位置，算出相机和机器人的坐标换算公式**，核心是采集数据要到位、覆盖全、有角度变化，标定完必须验证精度。
