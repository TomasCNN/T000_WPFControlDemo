# 999999002_999999001脚本优化及解析

针对原脚本的**手动列文件易遗漏、无错误处理、无日志、残留旧文件、路径不安全**等问题，我做了全面优化，完全适配工业上位机远程调试场景，**新增依赖不用改脚本、自动错误捕获、详细日志、自动清理旧版本**。

**优化版完整脚本（直接复制替换原脚本）**

```bat
@echo off
setlocal enabledelayedexpansion

REM ==============================================
REM 【配置区】所有可修改参数都在这里，不用改下面逻辑
REM ==============================================
set "REMOTE_DEBUG_ENABLED=$(RemoteDebugEnabled)"
set "LOCAL_TARGET_DIR=$(TargetDir)"
set "REMOTE_MACHINE=$(RemoteDebugMachine)"
set "REMOTE_DRIVE=D"  REM 远程机器盘符
set "LOG_FILE=$(TargetDir)\remote_sync.log"  REM 日志文件路径
set "RETRY_COUNT=3"   REM 拷贝失败重试次数
set "DELETE_OLD_FILES=true"  REM 是否删除远程多余文件（true=完整同步，false=只覆盖）
set "EXCLUDE_FILES=*.config|*.json|*.xml"  REM 不覆盖的配置文件（用|分隔）

REM ==============================================
REM 【总开关】远程调试未启用则直接退出
REM ==============================================
if /i "%REMOTE_DEBUG_ENABLED%"=="false" (
    echo [INFO] 远程调试已关闭，跳过文件同步
    goto :eof
)

REM ==============================================
REM 【初始化】路径处理与日志
REM ==============================================
call :LOG "=============================="
call :LOG "开始远程同步：$(ProjectName)"
call :LOG "本地目录：%LOCAL_TARGET_DIR%"

REM 拼接远程路径（自动剔除本地盘符）
set "LOCAL_PATH_NO_DRIVE=%LOCAL_TARGET_DIR:~3%"
set "REMOTE_TARGET_DIR=\\%REMOTE_MACHINE%\%REMOTE_DRIVE%\%LOCAL_PATH_NO_DRIVE%"
call :LOG "远程目录：%REMOTE_TARGET_DIR%"
call :LOG "=============================="

REM ==============================================
REM 【步骤1】创建远程目录
REM ==============================================
call :LOG "[1/3] 创建远程目录..."
mkdir "%REMOTE_TARGET_DIR%" 2>nul
if %errorlevel% neq 0 (
    call :LOG "[ERROR] 无法创建远程目录，请检查："
    call :LOG "  1. 远程机器是否开启文件共享"
    call :LOG "  2. 当前用户是否有远程目录读写权限"
    call :LOG "  3. 远程机器IP/计算机名是否正确"
    goto :ERROR_EXIT
)

REM ==============================================
REM 【步骤2】删除远程旧文件（可选）
REM ==============================================
if /i "%DELETE_OLD_FILES%"=="true" (
    call :LOG "[2/3] 清理远程旧文件..."
    for %%f in ("%REMOTE_TARGET_DIR%\*.exe", "%REMOTE_TARGET_DIR%\*.dll", "%REMOTE_TARGET_DIR%\*.pdb") do (
        REM 跳过排除列表中的文件
        echo "%%~nxf" | findstr /i /v "%EXCLUDE_FILES%" >nul
        if !errorlevel! equ 0 (
            del /f /q "%%f" 2>nul
        )
    )
)

REM ==============================================
REM 【步骤3】自动拷贝所有必要文件（核心优化）
REM ==============================================
call :LOG "[3/3] 开始同步文件..."
set "COPY_SUCCESS=true"

REM 拷贝主程序和依赖库（自动识别所有exe/dll/pdb）
for %%ext in (exe dll pdb) do (
    for %%f in ("%LOCAL_TARGET_DIR%\*.%%ext") do (
        REM 跳过排除列表中的文件
        echo "%%~nxf" | findstr /i /v "%EXCLUDE_FILES%" >nul
        if !errorlevel! equ 0 (
            call :COPY_FILE "%%f" "%REMOTE_TARGET_DIR%"
            if !errorlevel! neq 0 set "COPY_SUCCESS=false"
        )
    )
)

REM ==============================================
REM 【结果处理】
REM ==============================================
if /i "%COPY_SUCCESS%"=="true" (
    call :LOG "=============================="
    call :LOG "✅ 远程同步完成！"
    call :LOG "=============================="
    endlocal
    goto :eof
) else (
    goto :ERROR_EXIT
)

REM ==============================================
REM 【工具函数】带重试的文件拷贝
REM ==============================================
:COPY_FILE
set "SRC=%~1"
set "DEST=%~2"
set "FILENAME=%~nx1"

for /l %%i in (1,1,%RETRY_COUNT%) do (
    copy /y "%SRC%" "%DEST%" >nul 2>&1
    if %errorlevel% equ 0 (
        call :LOG "  ✓ %FILENAME%"
        exit /b 0
    )
    call :LOG "  ⚠️  第%%i次拷贝失败，重试中：%FILENAME%"
    ping -n 1 127.0.0.1 >nul 2>&1  REM 等待1秒
)

call :LOG "  ❌ 拷贝失败（重试%RETRY_COUNT%次）：%FILENAME%"
exit /b 1

REM ==============================================
REM 【工具函数】统一日志输出（控制台+文件）
REM ==============================================
:LOG
echo %~1
echo [%date% %time%] %~1 >> "%LOG_FILE%"
exit /b 0

REM ==============================================
REM 【错误退出】
REM ==============================================
:ERROR_EXIT
call :LOG "=============================="
call :LOG "❌ 远程同步失败！"
call :LOG "详细日志请查看：%LOG_FILE%"
call :LOG "=============================="
endlocal
exit /b 1
```

| :------------------------------- | :----------------------------------------------------- |

| 拷贝失败无提示，不知道哪里错了   | 每一步都有错误检查，失败时给出明确原因和解决方案       |

## 关键功能说明

### 1. 自动文件扫描（最实用）

原脚本需要手动写每一个`copy`命令，新增 dll 就要改脚本，非常容易漏。

优化后自动扫描本地输出目录下的所有：

- `.exe` 主程序
- `.dll` 所有依赖库
- `.pdb` 所有调试符号文件

**新增任何依赖都不用改脚本**，编译后自动同步。

### 2. 配置文件保护

工业上位机的配置文件（`app.config`、`settings.json`等）在远程机器上是定制化的，不能被本地覆盖。

通过`EXCLUDE_FILES`参数配置排除列表，多个文件用`|`分隔：

batch:

```bat
set "EXCLUDE_FILES=*.config|*.json|*.xml|settings.ini"
```

### 3. 完整同步模式

开启`DELETE_OLD_FILES=true`后，会先删除远程目录下所有旧的 exe/dll/pdb，再拷贝新文件，彻底避免旧版本残留导致的诡异问题。

如果只想覆盖不删除，设为`false`即可。

### 4. 自动重试机制

网络波动、远程文件被占用时，会自动重试 3 次，大幅提高同步成功率。

### 5. 详细日志

每次同步都会在本地输出目录生成`remote_sync.log`文件，记录：

- 同步开始 / 结束时间
- 本地和远程路径
- 每个文件的拷贝结果
- 错误信息和原因

## 使用方法

1. 右键你的 WPF 项目 → 属性 → 生成事件

2. 删除原来的生成后事件命令行

3. 把上面的优化版脚本完整粘贴进去

4. 配置 VS 远程调试：

   - 右键项目 → 属性 → 调试
   - 选择 "远程计算机"，输入你的远程机器 IP / 计算机名
   - 勾选 "启用远程调试"

## 常见问题解决

### 1. 提示 "无法创建远程目录"

- 远程机器开启 "文件和打印机共享"
- 远程机器的 D 盘设置共享，允许当前用户读写
- 关闭远程机器的防火墙（或添加文件共享例外）
- 测试：在资源管理器输入`\\远程机器IP\D`，看能否正常访问

### 2. 拷贝文件失败

- 远程机器上的程序正在运行，文件被占用
- 远程目录权限不足
- 网络断开

### 3. 不想同步某个 dll

把它添加到排除列表即可：

batch:

```bat
set "EXCLUDE_FILES=*.config|*.json|不需要的dll.dll"
```

## 终极增强（可选）

如果需要同步子目录（比如`Plugins`、`Config`等文件夹），在步骤 3 后面添加这段代码：

batch:

```
REM 同步所有子目录（递归）
xcopy /s /e /y /i /r "%LOCAL_TARGET_DIR%\*" "%REMOTE_TARGET_DIR%" /exclude:%EXCLUDE_FILES% >nul 2>&1
```
