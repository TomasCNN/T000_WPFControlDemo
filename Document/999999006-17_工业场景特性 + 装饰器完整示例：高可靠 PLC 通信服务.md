# 999999006-17_工业场景特性 + 装饰器完整示例：高可靠 PLC 通信服务

这是一个**真实工业自动化场景**的完整实现，展示了特性与装饰器的最佳结合方式：**用特性声明配置元数据，用装饰器实现横切关注点**。我们将构建一个支持**自动重试、日志记录、性能监控、超时控制和异常报警**的高可靠 PLC 通信服务。

## 一、架构设计

plaintext:

```tex
┌─────────────────────────────────────────────────────────┐
│  业务逻辑层：PlcCommunicationService                    │
│  核心功能：读写寄存器、执行PLC命令                       │
└───────────────────────────┬─────────────────────────────┘
                            │
┌───────────────────────────▼─────────────────────────────┐
│  特性层：声明式配置                                      │
│  [Retry] [LogExecution] [Timeout] [PlcCommand]          │
└───────────────────────────┬─────────────────────────────┘
                            │
┌───────────────────────────▼─────────────────────────────┐
│  装饰器层：横切关注点                                    │
│  RetryDecorator → LoggingDecorator → TimeoutDecorator   │
└───────────────────────────┬─────────────────────────────┘
                            │
┌───────────────────────────▼─────────────────────────────┐
│  调用方：透明使用包装后的服务                            │
└─────────────────────────────────────────────────────────┘
```

**核心原则**：

- 特性：只负责**声明配置**，不包含任何执行逻辑
- 装饰器：只负责**实现横切逻辑**，不包含任何业务逻辑
- 业务服务：只负责**核心业务逻辑**，不关心横切关注点

## 二、第一步：定义特性集

所有特性都是纯粹的元数据容器，用于标记需要特殊处理的方法并提供配置参数。

csharp:

```c#
using System;

namespace IndustrialAutomation.Core.Attributes
{
    /// <summary>
    /// 自动重试特性：标记方法失败时自动重试
    /// </summary>
    [AttributeUsage(AttributeTargets.Method, Inherited = false)]
    public sealed class RetryAttribute : Attribute
    {
        /// <summary>
        /// 最大重试次数
        /// </summary>
        public int MaxRetries { get; }
        
        /// <summary>
        /// 初始重试间隔(ms)
        /// </summary>
        public int InitialDelayMs { get; }
        
        /// <summary>
        /// 是否使用指数退避
        /// </summary>
        public bool UseExponentialBackoff { get; }
        
        /// <summary>
        /// 需要重试的异常类型
        /// </summary>
        public Type[] RetryableExceptions { get; }

        public RetryAttribute(int maxRetries = 3, int initialDelayMs = 100, 
            bool useExponentialBackoff = true, params Type[] retryableExceptions)
        {
            MaxRetries = maxRetries;
            InitialDelayMs = initialDelayMs;
            UseExponentialBackoff = useExponentialBackoff;
            RetryableExceptions = retryableExceptions ?? new[] { typeof(IOException) };
        }
    }

    /// <summary>
    /// 执行日志特性：标记方法需要记录执行日志
    /// </summary>
    [AttributeUsage(AttributeTargets.Method, Inherited = false)]
    public sealed class LogExecutionAttribute : Attribute
    {
        /// <summary>
        /// 操作名称
        /// </summary>
        public string OperationName { get; }
        
        /// <summary>
        /// 是否记录参数
        /// </summary>
        public bool LogParameters { get; }
        
        /// <summary>
        /// 是否记录返回值
        /// </summary>
        public bool LogReturnValue { get; }
        
        /// <summary>
        /// 是否记录执行时间
        /// </summary>
        public bool LogExecutionTime { get; }

        public LogExecutionAttribute(string operationName, 
            bool logParameters = true, bool logReturnValue = false, 
            bool logExecutionTime = true)
        {
            OperationName = operationName;
            LogParameters = logParameters;
            LogReturnValue = logReturnValue;
            LogExecutionTime = logExecutionTime;
        }
    }

    /// <summary>
    /// 超时控制特性：标记方法的最大执行时间
    /// </summary>
    [AttributeUsage(AttributeTargets.Method, Inherited = false)]
    public sealed class TimeoutAttribute : Attribute
    {
        /// <summary>
        /// 超时时间(ms)
        /// </summary>
        public int TimeoutMs { get; }

        public TimeoutAttribute(int timeoutMs)
        {
            TimeoutMs = timeoutMs;
        }
    }

    /// <summary>
    /// PLC命令特性：标记PLC命令的元数据
    /// </summary>
    [AttributeUsage(AttributeTargets.Method, Inherited = false)]
    public sealed class PlcCommandAttribute : Attribute
    {
        /// <summary>
        /// 功能码
        /// </summary>
        public byte FunctionCode { get; }
        
        /// <summary>
        /// 命令描述
        /// </summary>
        public string Description { get; }

        public PlcCommandAttribute(byte functionCode, string description)
        {
            FunctionCode = functionCode;
            Description = description;
        }
    }
}
```

## 三、第二步：定义服务接口与业务实现

业务服务只包含核心 PLC 通信逻辑，完全不关心重试、日志等横切关注点。

csharp:

```c#
using System;
using System.IO;
using System.Net.Sockets;
using Modbus.Device;

namespace IndustrialAutomation.Core.Services
{
    /// <summary>
    /// PLC通信服务接口
    /// </summary>
    public interface IPlcCommunicationService
    {
        /// <summary>
        /// 读取保持寄存器
        /// </summary>
        ushort[] ReadHoldingRegisters(ushort startAddress, ushort length);
        
        /// <summary>
        /// 写入单个保持寄存器
        /// </summary>
        void WriteSingleRegister(ushort address, ushort value);
        
        /// <summary>
        /// 执行自定义PLC命令
        /// </summary>
        byte[] ExecuteCustomCommand(byte[] commandData);
        
        /// <summary>
        /// 连接到PLC
        /// </summary>
        bool Connect(string ipAddress, int port = 502);
        
        /// <summary>
        /// 断开连接
        /// </summary>
        void Disconnect();
    }

    /// <summary>
    /// Modbus TCP PLC通信服务实现
    /// </summary>
    public class ModbusTcpPlcService : IPlcCommunicationService
    {
        private TcpClient _tcpClient;
        private ModbusIpMaster _modbusMaster;
        private readonly byte _slaveId;

        public ModbusTcpPlcService(byte slaveId = 1)
        {
            _slaveId = slaveId;
        }

        [LogExecution("连接PLC", logParameters: true)]
        [Retry(maxRetries: 5, initialDelayMs: 500, retryableExceptions: new[] { typeof(SocketException) })]
        [Timeout(3000)]
        public bool Connect(string ipAddress, int port = 502)
        {
            _tcpClient = new TcpClient();
            _tcpClient.Connect(ipAddress, port);
            _modbusMaster = ModbusIpMaster.CreateIp(_tcpClient);
            _modbusMaster.Transport.ReadTimeout = 2000;
            _modbusMaster.Transport.WriteTimeout = 2000;
            
            return _tcpClient.Connected;
        }

        [LogExecution("断开PLC连接")]
        public void Disconnect()
        {
            _modbusMaster?.Dispose();
            _tcpClient?.Close();
        }

        [LogExecution("读取保持寄存器", logReturnValue: true)]
        [Retry(maxRetries: 3, initialDelayMs: 100)]
        [Timeout(1000)]
        [PlcCommand(0x03, "读取保持寄存器")]
        public ushort[] ReadHoldingRegisters(ushort startAddress, ushort length)
        {
            if (_modbusMaster == null || !_tcpClient.Connected)
                throw new InvalidOperationException("PLC未连接");

            return _modbusMaster.ReadHoldingRegisters(_slaveId, startAddress, length);
        }

        [LogExecution("写入单个保持寄存器", logParameters: true)]
        [Retry(maxRetries: 3, initialDelayMs: 100)]
        [Timeout(1000)]
        [PlcCommand(0x06, "写入单个保持寄存器")]
        public void WriteSingleRegister(ushort address, ushort value)
        {
            if (_modbusMaster == null || !_tcpClient.Connected)
                throw new InvalidOperationException("PLC未连接");

            _modbusMaster.WriteSingleRegister(_slaveId, address, value);
        }

        [LogExecution("执行自定义PLC命令", logParameters: true, logReturnValue: true)]
        [Retry(maxRetries: 2, initialDelayMs: 200)]
        [Timeout(2000)]
        [PlcCommand(0x41, "自定义命令")]
        public byte[] ExecuteCustomCommand(byte[] commandData)
        {
            if (_modbusMaster == null || !_tcpClient.Connected)
                throw new InvalidOperationException("PLC未连接");

            // 模拟自定义命令执行
            // 实际项目中这里会发送自定义Modbus功能码
            return new byte[] { 0x41, 0x00, 0x01 };
        }
    }
}
```

**关键点**：

- 业务代码极其简洁，只关注核心通信逻辑
- 所有横切关注点通过特性声明
- 不同方法可以有不同的配置（重试次数、超时时间等）

## 四、第三步：实现装饰器

每个装饰器实现一个单一的横切关注点，通过读取方法上的特性获取配置。

### 4.1 基础装饰器抽象类

csharp:

```c#
using System;
using System.Reflection;
using System.Threading.Tasks;

namespace IndustrialAutomation.Core.Decorators
{
    /// <summary>
    /// 装饰器基类：实现装饰器模式的基础结构
    /// </summary>
    public abstract class PlcServiceDecoratorBase : IPlcCommunicationService
    {
        protected readonly IPlcCommunicationService _innerService;

        protected PlcServiceDecoratorBase(IPlcCommunicationService innerService)
        {
            _innerService = innerService;
        }

        public virtual bool Connect(string ipAddress, int port = 502)
        {
            return _innerService.Connect(ipAddress, port);
        }

        public virtual void Disconnect()
        {
            _innerService.Disconnect();
        }

        public virtual ushort[] ReadHoldingRegisters(ushort startAddress, ushort length)
        {
            return _innerService.ReadHoldingRegisters(startAddress, length);
        }

        public virtual void WriteSingleRegister(ushort address, ushort value)
        {
            _innerService.WriteSingleRegister(address, value);
        }

        public virtual byte[] ExecuteCustomCommand(byte[] commandData)
        {
            return _innerService.ExecuteCustomCommand(commandData);
        }

        /// <summary>
        /// 获取方法上的指定特性
        /// </summary>
        protected TAttribute GetAttribute<TAttribute>(string methodName) 
            where TAttribute : Attribute
        {
            var method = typeof(IPlcCommunicationService).GetMethod(methodName);
            return method?.GetCustomAttribute<TAttribute>();
        }
    }
}
```

### 4.2 自动重试装饰器

csharp:

```c#
using System;
using System.Threading;

namespace IndustrialAutomation.Core.Decorators
{
    /// <summary>
    /// 自动重试装饰器：根据[Retry]特性自动重试失败的操作
    /// </summary>
    public class RetryDecorator : PlcServiceDecoratorBase
    {
        public RetryDecorator(IPlcCommunicationService innerService) 
            : base(innerService) { }

        public override ushort[] ReadHoldingRegisters(ushort startAddress, ushort length)
        {
            var attribute = GetAttribute<RetryAttribute>(nameof(ReadHoldingRegisters));
            return attribute == null 
                ? base.ReadHoldingRegisters(startAddress, length) 
                : ExecuteWithRetry(() => base.ReadHoldingRegisters(startAddress, length), attribute);
        }

        public override void WriteSingleRegister(ushort address, ushort value)
        {
            var attribute = GetAttribute<RetryAttribute>(nameof(WriteSingleRegister));
            if (attribute == null)
            {
                base.WriteSingleRegister(address, value);
                return;
            }

            ExecuteWithRetry(() => 
            {
                base.WriteSingleRegister(address, value);
                return (object)null;
            }, attribute);
        }

        public override bool Connect(string ipAddress, int port = 502)
        {
            var attribute = GetAttribute<RetryAttribute>(nameof(Connect));
            return attribute == null 
                ? base.Connect(ipAddress, port) 
                : ExecuteWithRetry(() => base.Connect(ipAddress, port), attribute);
        }

        public override byte[] ExecuteCustomCommand(byte[] commandData)
        {
            var attribute = GetAttribute<RetryAttribute>(nameof(ExecuteCustomCommand));
            return attribute == null 
                ? base.ExecuteCustomCommand(commandData) 
                : ExecuteWithRetry(() => base.ExecuteCustomCommand(commandData), attribute);
        }

        /// <summary>
        /// 执行带重试的操作
        /// </summary>
        private T ExecuteWithRetry<T>(Func<T> operation, RetryAttribute attribute)
        {
            int retryCount = 0;
            while (true)
            {
                try
                {
                    return operation();
                }
                catch (Exception ex)
                {
                    if (retryCount >= attribute.MaxRetries || !IsRetryable(ex, attribute))
                        throw;

                    retryCount++;
                    int delay = attribute.UseExponentialBackoff 
                        ? attribute.InitialDelayMs * (int)Math.Pow(2, retryCount - 1) 
                        : attribute.InitialDelayMs;

                    Console.WriteLine($"操作失败，{delay}ms后进行第{retryCount}次重试：{ex.Message}");
                    Thread.Sleep(delay);
                }
            }
        }

        /// <summary>
        /// 检查异常是否可重试
        /// </summary>
        private bool IsRetryable(Exception ex, RetryAttribute attribute)
        {
            foreach (var exceptionType in attribute.RetryableExceptions)
            {
                if (exceptionType.IsInstanceOfType(ex))
                    return true;
            }
            return false;
        }
    }
}
```

### 4.3 执行日志装饰器

csharp:

```c#
using System;
using System.Diagnostics;
using System.Linq;

namespace IndustrialAutomation.Core.Decorators
{
    /// <summary>
    /// 执行日志装饰器：根据[LogExecution]特性记录方法执行日志
    /// </summary>
    public class LoggingDecorator : PlcServiceDecoratorBase
    {
        public LoggingDecorator(IPlcCommunicationService innerService) 
            : base(innerService) { }

        public override ushort[] ReadHoldingRegisters(ushort startAddress, ushort length)
        {
            var attribute = GetAttribute<LogExecutionAttribute>(nameof(ReadHoldingRegisters));
            return attribute == null 
                ? base.ReadHoldingRegisters(startAddress, length) 
                : ExecuteWithLogging(() => base.ReadHoldingRegisters(startAddress, length), attribute, startAddress, length);
        }

        public override void WriteSingleRegister(ushort address, ushort value)
        {
            var attribute = GetAttribute<LogExecutionAttribute>(nameof(WriteSingleRegister));
            if (attribute == null)
            {
                base.WriteSingleRegister(address, value);
                return;
            }

            ExecuteWithLogging(() => 
            {
                base.WriteSingleRegister(address, value);
                return (object)null;
            }, attribute, address, value);
        }

        public override bool Connect(string ipAddress, int port = 502)
        {
            var attribute = GetAttribute<LogExecutionAttribute>(nameof(Connect));
            return attribute == null 
                ? base.Connect(ipAddress, port) 
                : ExecuteWithLogging(() => base.Connect(ipAddress, port), attribute, ipAddress, port);
        }

        public override byte[] ExecuteCustomCommand(byte[] commandData)
        {
            var attribute = GetAttribute<LogExecutionAttribute>(nameof(ExecuteCustomCommand));
            return attribute == null 
                ? base.ExecuteCustomCommand(commandData) 
                : ExecuteWithLogging(() => base.ExecuteCustomCommand(commandData), attribute, commandData);
        }

        /// <summary>
        /// 执行带日志的操作
        /// </summary>
        private T ExecuteWithLogging<T>(Func<T> operation, LogExecutionAttribute attribute, params object[] parameters)
        {
            var stopwatch = Stopwatch.StartNew();
            try
            {
                // 前置日志
                if (attribute.LogParameters)
                {
                    string paramStr = string.Join(", ", parameters.Select(p => p?.ToString() ?? "null"));
                    Console.WriteLine($"[{DateTime.Now:HH:mm:ss.fff}] 开始执行 {attribute.OperationName}，参数：{paramStr}");
                }
                else
                {
                    Console.WriteLine($"[{DateTime.Now:HH:mm:ss.fff}] 开始执行 {attribute.OperationName}");
                }

                // 执行操作
                var result = operation();

                // 成功后置日志
                if (attribute.LogExecutionTime)
                {
                    Console.WriteLine($"[{DateTime.Now:HH:mm:ss.fff}] 执行 {attribute.OperationName} 成功，耗时：{stopwatch.ElapsedMilliseconds}ms");
                }
                else
                {
                    Console.WriteLine($"[{DateTime.Now:HH:mm:ss.fff}] 执行 {attribute.OperationName} 成功");
                }

                if (attribute.LogReturnValue && result != null)
                {
                    Console.WriteLine($"[{DateTime.Now:HH:mm:ss.fff}] 返回值：{result}");
                }

                return result;
            }
            catch (Exception ex)
            {
                // 失败后置日志
                Console.WriteLine($"[{DateTime.Now:HH:mm:ss.fff}] 执行 {attribute.OperationName} 失败，耗时：{stopwatch.ElapsedMilliseconds}ms，错误：{ex.Message}");
                throw;
            }
        }
    }
}
```

### 4.4 超时控制装饰器

csharp:

```c#
using System;
using System.Threading;
using System.Threading.Tasks;

namespace IndustrialAutomation.Core.Decorators
{
    /// <summary>
    /// 超时控制装饰器：根据[Timeout]特性限制方法最大执行时间
    /// </summary>
    public class TimeoutDecorator : PlcServiceDecoratorBase
    {
        public TimeoutDecorator(IPlcCommunicationService innerService) 
            : base(innerService) { }

        public override ushort[] ReadHoldingRegisters(ushort startAddress, ushort length)
        {
            var attribute = GetAttribute<TimeoutAttribute>(nameof(ReadHoldingRegisters));
            return attribute == null 
                ? base.ReadHoldingRegisters(startAddress, length) 
                : ExecuteWithTimeout(() => base.ReadHoldingRegisters(startAddress, length), attribute.TimeoutMs);
        }

        public override void WriteSingleRegister(ushort address, ushort value)
        {
            var attribute = GetAttribute<TimeoutAttribute>(nameof(WriteSingleRegister));
            if (attribute == null)
            {
                base.WriteSingleRegister(address, value);
                return;
            }

            ExecuteWithTimeout(() => 
            {
                base.WriteSingleRegister(address, value);
                return (object)null;
            }, attribute.TimeoutMs);
        }

        public override bool Connect(string ipAddress, int port = 502)
        {
            var attribute = GetAttribute<TimeoutAttribute>(nameof(Connect));
            return attribute == null 
                ? base.Connect(ipAddress, port) 
                : ExecuteWithTimeout(() => base.Connect(ipAddress, port), attribute.TimeoutMs);
        }

        public override byte[] ExecuteCustomCommand(byte[] commandData)
        {
            var attribute = GetAttribute<TimeoutAttribute>(nameof(ExecuteCustomCommand));
            return attribute == null 
                ? base.ExecuteCustomCommand(commandData) 
                : ExecuteWithTimeout(() => base.ExecuteCustomCommand(commandData), attribute.TimeoutMs);
        }

        /// <summary>
        /// 执行带超时的操作
        /// </summary>
        private T ExecuteWithTimeout<T>(Func<T> operation, int timeoutMs)
        {
            var task = Task.Run(operation);
            if (!task.Wait(timeoutMs))
            {
                throw new TimeoutException($"操作执行超时，超过{timeoutMs}ms");
            }
            return task.Result;
        }
    }
}
```

## 五、第四步：装饰器工厂

创建一个工厂类，自动根据特性应用对应的装饰器，避免手动嵌套。

csharp:

```c#
using System;

namespace IndustrialAutomation.Core.Decorators
{
    /// <summary>
    /// PLC服务装饰器工厂：自动应用所有装饰器
    /// </summary>
    public static class PlcServiceDecoratorFactory
    {
        /// <summary>
        /// 创建包装了所有装饰器的PLC服务实例
        /// </summary>
        public static IPlcCommunicationService CreateDecoratedService(IPlcCommunicationService service)
        {
            // 装饰器顺序：超时 → 重试 → 日志
            // 注意：最内层的装饰器最先执行
            IPlcCommunicationService decoratedService = service;
            decoratedService = new TimeoutDecorator(decoratedService);
            decoratedService = new RetryDecorator(decoratedService);
            decoratedService = new LoggingDecorator(decoratedService);
            
            return decoratedService;
        }
    }
}
```

**装饰器执行顺序**：

1. 调用方 → LoggingDecorator（记录开始日志）
2. → RetryDecorator（处理重试）
3. → TimeoutDecorator（控制超时）
4. → 实际业务服务
5. ← TimeoutDecorator
6. ← RetryDecorator
7. ← LoggingDecorator（记录结束日志）
8. 返回调用方

## 六、第五步：使用示例

展示如何在实际业务中使用这个架构。

csharp:

```c#
using System;
using IndustrialAutomation.Core.Decorators;
using IndustrialAutomation.Core.Services;

namespace IndustrialAutomation.ProductionLine
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("=== 工业PLC通信服务示例 ===");
            Console.WriteLine();

            // 创建原始PLC服务
            var rawPlcService = new ModbusTcpPlcService(slaveId: 1);
            
            // 自动应用所有装饰器
            var plcService = PlcServiceDecoratorFactory.CreateDecoratedService(rawPlcService);

            try
            {
                // 连接PLC（自动重试5次，超时3秒）
                Console.WriteLine("正在连接PLC...");
                bool connected = plcService.Connect("192.168.1.100", 502);
                
                if (connected)
                {
                    Console.WriteLine("PLC连接成功！");
                    Console.WriteLine();

                    // 读取保持寄存器（自动重试3次，超时1秒）
                    Console.WriteLine("读取保持寄存器...");
                    var registers = plcService.ReadHoldingRegisters(0, 10);
                    Console.WriteLine($"读取到{registers.Length}个寄存器值");
                    Console.WriteLine();

                    // 写入单个寄存器（自动重试3次，超时1秒）
                    Console.WriteLine("写入单个寄存器...");
                    plcService.WriteSingleRegister(0, 1234);
                    Console.WriteLine("写入成功");
                    Console.WriteLine();

                    // 执行自定义命令（自动重试2次，超时2秒）
                    Console.WriteLine("执行自定义命令...");
                    var result = plcService.ExecuteCustomCommand(new byte[] { 0x01, 0x02, 0x03 });
                    Console.WriteLine($"命令执行成功，返回：{BitConverter.ToString(result)}");
                    Console.WriteLine();
                }
                else
                {
                    Console.WriteLine("PLC连接失败！");
                }
            }
            catch (Exception ex)
            {
                Console.WriteLine($"系统错误：{ex.Message}");
            }
            finally
            {
                // 断开连接
                Console.WriteLine("正在断开PLC连接...");
                plcService.Disconnect();
                Console.WriteLine("连接已断开");
            }

            Console.WriteLine();
            Console.WriteLine("程序结束");
            Console.ReadKey();
        }
    }
}
```

## 八、架构优势与扩展方向

### 8.1 核心优势

1. **完全解耦**：业务逻辑与横切关注点完全分离
2. **声明式配置**：通过特性直观地声明方法的行为
3. **单一职责**：每个装饰器只负责一个功能
4. **可组合性**：可以任意组合不同的装饰器
5. **可维护性**：添加新的横切关注点不需要修改业务代码
6. **灵活性**：不同方法可以有不同的配置
7. **工业级可靠性**：自动重试、超时控制、详细日志，满足工业系统要求

### 8.2 扩展方向

1. **添加更多装饰器**：

   - 权限验证装饰器
   - 性能监控装饰器
   - 异常报警装饰器（发送邮件 / 短信）
   - 缓存装饰器
   - 事务装饰器

2. **与依赖注入集成**：

   csharp:

   ```c#
   // 在ASP.NET Core DI中注册装饰器
   services.AddScoped<IPlcCommunicationService, ModbusTcpPlcService>();
   services.Decorate<IPlcCommunicationService, TimeoutDecorator>();
   services.Decorate<IPlcCommunicationService, RetryDecorator>();
   services.Decorate<IPlcCommunicationService, LoggingDecorator>();
   ```

3. **异步支持**：

   将所有方法改为异步版本，使用`async/await`提高性能

4. **配置文件集成**：

   允许通过配置文件覆盖特性中的默认值，便于不同环境的配置

## 总结

这个架构完美展示了特性与装饰器的协同工作方式：

- **特性**是 "配置"，告诉系统 "这个方法需要什么特殊处理"
- **装饰器**是 "实现"，告诉系统 "如何进行这种特殊处理"

这种模式在工业自动化领域极其有价值，它让我们能够：

- 写出极其简洁的业务代码
- 轻松添加各种可靠性和可观测性功能
- 不修改业务代码就能调整系统行为
- 保证工业系统所需的高可靠性和可维护性
