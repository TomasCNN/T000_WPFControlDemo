## 一、基础几何组合（Geometry 对象方式）

适合结构化图形、需要程序动态控制的场景，可读性强、易维护。

### 案例 1：组合式指示灯底座

**场景**：工业工位状态指示灯，由「底座矩形 + 顶部圆形灯头」组合而成，共用描边填充样式。

xaml:

```xaml
<Canvas Width="80" Height="100" Background="#222">
    <Path Stroke="#666" StrokeThickness="1.5" Fill="#DDD">
        <Path.Data>
            <GeometryGroup FillRule="Nonzero">
                <!-- 底部矩形底座 -->
                <RectangleGeometry Rect="20,45 40,50" RadiusX="4" RadiusY="4"/>
                <!-- 顶部圆形灯头 -->
                <EllipseGeometry Center="40,30" RadiusX="25" RadiusY="25"/>
            </GeometryGroup>
        </Path.Data>
    </Path>
    <!-- 灯芯发光效果 -->
    <Ellipse Canvas.Left="18" Canvas.Top="8" Width="44" Height="44" Fill="#00FF7F" Opacity="0.8"/>
</Canvas>
```

**关键特性**：`GeometryGroup` 将多个基础几何合并为一个整体，统一设置样式。

### 案例 2：带孔法兰盘（布尔挖洞）

**场景**：工业零件轮廓，通过布尔运算实现「矩形中心挖圆孔」效果，是工件镂空、视窗开孔的标准实现。

xaml:

```xaml
<Canvas Width="200" Height="200" Background="#F0F0F0">
    <Path Stroke="SteelBlue" StrokeThickness="2" Fill="#334682B4">
        <Path.Data>
            <!-- 布尔运算：Geometry1 排除 Geometry2 = 挖洞效果 -->
            <CombinedGeometry GeometryCombineMode="Exclude">
                <CombinedGeometry.Geometry1>
                    <RectangleGeometry Rect="20,20 160,160" RadiusX="10" RadiusY="10"/>
                </CombinedGeometry.Geometry1>
                <CombinedGeometry.Geometry2>
                    <EllipseGeometry Center="100,100" RadiusX="40" RadiusY="40"/>
                </CombinedGeometry.Geometry2>
            </CombinedGeometry>
        </Path.Data>
    </Path>
</Canvas>
```

**关键特性**：`GeometryCombineMode.Exclude` 实现排除挖洞；支持 `Union`（合并）、`Intersect`（相交）、`Xor`（异或）三种运算。

## 二、路径标记语法（迷你语言）

适合静态复杂图形、图标、矢量素材，语法简洁，代码量少，是设计软件导出矢量图的标准格式。

### 案例 1：实心流向箭头

**场景**：产线物料流向、工序流转指示，比 Line+Polygon 拼接更简洁，描边填充统一。

xaml:

```xaml
<Canvas Width="200" Height="80">
    <Path Data="M 0,25 L 100,25 L 100,10 L 160,40 L 100,70 L 100,55 L 0,55 Z"
          Fill="#32CD32"
          Stroke="#228B22"
          StrokeThickness="1.5"
          StrokeLineJoin="Round"/>
</Canvas>
```

**语法说明**：`M` 移动起点，`L` 画直线，`Z` 闭合路径。

### 案例 2：异形检测 ROI（带圆弧）

**场景**：视觉检测的异形感兴趣区域，包含直线与圆弧过渡，贴合真实工件轮廓。

xaml:

```xaml
<Canvas Width="400" Height="300" Background="#1E1E1E" SnapsToDevicePixels="True">
    <Path Data="M 80,200
               L 80,100
               A 40,40 0 0 1 120,60
               L 280,60
               A 40,40 0 0 1 320,100
               L 320,200
               L 250,200
               L 250,150
               L 150,150
               L 150,200
               Z"
          Stroke="Cyan"
          StrokeThickness="2"
          Fill="#2200FFFF"
          StrokeLineJoin="Round"/>
</Canvas>
```

**关键特性**：`A` 命令绘制椭圆圆弧，实现圆角过渡，比纯折线更贴合真实工件。

### 案例 3：多孔零件（EvenOdd 镂空）

**场景**：带多个安装孔的零件，利用 `FillRule.EvenOdd` 一次性实现多空洞，无需嵌套多层布尔运算。

xaml:

```xaml
<Canvas Width="300" Height="200" Background="#F5F5F5">
    <Path Data="M 30,30 L 270,30 L 270,170 L 30,170 Z
               M 80,80 m -15,0 a 15,15 0 1 0 30,0 a 15,15 0 1 0 -30,0
               M 150,80 m -15,0 a 15,15 0 1 0 30,0 a 15,15 0 1 0 -30,0
               M 220,80 m -15,0 a 15,15 0 1 0 30,0 a 15,15 0 1 0 -30,0"
          FillRule="EvenOdd"
          Stroke="DimGray"
          StrokeThickness="2"
          Fill="#888"/>
</Canvas>
```

**关键特性**：单个 Path 包含多个闭合路径，奇偶填充规则自动实现镂空，代码更简洁。

### 案例 2：沿路径运动点位（轨迹回放）

**场景**：物流轨迹回放、运动轴路径演示，让点位元素沿 Path 路径自动运动。

          StrokeThickness="2"

## 六、C# 后台动态生成

### 案例：动态生成实时正弦波形

**场景**：实时数据波形、工艺参数曲线，后台代码动态构建几何数据，适合高频刷新场景。

csharp:

```c#
using System.Windows;
using System.Windows.Media;
using System.Windows.Shapes;

public Path CreateSineWave(double amplitude, double period, double totalLength)
{
    Path wavePath = new Path
    {
        Stroke = Brushes.RoyalBlue,
        StrokeThickness = 2,
        Fill = Brushes.Transparent,
        StrokeLineJoin = PenLineJoin.Round
    };

    // 使用 StreamGeometry 高性能绘制静态波形
    StreamGeometry geometry = new StreamGeometry();
    using (StreamGeometryContext ctx = geometry.Open())
    {
        // 起点
        ctx.BeginFigure(new Point(0, amplitude), false, false);
        
        // 逐点生成波形
        for (double x = 0; x <= totalLength; x += 2)
        {
            double y = amplitude * Math.Sin(x * 2 * Math.PI / period) + amplitude;
            ctx.LineTo(new Point(x, y), true, false);
        }
    }
    
    geometry.Freeze(); // 冻结后不可修改，渲染性能最优
    wavePath.Data = geometry;
    return wavePath;
}
```

**关键优化**：静态波形使用 `StreamGeometry` + `Freeze()`，内存占用更低、渲染速度比 `PathGeometry` 快 30% 以上。

## 选型小提示

1. **简单图标 / 静态图形**：优先用**路径标记语法**，代码最简洁；
2. **结构化组合、动态生成**：用 `GeometryGroup` / `PathGeometry` 等几何对象，易维护、可编程；
3. **挖洞 / 布尔运算**：简单镂空用 `FillRule.EvenOdd`，复杂运算用 `CombinedGeometry`；
4. **大量静态复杂图形**：用 `StreamGeometry` 并冻结，性能最优；
5. **纯直线多边形**：优先用 `Polygon`，语义更清晰；只有含曲线、圆弧时再用 `Path`。
