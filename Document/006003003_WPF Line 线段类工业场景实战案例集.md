## 一、基础绘制案例（入门必看）

### 1. 三类基础直线（水平 / 垂直 / 斜向）

最基础的用法，通过 `X1/Y1/X2/Y2` 四个端点坐标定义线段，`Stroke`/`StrokeThickness` 控制外观。

xaml:

```xaml
<Canvas Width="400" Height="200" SnapsToDevicePixels="True">
    <!-- 水平直线 -->
    <Line X1="20" Y1="50" X2="380" Y2="50"
          Stroke="Black" StrokeThickness="2"/>

    <!-- 垂直直线 -->
    <Line X1="200" Y1="20" X2="200" Y2="180"
          Stroke="Gray" StrokeThickness="1.5"/>

    <!-- 斜向直线 -->
    <Line X1="50" Y1="150" X2="350" Y2="80"
          Stroke="RoyalBlue" StrokeThickness="1"/>
</Canvas>
```

> 注意：必须设置 `Stroke` 属性线条才会显示；父容器加 `SnapsToDevicePixels="True"` 避免线条发虚。

### 2. 虚线样式（警戒线 / 检测框常用）

通过 `StrokeDashArray` 定义虚线序列，格式为「实线长度，空白长度」，循环重复。

xaml:

```xaml
<Canvas Width="400" Height="100">
    <!-- 短虚线：4像素实 + 2像素空 -->
    <Line X1="20" Y1="30" X2="380" Y2="30"
          Stroke="Red" StrokeThickness="2"
          StrokeDashArray="4,2"/>

    <!-- 长虚线：8像素实 + 4像素空 -->
    <Line X1="20" Y1="70" X2="380" Y2="70"
          Stroke="Orange" StrokeThickness="2"
          StrokeDashArray="8,4"/>
</Canvas>
```

### 3. 不同端点线帽效果

通过 `StrokeStartLineCap` / `StrokeEndLineCap` 控制线段两端样式，适配不同精度需求。

xaml:

```xaml
<StackPanel Orientation="Horizontal" Margin="20" Spacing="30">
    <!-- 平端：刻度线专用，保证尺寸精度 -->
    <Line X1="0" Y1="0" X2="100" Y2="0"
          Stroke="Black" StrokeThickness="4"
          StrokeStartLineCap="Flat" StrokeEndLineCap="Flat"/>

    <!-- 圆端：指示线专用，视觉平滑 -->
    <Line X1="0" Y1="0" X2="100" Y2="0"
          Stroke="Black" StrokeThickness="4"
          StrokeStartLineCap="Round" StrokeEndLineCap="Round"/>

    <!-- 三角端：标注箭头简化版 -->
    <Line X1="0" Y1="0" X2="100" Y2="0"
          Stroke="Black" StrokeThickness="4"
          StrokeStartLineCap="Triangle" StrokeEndLineCap="Triangle"/>
</StackPanel>
```

### 案例 1：坐标轴标尺刻度（视觉检测标配）

**场景**：AOI 检测界面的坐标标尺、运动轴位置刻度，区分主刻度（长、粗）和次刻度（短、细）。

xaml:

```xaml
<Canvas Width="500" Height="60" SnapsToDevicePixels="True">
    <!-- 标尺主线 -->
    <Line X1="20" Y1="50" X2="480" Y2="50"
          Stroke="Black" StrokeThickness="1.5"/>

    <!-- 长主刻度：每50px一个，对应5mm精度 -->
    <Line X1="20" Y1="30" X2="20" Y2="50" Stroke="Black" StrokeThickness="1.5"/>
    <Line X1="70" Y1="30" X2="70" Y2="50" Stroke="Black" StrokeThickness="1.5"/>
    <Line X1="120" Y1="30" X2="120" Y2="50" Stroke="Black" StrokeThickness="1.5"/>
    <Line X1="170" Y1="30" X2="170" Y2="50" Stroke="Black" StrokeThickness="1.5"/>

    <!-- 短次刻度：每10px一个，对应1mm精度 -->
    <Line X1="30" Y1="40" X2="30" Y2="50" Stroke="Gray" StrokeThickness="1"/>
    <Line X1="40" Y1="40" X2="40" Y2="50" Stroke="Gray" StrokeThickness="1"/>
    <Line X1="50" Y1="40" X2="50" Y2="50" Stroke="Gray" StrokeThickness="1"/>
    <Line X1="60" Y1="40" X2="60" Y2="50" Stroke="Gray" StrokeThickness="1"/>
</Canvas>
```

> 工业价值：`Flat` 平端 + 像素对齐，保证刻度物理精度，配合数值文本可实现完整测量标尺。

## 三、动画与交互案例

### 案例 1：线扫相机流动扫描线

**场景**：模拟线扫相机的扫描过程，通过虚线偏移动画实现单向流动效果，直观展示扫描进度。

xaml:

```xaml
<Canvas Width="400" Height="300" Background="#1E1E1E">
    <!-- 绿色流动扫描线 -->
    <Line X1="0" Y1="150" X2="400" Y2="150"
          Stroke="LimeGreen" StrokeThickness="2"
          StrokeDashArray="10,5"
          StrokeDashCap="Round">
        <Line.Triggers>
            <EventTrigger RoutedEvent="Loaded">
                <BeginStoryboard>
                    <Storyboard RepeatBehavior="Forever">
                        <!-- 虚线偏移动画：从左向右流动 -->
                        <DoubleAnimation 
                            Storyboard.TargetProperty="StrokeDashOffset"
                            From="0" To="-15" Duration="0:0:0.6" />
                    </Storyboard>
                </BeginStoryboard>
            </EventTrigger>
        </Line.Triggers>
    </Line>
</Canvas>
```

> 原理：持续修改 `StrokeDashOffset` 让虚线产生位移，模拟扫描、传送带的运动感，是工业设备界面的标准动效。

### 案例 2：可点击的检测触发线

**场景**：检测工位的光电触发线，点击可配置参数，基于几何精确命中测试。

xaml:

## 四、C# 后台动态创建案例

### 案例 1：批量生成定位网格线

**场景**：视觉检测界面的定位网格，后台代码循环生成，画刷冻结优化性能。

csharp:

```c#
using System.Windows;
using System.Windows.Media;
using System.Windows.Shapes;

/// <summary>
/// 在Canvas上绘制等距定位网格
/// </summary>
/// <param name="canvas">目标画布</param>
/// <param name="totalWidth">总宽度</param>
/// <param name="totalHeight">总高度</param>
/// <param name="gridStep">网格间距</param>
public void DrawPositionGrid(Canvas canvas, double totalWidth, double totalHeight, double gridStep)
{
    // 画刷提前冻结，减少性能开销
    Brush gridBrush = new SolidColorBrush(Color.FromArgb(40, 128, 128, 128));
    gridBrush.Freeze();

    // 垂直网格线
    for (double x = 0; x <= totalWidth; x += gridStep)
    {
        Line vLine = new Line
        {
            X1 = x,
            Y1 = 0,
            X2 = x,
            Y2 = totalHeight,
            Stroke = gridBrush,
            StrokeThickness = 1
        };
        canvas.Children.Add(vLine);
    }

    // 水平网格线
    for (double y = 0; y <= totalHeight; y += gridStep)
    {
        Line hLine = new Line
        {
            X1 = 0,
            Y1 = y,
            X2 = totalWidth,
            Y2 = y,
            Stroke = gridBrush,
            StrokeThickness = 1
        };
        canvas.Children.Add(hLine);
    }
}
```

### 案例 2：实时更新运动位置指示线

```c#
// 声明全局位置指示线
private Line _positionIndicator;

// 初始化创建
private void InitPositionLine(Canvas canvas)
{
    _positionIndicator = new Line
    {
        Y1 = 0,
        Y2 = 400,
        Stroke = Brushes.Red,
        StrokeThickness = 1.5
    };
    canvas.Children.Add(_positionIndicator);
}

// 轴位置更新时调用（UI线程）
private void UpdateAxisPosition(double currentX)
{
    _positionIndicator.X1 = currentX;
    _positionIndicator.X2 = currentX;
}
```

## 五、MVVM 数据驱动案例

**场景**：运动轴实时位置绑定，纯数据驱动，无需后台操作 UI 元素，符合 MVVM 架构。

### 视图模型属性

csharp:

```c#
// 轴当前X坐标，由PLC通信线程更新
public double AxisCurrentX
{
    get => _axisCurrentX;
    set { _axisCurrentX = value; OnPropertyChanged(); }
}
```

### XAML 绑定

xaml:

```xaml
<Canvas Width="600" Height="300">
    <!-- 位置指示线：X1/X2同时绑定轴坐标，实现垂直位置线 -->
    <Line Y1="0" Y2="300"
          X1="{Binding AxisCurrentX}"
          X2="{Binding AxisCurrentX}"
          Stroke="Red" StrokeThickness="1.5"
          StrokeDashArray="4,2"/>
</Canvas>
```

> 工业价值：通信线程只需更新数据源属性，UI 自动刷新位置，完全避免跨线程操作 UI 的问题，代码更易维护。

## 六、工业场景避坑提示

1. **`Fill` 属性完全无效**：Line 是开放图形，没有内部区域，设置填充不会有任何效果，只需关注 `Stroke` 描边。
2. **`Width`/`Height` 不控制线条长度**：线条长度由端点坐标差决定，`Width` 只是布局属性，不要试图通过它修改线长。
3. **高精度绘图必开像素对齐**：标尺、刻度线场景必须设置 `SnapsToDevicePixels="True"`，避免亚像素渲染导致的线条发虚、精度下降。
4. **大量线条注意性能**：上百条高频刷新的线段，每个 Line 都是完整 `FrameworkElement`，有布局开销；超大量实时轨迹建议改用 `Polyline` 或 `DrawingVisual` 低层方案。
5. **多段连续折线用 Polyline**：不要用多个 Line 拼接运动轨迹，`Polyline` 性能更好、拐角更平滑、代码更简洁。
