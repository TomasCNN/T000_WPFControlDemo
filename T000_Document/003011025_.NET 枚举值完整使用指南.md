# 003011025_.NET 枚举值完整使用指南

## 一、枚举是什么？为什么工业项目必须用？

枚举（Enum）是一种**强类型的常量集合**，用来表示一组固定的、相关的离散值。

### 工业场景不用枚举的致命问题

你之前的代码里有这样的写法：

csharp:

```c#
// ❌ 硬编码魔法数字+字符串数组，极易出错
List<string> list = new List<string>() { "RUN", "DOWN", "IDLE", "PM" };
var eqpStateMessage = list[eqpStatNo - 1].ToString();
```

- **索引越界风险**：如果 PLC 返回 5，会直接抛出`IndexOutOfRangeException`导致程序崩溃
- **可读性差**：看到数字 1 不知道代表什么，必须看注释
- **无编译时检查**：传错数字编译器不会报错，只会在运行时出问题
- **维护困难**：新增或修改状态时，需要修改所有用到的地方

### 用枚举的优势

csharp:

```c#
// ✅ 强类型枚举，安全可靠
public enum EqpMainStatus
{
    RUN = 1,
    DOWN = 2,
    Idle = 3,
    PM = 4
}
```

- **类型安全**：编译器会检查类型，不能传任意数字
- **可读性高**：`EqpMainStatus.RUN`比数字 1 清晰 100 倍
- **编译时检查**：传错值会直接编译报错
- **易于维护**：修改枚举值只需要改定义处
- **功能强大**：支持转换、特性、扩展方法等高级用法

## 二、第一步：定义枚举

### 基本语法

csharp:

```c#
// 访问修饰符 enum 枚举名 { 枚举值 = 整数, ... }
public enum EqpMainStatus
{
    RUN = 1,    // 运行中
    DOWN = 2,   // 停机
    Idle = 3,   // 空闲
    PM = 4      // 维护中
}
```

### 工业项目定义规范

1. **枚举名用名词**：`EqpMainStatus`、`RecipeEventType`、`AlarmLevel`
2. **枚举值用帕斯卡命名法**：`RUN`、`DOWN`、`Enable`
3. **显式指定整数值**：必须和 PLC 或 MES 约定的值完全一致
4. **不要用 0 作为有效业务值**：因为枚举的默认值是 0，避免混淆 "未初始化" 和 "有效状态"
5. **添加 XML 注释**：说明每个枚举值的含义

**工业标准示例**：

csharp:

```c#
/// <summary>
/// 配方事件类型（与MES接口约定）
/// </summary>
public enum RecipeEventType
{
    /// <summary>
    /// 启用配方
    /// </summary>
    Enable = 1,
    
    /// <summary>
    /// 创建配方
    /// </summary>
    Create = 2,
    
    /// <summary>
    /// 修改配方
    /// </summary>
    Modify = 3
}

/// <summary>
/// 报警级别
/// </summary>
public enum AlarmLevel
{
    /// <summary>
    /// 提示
    /// </summary>
    Info = 1,
    
    /// <summary>
    /// 警告
    /// </summary>
    Warn = 2,
    
    /// <summary>
    /// 错误
    /// </summary>
    Error = 3,
    
    /// <summary>
    /// 致命
    /// </summary>
    Fatal = 4
}
```

## 三、第二步：枚举的基本使用

### 1. 声明枚举变量

csharp:

```c#
// 声明并赋值
EqpMainStatus currentStatus = EqpMainStatus.RUN;

// 默认值是0（如果没有定义0的枚举值，会显示数字0）
EqpMainStatus defaultStatus = default; // 输出：0
```

### 2. 枚举比较

csharp:

```c#
if (currentStatus == EqpMainStatus.RUN)
{
    // 设备运行中
}
else if (currentStatus == EqpMainStatus.DOWN)
{
    // 设备停机
}
```

### 3. 转换为字符串

csharp:

```c#
string statusStr = currentStatus.ToString(); // 输出："RUN"
```

**这正是你 MES 上报需要的！** 接口要求的`"RUN"`、`"DOWN"`字符串，直接用`ToString()`就能得到，完全不需要硬编码字符串数组。

## 四、第三步：核心类型转换（工业场景最常用）

工业项目中 90% 的枚举使用都是**PLC 数字→枚举→MES 字符串**的转换流程，这是必须掌握的核心。

### 1. 整数 → 枚举（PLC 读取后转换）

PLC 返回的都是整数，需要转换成枚举类型。

#### 显式转换（简单但不安全）

csharp:

```c#
int plcValue = 1;
EqpMainStatus status = (EqpMainStatus)plcValue; // 输出：EqpMainStatus.RUN
```

**问题**：如果 PLC 返回无效值（如 5），转换不会报错，只会显示数字 5，导致后续逻辑异常。

#### 安全转换（工业项目必须用）

使用`Enum.IsDefined`检查转换后的值是否有效：

csharp:

```c#
int plcValue = Device.PLC.GetEqpStateMassage;

if (Enum.IsDefined(typeof(EqpMainStatus), plcValue))
{
    EqpMainStatus status = (EqpMainStatus)plcValue;
    // 正常处理
}
else
{
    // 无效值处理：记录日志，使用默认值
    Logger.LogCommucation.Error($"PLC返回无效的设备状态值：{plcValue}");
    EqpMainStatus status = EqpMainStatus.Idle;
}
```

### 2. 枚举 → 整数（写入 PLC 时转换）

csharp:

```c#
EqpMainStatus status = EqpMainStatus.RUN;
int plcValue = (int)status; // 输出：1
Device.PLC.WriteInt("DB1.DBW0", plcValue);
```

### 3. 字符串 → 枚举（解析配置或 MES 返回）

csharp:

```c#
string mesStatus = "DOWN";

// 方法1：Enum.Parse（可能抛出异常）
EqpMainStatus status1 = (EqpMainStatus)Enum.Parse(typeof(EqpMainStatus), mesStatus);

// 方法2：Enum.TryParse（推荐，安全不抛异常）
if (Enum.TryParse<EqpMainStatus>(mesStatus, ignoreCase: true, out var status2))
{
    // 解析成功
}
else
{
    // 解析失败处理
    Logger.LogCommucation.Error($"无效的设备状态字符串：{mesStatus}");
}
```

`ignoreCase: true`表示忽略大小写，`"run"`、`"Run"`、`"RUN"`都能正确解析。

## 五、第四步：枚举特性（工业场景高级用法）

### 1. [Description] 特性（中文描述）

给枚举值添加中文描述，用于 UI 显示和日志记录，操作人员不需要看英文。

#### 第一步：引用命名空间

csharp:

```c#
using System.ComponentModel;
```

#### 第二步：给枚举添加特性

csharp:

```c#
public enum EqpMainStatus
{
    [Description("运行中")]
    RUN = 1,
    
    [Description("停机")]
    DOWN = 2,
    
    [Description("空闲")]
    Idle = 3,
    
    [Description("维护中")]
    PM = 4
}
```

#### 第三步：编写扩展方法获取描述

csharp:

```c#
using System.Reflection;

public static class EnumExtensions
{
    /// <summary>
    /// 获取枚举的Description特性值
    /// </summary>
    public static string GetDescription(this Enum enumValue)
    {
        FieldInfo field = enumValue.GetType().GetField(enumValue.ToString());
        DescriptionAttribute attribute = field.GetCustomAttribute<DescriptionAttribute>();
        return attribute?.Description ?? enumValue.ToString();
    }
}
```

#### 第四步：使用

csharp:

```c#
EqpMainStatus status = EqpMainStatus.RUN;
string chineseDesc = status.GetDescription(); // 输出："运行中"

// UI显示中文
StatusTextBlock.Text = $"设备状态：{chineseDesc}";

// 日志记录中文
Logger.LogCommucation.Info($"设备状态变更为：{chineseDesc}");
```

### 2. [Flags] 特性（位枚举，组合状态）

当一个值可以表示多个状态的组合时使用，比如多个报警同时存在。

#### 定义位枚举

csharp:

```c#
[Flags]
public enum AlarmType
{
    None = 0,
    CameraError = 1 << 0, // 1
    PlcError = 1 << 1,    // 2
    LightError = 1 << 2,  // 4
    MotorError = 1 << 3   // 8
}
```

#### 使用组合状态

csharp:

```c#
// 同时存在相机和PLC报警
AlarmType alarms = AlarmType.CameraError | AlarmType.PlcError;

// 检查是否包含某个报警
if (alarms.HasFlag(AlarmType.CameraError))
{
    // 有相机报警
}

// 移除一个报警
alarms &= ~AlarmType.CameraError;
```

## 六、工业场景实战用法（直接替换你的代码）

### 实战 1：设备状态上报（替换你之前的硬编码代码）

**原代码（有问题）**：

csharp:

```c#
// ❌ 硬编码字符串数组，索引越界风险
List<string> list = new List<string>() { "RUN", "DOWN", "IDLE", "PM" };
var eqpStateMessage = list[eqpStatNo - 1].ToString();

requestObj["MAINSTATUS"] = eqpStateMessage;
```

**优化后代码（安全可靠）**：

csharp:

```c#
// ✅ 安全转换PLC值为枚举
int eqpStatNo = Device.PLC.GetEqpStateMassage;
if (!Enum.IsDefined(typeof(EqpMainStatus), eqpStatNo))
{
    Logger.LogCommucation.Error($"PLC返回无效设备状态：{eqpStatNo}，使用默认值Idle");
    eqpStatNo = (int)EqpMainStatus.Idle;
}

EqpMainStatus currentStatus = (EqpMainStatus)eqpStatNo;

// 直接ToString()得到MES需要的字符串
requestObj["MAINSTATUS"] = currentStatus.ToString();

// UI显示中文
UpdateProcess($"设备状态：{currentStatus.GetDescription()}");
```

### 实战 3：设备状态机

用枚举管理设备状态机，比用 int 清晰太多：

csharp:

```c#
public class DeviceStateMachine
{
    private EqpMainStatus _currentState = EqpMainStatus.Idle;

    public void TransitionTo(EqpMainStatus newState)
    {
        // 检查状态转换是否合法
        if (!IsValidTransition(_currentState, newState))
        {
            throw new InvalidOperationException($"无法从{_currentState}转换到{newState}");
        }

        _currentState = newState;
        // 上报状态变化到MES
        _statusReportManager.ReportStatusChange(newState);
    }

    private bool IsValidTransition(EqpMainStatus from, EqpMainStatus to)
    {
        return (from, to) switch
        {
            (EqpMainStatus.Idle, EqpMainStatus.RUN) => true,
            (EqpMainStatus.RUN, EqpMainStatus.DOWN) => true,
            (EqpMainStatus.DOWN, EqpMainStatus.Idle) => true,
            _ => false
        };
    }
}
```

## 七、常见坑与最佳实践

### 1. 不要用 0 作为有效业务值

csharp:

```c#
// ❌ 错误：0是枚举默认值，容易混淆未初始化和有效状态
public enum EqpMainStatus
{
    RUN = 0,
    DOWN = 1
}

// ✅ 正确：0表示未定义，有效状态从1开始
public enum EqpMainStatus
{
    Undefined = 0,
    RUN = 1,
    DOWN = 2
}
```

### 2. 总是检查枚举值的有效性

永远不要相信外部输入（PLC、MES、用户输入），必须用`Enum.IsDefined`检查：

csharp:

```c#
// ❌ 错误：直接转换，无效值会导致后续逻辑异常
EqpMainStatus status = (EqpMainStatus)plcValue;

// ✅ 正确：先检查再转换
if (Enum.IsDefined(typeof(EqpMainStatus), plcValue))
{
    EqpMainStatus status = (EqpMainStatus)plcValue;
}
else
{
    // 处理无效值
}
```

### 3. 不要随意修改枚举的整数值

一旦枚举值已经持久化到数据库、配置文件或 MES 系统，就不要修改它的整数值，否则会导致历史数据解析错误。

### 4. 枚举值不要太多

如果枚举值超过 10 个，考虑是否需要拆分成多个枚举，或者用其他方式管理。

### 5. 不要用枚举存储动态数据

枚举是编译时常量，不能在运行时添加或修改。如果数据是动态的（比如配方列表），不要用枚举。

## 八、总结：工业项目枚举使用流程

1. **定义**：根据 PLC 和 MES 的约定，定义强类型枚举，显式指定整数值，添加注释
2. **转换**：从 PLC 读取整数后，用`Enum.IsDefined`安全转换为枚举
3. **使用**：在代码中用枚举值进行比较和逻辑判断，可读性高
4. **上报**：用`ToString()`转换为 MES 需要的字符串，用`(int)`转换为需要的数字
5. **显示**：用`[Description]`特性和扩展方法获取中文描述，用于 UI 和日志
