# 006007005_WPF `Path` 类常用属性全解析

`Path` 自身仅新增 **1 个核心自有属性**，绝大多数常用属性都继承自 `Shape` 基类与 `FrameworkElement` 基类。以下按「自有核心属性 → 外观控制属性 → 布局交互属性」分类整理，均为实际开发中高频使用的属性，并结合工业 / 可视化场景说明作用与注意事项。

------

## 一、Path 自身独有核心属性

### `Data`

- **类型**：`Geometry`（所有几何类的抽象基类）
- **作用**：Path 的灵魂属性，定义路径的具体形状，是 Path 能绘制任意复杂图形的根本原因。
- **支持的几何类型**：可赋值任意 `Geometry` 子类，包括：
  - 基础几何：`RectangleGeometry`、`EllipseGeometry`、`LineGeometry`
  - 自由路径：`PathGeometry`（直线、贝塞尔、圆弧任意组合）
  - 组合几何：`GeometryGroup`（多几何叠加）
  - 布尔几何：`CombinedGeometry`（合并、相交、挖洞）
  - 轻量几何：`StreamGeometry`（静态高性能场景）
- **XAML 简化写法**：支持**路径标记语法（迷你语言）**，用字符串描述复杂路径，例如 `Data="M 0,0 L 100,0 L 50,100 Z"`
- **注意事项**：默认值为 `null`，不设置 `Data` 时 Path 完全不可见；属性变更时自动触发布局重绘。

## 二、继承自 Shape 的核心外观属性

这是控制 Path 显示效果最高频的属性，所有 Shape 派生类通用，在 Path 上作用更显著（复杂路径的描边、填充效果更丰富）。

### 1. 填充相关

#### `Fill`

- **类型**：`Brush`
- **作用**：填充路径闭合区域的内部颜色 / 画刷，支持纯色、渐变、图片填充等。
- **注意事项**：
  - 若路径是开放的（未闭合），设置 `Fill` 后会**自动隐式连接起点与终点形成闭合区域**再填充，行为与 Polyline 一致；
  - 若只需要轮廓线，请勿设置 `Fill`，或设为 `Transparent`（需要内部命中测试时用）。

#### `FillRule`

- **类型**：`FillRule` 枚举（`EvenOdd` / `Nonzero`）
- **作用**：控制复杂路径的填充计算规则，对自相交、嵌套、带孔的图形影响极大。
  - `EvenOdd`（默认）：奇偶环绕规则，交叉区域自动镂空，适合实现带孔、挖洞效果；
  - `Nonzero`：非零环绕规则，绝大多数区域实心填充，适合普通闭合图形。
- **典型场景**：绘制带安装孔的工件、镂空图标、嵌套多边形区域。

### 2. 描边（轮廓）相关

这组属性直接决定路径线条的视觉效果，是工业绘图、轨迹展示最常调优的属性。

#### `Stroke`

- **类型**：`Brush`
- **作用**：路径轮廓的画刷 / 颜色。
- **注意事项**：默认值为 `null`，不设置 `Stroke` 时看不到线条轮廓，是新手最高频踩坑点。

#### `StrokeThickness`

- **类型**：`double`
- **作用**：路径轮廓的线条厚度，单位为与设备无关像素，支持小数。

#### `StrokeLineJoin`

- **类型**：`PenLineJoin` 枚举（`Miter` / `Bevel` / `Round`）
- **作用**：控制路径拐角的连接样式，对多拐点的复杂路径视觉影响极大。
  - `Miter`（默认）：尖角连接，小角度拐角易出现长尖刺；
  - `Bevel`：斜切平角；
  - `Round`：圆角平滑过渡，工业轨迹、工件轮廓推荐使用。

#### `StrokeMiterLimit`

- **类型**：`double`，默认值 10
- **作用**：限制尖角模式下拐角尖刺的最大延伸长度，防止小角度拐角出现过长尖刺。

#### `StrokeStartLineCap` / `StrokeEndLineCap`

- **类型**：`PenLineCap` 枚举（`Flat` / `Square` / `Round` / `Triangle`）
- **作用**：控制**开放路径**首尾端点的样式，闭合路径无效果。
  - `Flat`：平端，刻度、精度标注常用；
  - `Round`：圆端，轨迹线、指示线常用，视觉更平滑。

#### `StrokeDashArray`

- **类型**：`DoubleCollection`
- **作用**：定义虚线序列，格式为「实线长度，空白长度」，循环重复。
- **典型场景**：规划路径、安全警戒线、临时选区、检测辅助线。
- **示例**：`StrokeDashArray="6,3"` 表示 6 像素实线 + 3 像素空白。

#### `StrokeDashOffset`

- **类型**：`double`
- **作用**：虚线的起始偏移量，配合动画可实现线条流动效果。
- **典型场景**：扫描线流动、传送带方向指示、检测进度动画。

#### `StrokeDashCap`

- **类型**：`PenLineCap` 枚举
- **作用**：控制虚线每一小段的端点样式。

### 3. 拉伸适配

#### `Stretch`

- **类型**：`Stretch` 枚举（`None` / `Fill` / `Uniform` / `UniformToFill`）
- **作用**：控制路径如何适配自身布局区域的大小。
  - `None`（默认）：按原始坐标尺寸渲染，不拉伸，高精度绘图推荐；
  - `Uniform`：等比例缩放至完全容纳在容器内，不变形，图标自适应场景最常用；
  - `Fill`：拉伸填满容器，宽高比可能失真；
  - `UniformToFill`：等比例缩放至完全覆盖容器，超出部分裁剪。

### 4. 几何只读属性

#### `RenderedGeometry`

- **类型**：`Geometry`（只读）
- **作用**：获取最终渲染生效的几何对象，包含了描边厚度、拉伸变换的影响，用于精确命中测试、边界计算、坐标换算。

#### `GeometryTransform`

- **类型**：`Transform`（只读）
- **作用**：获取应用在原始几何上的变换矩阵，用于坐标映射计算。

## 三、继承自 FrameworkElement / UIElement 的常用属性

这类属性是所有 WPF 控件通用，但在 Path 绘图场景中高频使用。

### 1. 布局定位

#### `Canvas.Left` / `Canvas.Top`（附加属性）

- **作用**：在 Canvas 画布中绝对定位 Path 的左上角位置，工业绘图、ROI 标注场景必用。
- **说明**：Path 最常用的布局容器就是 Canvas，配合绝对定位实现精确坐标绘制。

#### `Width` / `Height`

- **作用**：设置 Path 元素的布局尺寸，配合 `Stretch` 属性实现路径缩放自适应。

#### `Margin` / `HorizontalAlignment` / `VerticalAlignment`

- **作用**：在 Grid、StackPanel 等流式容器中控制 Path 的对齐与边距，图标、装饰元素场景常用。

### 2. 交互与可见性

#### `Visibility`

- **类型**：`Visibility` 枚举
- **作用**：控制 Path 的显示 / 隐藏状态，切换选区显隐、辅助线开关常用。

#### `Opacity`

- **类型**：`double`，0~1
- **作用**：控制 Path 整体透明度，高亮选中态、半透明辅助线、禁用状态常用。

#### `IsHitTestVisible`

- **类型**：`bool`
- **作用**：设置是否参与命中测试。纯装饰性、背景类的路径设为 `false` 可提升渲染性能；需要响应鼠标点击的路径必须设为 `true`（默认）。

#### `Cursor`

- **类型**：`Cursor`
- **作用**：设置鼠标悬停在路径上的光标样式，可点击的选区、可编辑的路径通常设为 `Hand`。

### 3. 变换与动画

#### `RenderTransform`

- **类型**：`Transform`
- **作用**：对 Path 进行渲染变换（平移、旋转、缩放、扭曲），不影响布局计算。
- **典型场景**：图标旋转、轨迹缩放、图形动画、工件角度调整。

#### `RenderTransformOrigin`

- **类型**：`Point`
- **作用**：设置渲染变换的原点坐标，例如 `0.5,0.5` 表示绕中心旋转 / 缩放。

### 4. 渲染优化

#### `SnapsToDevicePixels`

- **类型**：`bool`
- **作用**：开启像素对齐，避免亚像素渲染导致的线条发虚、模糊。
- **工业场景建议**：高精度绘图、刻度线、细线条场景务必开启，通常在父容器 Canvas 上统一设置即可。

## 四、高频使用组合示例

### 1. 工业检测 ROI（青色半透明 + 实线描边）

xaml:

```xaml
<Path Data="M 80,200 L 80,100 A 40,40 0 0 1 120,60 L 280,60 Z"
      Stroke="Cyan"
      StrokeThickness="2"
      Fill="#2200FFFF"
      StrokeLineJoin="Round"
      Canvas.Left="50"
      Canvas.Top="50"/>
```

### 2. 规划虚线轨迹（蓝色虚线 + 圆端）

xaml:

```xaml
<Path Data="M 50,250 C 150,100 300,100 400,200"
      Stroke="#1E90FF"
      StrokeThickness="2"
      StrokeDashArray="8,4"
      StrokeStartLineCap="Round"
      StrokeEndLineCap="Round"
      Fill="Transparent"/>
```

### 3. 自适应图标（等比例缩放）

xaml:

```xaml
<Path Data="M 0,25 L 100,25 L 100,10 L 160,40 L 100,70 L 100,55 L 0,55 Z"
      Fill="#32CD32"
      Stretch="Uniform"
      Width="40"
      Height="20"/>
```
