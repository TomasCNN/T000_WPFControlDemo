# 006001001_WPF `Shape` 图形体系概述

在 WPF 中，`Shape` 是**二维矢量图形元素的抽象基类**，位于 `System.Windows.Shapes` 命名空间，隶属于 WPF 渲染体系的「高层绘图接口」。它继承自 `FrameworkElement`，因此天然具备完整的 UI 元素能力：参与布局系统、支持数据绑定、样式触发器、动画、鼠标键盘交互，开发者可以像使用按钮、文本框一样，通过 XAML 声明式地绘制矢量图形，无需手动处理底层渲染逻辑。

Shape 是 WPF 中最易用的二维绘图方式，非常适合实现状态指示灯、设备简图、流程图、自定义图标等工业界面常见图形元素；其矢量特性保证了在不同分辨率工控屏上都能无损缩放显示，完美适配工业现场多尺寸触控屏、监视器的场景。

------

## 一、继承体系与核心定位

### 完整继承链

plaintext:

```tex
Object → DispatcherObject → DependencyObject → Visual → UIElement → FrameworkElement → Shape
```

继承 `FrameworkElement` 是 Shape 区别于低级绘图对象（如 `Geometry`）的核心标志：它是完整的界面元素，拥有独立的布局槽位，支持边距、对齐、数据上下文等所有 WPF 控件通用能力，可直接融入布局系统与 MVVM 架构。

> Shape 本身是抽象类，不能直接实例化，实际开发中使用其标准派生类：`Line`、`Rectangle`、`Ellipse`、`Polyline`、`Polygon`、`Path`。

------

## 二、Shape 基类核心公共属性

所有派生类共享以下核心绘图属性，全部为依赖属性，支持数据绑定、动画、样式触发器。

### 1. 填充与描边（最常用）

| 属性              | 类型     | 作用                       | 工业场景典型用法                                             |
| :---------------- | :------- | :------------------------- | :----------------------------------------------------------- |
| `Fill`            | `Brush`  | 图形内部的填充画刷         | 状态灯填充色、设备本体颜色、区域背景；支持纯色、渐变、纹理等所有画刷类型 |
| `Stroke`          | `Brush`  | 图形轮廓的描边画刷         | 设备边框、管路线条、分隔线颜色                               |
| `StrokeThickness` | `double` | 描边线条的粗细（像素单位） | 主管路粗线、支管路细线的区分                                 |

### 2. 笔触细节样式

用于精细控制线条的端点、转角、虚线样式：

- `StrokeStartLineCap` / `StrokeEndLineCap`：线条两端的端点样式，可选 `Flat`（平）、`Round`（圆头）、`Square`（方头）、`Triangle`（三角）；工业管道绘制常用圆头，模拟真实管路效果。
- `StrokeDashArray`：`DoubleCollection` 类型，定义虚线的间隔规则，可实现虚线、点划线等效果，常用于表示预留管路、未启用线路、示意边界。
- `StrokeLineJoin`：线条转角的连接样式，可选 `Miter`（尖角）、`Bevel`（斜切）、`Round`（圆角）。
- `StrokeMiterLimit`：尖角连接的长度限制，防止锐角处尖角过长出现视觉异常。

### 3. 拉伸与布局

- `Stretch`：`Stretch` 枚举，控制图形如何适配自身的布局尺寸：
  - `None`：按原始尺寸显示，不拉伸；
  - `Fill`：拉伸填满整个区域，可能变形；
  - `Uniform`：等比缩放，完整显示图形（不变形）；
  - `UniformToFill`：等比缩放填满区域，超出部分裁剪。
- 同时继承所有 `FrameworkElement` 布局属性：`Width`/`Height`、`Margin`、`HorizontalAlignment`、`RenderTransform`（旋转 / 缩放 / 平移变换）等。

## 三、标准派生类与适用场景

WPF 提供 6 个 Shape 标准派生类，覆盖绝大多数二维绘图场景，从简单到复杂依次为：

### 1. Line（直线）

- **作用**：绘制两点之间的直线段，无填充区域，仅描边生效。

- **核心属性**：`X1`、`Y1`（起点坐标）；`X2`、`Y2`（终点坐标）。

- **典型工业场景**：产线输送线、管路连接、界面分隔线、电气连线。

- **示例**：

  xaml:

  ```xaml
  <Line X1="0" Y1="10" X2="200" Y2="10" Stroke="Gray" StrokeThickness="2"/>
  ```

### 2. Rectangle（矩形）

- **作用**：绘制矩形 / 正方形，支持圆角设置。

- **核心属性**：`RadiusX`、`RadiusY` 分别控制水平 / 垂直圆角半径。

- **典型工业场景**：工位框、按钮背景、液位 / 进度指示器、面板边框、储罐轮廓。

- **示例**：

  xaml:

  ```xaml
  <Rectangle Width="120" Height="60" Fill="#F5F5F5" Stroke="#DDD" RadiusX="4" RadiusY="4"/>
  ```

### 3. Ellipse（椭圆 / 圆）

- **作用**：绘制椭圆；宽高相等时为正圆形。

- **典型工业场景**：状态指示灯、设备节点、报警灯，是工业界面最高频使用的 Shape。

- **示例（绿色运行指示灯）**：

  xaml:

  ```xaml
  <Ellipse Width="16" Height="16" Fill="#52C41A" Stroke="#389E0D" StrokeThickness="1"/>
  ```

### 4. Polyline（折线）

- **作用**：绘制由多个顶点连接的多段折线，路径不自动闭合，仅描边生效。
- **核心属性**：`Points` 点集合，定义所有折点坐标。
- **典型工业场景**：趋势曲线、管路走向、不规则连线、简单波形。

### 5. Polygon（多边形）

- **作用**：绘制闭合多边形，自动将首尾点连接，同时支持填充与描边。
- **核心属性**：`Points` 顶点集合。
- **典型工业场景**：三角形警示标识、六边形工位、不规则设备轮廓、漏斗 / 料斗图形。

### 6. Path（路径）

- **作用**：最灵活、功能最强的 Shape，通过 `Data` 属性（`Geometry` 几何对象）绘制任意复杂图形，包括直线、圆弧、贝塞尔曲线、复合图形、孔洞等。

- **核心属性**：`Data`，支持「路径标记语法」（迷你字符串语法），可简洁表达复杂轮廓。

- **典型工业场景**：自定义设备图标、管道弯头、阀门泵体、复杂流程图、矢量图标。

- **示例（简单箭头）**：

  xaml:

  ```xaml
  <Path Data="M0,0 L20,10 L0,20 Z" Fill="#1890FF"/>
  ```

## 四、核心特性与底层机制

### 1. 矢量无损缩放

Shape 基于矢量几何渲染，无论放大多少倍都不会出现锯齿、模糊，完美适配工业现场不同尺寸、不同分辨率的触控屏、监视器，无需做多套图片资源，也不会因界面缩放出现画质损失。

### 2. 完整的 UI 元素能力

与 GDI+ 绘图、低级 `DrawingVisual` 不同，Shape 是完整的 `FrameworkElement`：

- 参与 WPF 布局系统，支持对齐、边距、自动排列，可直接放入 Grid、StackPanel 等布局容器；
- 支持 `MouseEnter`、`MouseLeftButtonUp` 等所有鼠标键盘事件，可实现点击、悬停等交互；
- 支持数据绑定、样式、触发器、故事板动画，完全融入 MVVM 架构；
- 支持 `RenderTransform` 变换（旋转、缩放、平移、扭曲），轻松实现设备旋转、动画效果。

### 3. 声明式开发

所有图形都可以通过 XAML 直接声明，无需后台代码编写绘图逻辑，界面与逻辑完全分离，符合 WPF 的开发范式，也便于样式复用与主题切换。

## 五、不同绘图方案的选型对比

WPF 提供了多层级的绘图接口，Shape 属于「易用优先」的高层方案，不同场景选型不同：

| 方案            | 层级   | 交互能力                   | 性能量级           | 适用工业场景                                                 |
| :-------------- | :----- | :------------------------- | :----------------- | :----------------------------------------------------------- |
| **Shape**       | 高层   | 完整 UI 交互               | 百级以内无压力     | 少量图形、需要交互、状态绑定，如指示灯、按钮图标、简单流程图 |
| Geometry + Path | 中高层 | 仅 Path 容器可交互         | 千级以内           | 中等复杂度图形，如设备简图、自定义图标、管路图               |
| DrawingVisual   | 底层   | 无原生交互，需手动命中测试 | 万级以上           | 海量数据点、实时高速曲线、复杂工业图纸                       |
| WriteableBitmap | 底层   | 无原生交互                 | 极高（像素级操作） | 高速图像渲染、线扫相机图像显示                               |

> 工业场景选型建议：
>
> - 状态指示灯、按钮图标、简单工位图 → 直接用 Shape，开发效率最高；
> - 复杂设备轮廓、管路流程图 → 用 Path + Geometry；
> - 实时曲线、海量数据点 → 用 DrawingVisual 或专业图表控件。

## 六、工业场景典型应用

1. **状态指示灯**：用 `Ellipse` 配合数据触发器，根据设备状态切换填充色（绿运行 / 黄待机 / 红故障），实现可视化状态反馈，远距离即可识别。
2. **产线流程图**：用 `Rectangle` 表示工位，`Line`/`Polyline` 表示输送线，`Path` 表示阀门、泵体，搭建成完整的产线布局图，实时映射设备状态。
3. **自定义液位 / 进度**：用两个 `Rectangle` 叠加，通过绑定高度控制填充区域，模拟储罐液位、物料进度、缓存占比。
4. **报警闪烁效果**：通过 `Storyboard` 动画改变 `Fill` 颜色，实现报警时红灯闪烁的强提醒效果，无需后台线程控制。
5. **设备状态映射**：将设备运行状态绑定到 Shape 的填充色、描边粗细、虚线样式，操作人员一眼即可识别设备健康度与运行模式。

------

## 总结

Shape 是 WPF 图形体系中入门门槛最低、通用性最强的矢量绘图方案。它将复杂的渲染逻辑封装为标准控件，让开发者可以专注于业务逻辑而非绘图实现，是工业上位机界面实现图形化、可视化的基础工具。对于绝大多数界面装饰、状态展示、简单图形的需求，Shape 都是最优选择。
