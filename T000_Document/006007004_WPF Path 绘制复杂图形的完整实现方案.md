# 006007004_WPF `Path` 绘制复杂图形的完整实现方案

`Path` 绘制复杂图形的核心逻辑是：**`Path` 本身只是渲染容器，图形的复杂度完全由 `Data` 属性承载的 `Geometry` 几何数据决定**。通过组合基础几何、布尔运算、贝塞尔曲线、圆弧等元素，可以构建任意复杂度的 2D 矢量图形。

以下从实现方式、核心语法、进阶技巧到工业场景实战，系统讲解复杂图形的绘制方法。

------

## 一、核心原理：Path + Geometry 的组合模式

`Path` 自身不定义具体形状，只负责将 `Geometry` 几何数据渲染为 UI 元素。复杂图形的本质，就是通过**几何组合、路径拼接、布尔运算**构建出复杂的 `Geometry` 对象，再赋值给 `Path.Data`。

绘制复杂图形主要有两种实现方式，适用场景不同：

| 实现方式                     | 适用场景                                        | 优势                             | 劣势                       |
| :--------------------------- | :---------------------------------------------- | :------------------------------- | :------------------------- |
| **Geometry 对象组合**        | C# 后台动态生成、需要程序控制形状、结构化逻辑强 | 可读性强、易维护、可动态修改     | 代码量稍大                 |
| **路径标记语法（迷你语言）** | XAML 静态绘制、设计软件导出矢量图               | 语法简洁、代码量少、适合静态图形 | 可读性差，复杂路径手写困难 |

------

## 二、方式一：Geometry 对象结构化组合

通过显式创建不同类型的 `Geometry` 子类并进行组合，是构建复杂图形最灵活、最可控的方式，适合工业场景下动态生成工件轮廓、检测区域等需求。

### 1. 多几何叠加：`GeometryGroup`

将多个独立的基础几何（矩形、圆、直线等）组合为一个整体，共用填充、描边样式，适合由多个简单部分拼接而成的图形。

#### 示例：工业指示灯底座（矩形 + 圆形组合）

xaml:

```xaml
<Canvas Width="80" Height="100">
    <Path Stroke="#555" StrokeThickness="1.5" Fill="#DDD">
        <Path.Data>
            <GeometryGroup FillRule="Nonzero">
                <!-- 底座矩形 -->
                <RectangleGeometry Rect="20,45 40,50" RadiusX="4" RadiusY="4"/>
                <!-- 顶部灯头圆形 -->
                <EllipseGeometry Center="40,30" RadiusX="25" RadiusY="25"/>
            </GeometryGroup>
        </Path.Data>
    </Path>
</Canvas>
```

#### C# 动态生成版本

csharp:

```c#
Path lampPath = new Path();
lampPath.Stroke = Brushes.Gray;
lampPath.StrokeThickness = 1.5;
lampPath.Fill = Brushes.LightGray;

GeometryGroup group = new GeometryGroup();
group.FillRule = FillRule.Nonzero;
group.Children.Add(new RectangleGeometry(new Rect(20, 45, 40, 50), 4, 4));
group.Children.Add(new EllipseGeometry(new Point(40, 30), 25, 25));

lampPath.Data = group;
```

### 2. 布尔运算：`CombinedGeometry`

对两个几何执行布尔运算，实现**挖洞、合并、相交、异或**效果，是绘制带孔零件、镂空区域的核心手段，工业场景使用频率极高。

`GeometryCombineMode` 支持 4 种运算模式：

- `Union`：合并两个几何
- `Intersect`：取两个几何的交集
- `Exclude`：从第一个几何中排除第二个几何（最常用，用于挖洞）
- `Xor`：异或，取两个几何不重叠的部分

#### 示例：带圆孔的法兰盘（矩形排除圆形 = 挖洞）

xaml:

```xaml
<Canvas Width="200" Height="200" Background="#F0F0F0">
    <Path Stroke="SteelBlue" StrokeThickness="2" Fill="#334682B4">
        <Path.Data>
            <!-- 布尔运算：大矩形排除中心小圆，形成带孔工件 -->
            <CombinedGeometry GeometryCombineMode="Exclude">
                <CombinedGeometry.Geometry1>
                    <RectangleGeometry Rect="20,20 160,160" RadiusX="10" RadiusY="10"/>
                </CombinedGeometry.Geometry1>
                <CombinedGeometry.Geometry2>
                    <EllipseGeometry Center="100,100" RadiusX="40" RadiusY="40"/>
                </CombinedGeometry.Geometry2>
            </CombinedGeometry>
        </Path.Data>
    </Path>
</Canvas>
```

> 多个几何运算可嵌套 `CombinedGeometry`，实现多次挖洞、多部件合并。

### 3. 自由路径：`PathGeometry`

最灵活、功能最强的几何类，支持由直线、贝塞尔曲线、圆弧等任意段拼接而成，是绘制异形轮廓、平滑曲线的终极方案。

核心组成：

- `PathFigure`：一条独立的路径，包含起点和多个线段
- `Segments`：路径段集合，支持 `LineSegment`（直线）、`BezierSegment`（三次贝塞尔）、`QuadraticBezierSegment`（二次贝塞尔）、`ArcSegment`（圆弧）
- `IsClosed`：是否自动闭合路径

#### 示例：带圆弧的异形工件轮廓

xaml:

```xaml
<Canvas Width="400" Height="300" Background="#1E1E1E">
    <Path Stroke="Cyan" StrokeThickness="2" Fill="#2200FFFF" StrokeLineJoin="Round">
        <Path.Data>
            <PathGeometry FillRule="Nonzero">
                <PathFigure StartPoint="80,200" IsClosed="True">
                    <PathFigure.Segments>
                        <!-- 左侧竖直线 -->
                        <LineSegment Point="80,100"/>
                        <!-- 左上角圆弧过渡 -->
                        <ArcSegment Point="120,60" Size="40,40" RotationAngle="0" SweepDirection="Clockwise" IsLargeArc="False"/>
                        <!-- 顶部水平线 -->
                        <LineSegment Point="280,60"/>
                        <!-- 右上角圆弧过渡 -->
                        <ArcSegment Point="320,100" Size="40,40" RotationAngle="0" SweepDirection="Clockwise" IsLargeArc="False"/>
                        <!-- 右侧竖直线 -->
                        <LineSegment Point="320,200"/>
                        <!-- 底部内凹 -->
                        <LineSegment Point="250,200"/>
                        <LineSegment Point="250,150"/>
                        <LineSegment Point="150,150"/>
                        <LineSegment Point="150,200"/>
                    </PathFigure.Segments>
                </PathFigure>
            </PathGeometry>
        </Path.Data>
    </Path>
</Canvas>
```

## 三、方式二：路径标记语法（迷你语言）

WPF 提供了一套字符串形式的简洁语法，直接赋值给 `Path.Data`，是 XAML 中绘制复杂图形最常用的方式，设计软件（Blend、Figma、AI）导出的矢量图通常都是这种格式。

### 1. 核心命令速查表

命令**大写**表示绝对坐标，**小写**表示相对当前点的偏移量。

| 命令                             | 全称             | 功能说明                               | 格式示例                |
| :------------------------------- | :--------------- | :------------------------------------- | :---------------------- |
| `M x,y`                          | Move             | 移动起点，不绘制线条（路径起始必须有） | `M 10,10`               |
| `L x,y`                          | Line             | 从当前点画直线到目标点                 | `L 100,10`              |
| `H x`                            | Horizontal       | 画水平线（Y 坐标不变）                 | `H 200`                 |
| `V y`                            | Vertical         | 画垂直线（X 坐标不变）                 | `V 50`                  |
| `C x1,y1 x2,y2 x,y`              | Cubic Bezier     | 三次贝塞尔曲线（2 个控制点）           | `C 10,10 50,100 100,50` |
| `S x2,y2 x,y`                    | Smooth Cubic     | 平滑三次贝塞尔（自动镜像前一个控制点） | `S 150,10 200,50`       |
| `Q x1,y1 x,y`                    | Quadratic Bezier | 二次贝塞尔曲线（1 个控制点）           | `Q 50,0 100,50`         |
| `A rx,ry rot largeArc sweep x,y` | Arc              | 椭圆圆弧                               | `A 50,50 0 0 1 100,50`  |
| `Z`                              | Close            | 闭合路径，自动连接起点与终点           | `Z`                     |

圆弧命令 `A` 的参数说明：

- `rx,ry`：椭圆弧的水平 / 垂直半径
- `rot`：椭圆的旋转角度
- `largeArc`：0 = 小弧，1 = 大弧
- `sweep`：0 = 逆时针，1 = 顺时针
- `x,y`：圆弧终点坐标

## 四、进阶技巧与最佳实践

### 1. 填充规则 `FillRule` 的影响

复杂图形（尤其是自相交、嵌套图形）的填充效果由 `FillRule` 决定：

- `EvenOdd`（默认）：奇偶环绕，交叉区域自动镂空，适合做带孔图形
- `Nonzero`：非零环绕，绝大多数区域实心填充，适合普通闭合图形

> 技巧：不需要布尔运算，用两个闭合路径 + `EvenOdd` 也能快速实现挖洞效果。

### 2. 性能优化：`StreamGeometry`

如果复杂图形是**静态不变**的，优先使用 `StreamGeometry` 替代 `PathGeometry`：

- 内存占用降低约 30%~50%
- 渲染速度更快
- 缺点是一旦创建就不能修改，只读

#### C# 示例：高性能静态波形

csharp:

```c#
public Path CreateStaticSinePath()
{
    Path path = new Path
    {
        Stroke = Brushes.RoyalBlue,
        StrokeThickness = 2,
        Fill = Brushes.Transparent
    };

    StreamGeometry geo = new StreamGeometry();
    using (StreamGeometryContext ctx = geo.Open())
    {
        ctx.BeginFigure(new Point(0, 50), false, false);
        for (double x = 0; x <= 300; x += 2)
        {
            double y = 50 * Math.Sin(x * 0.05) + 50;
            ctx.LineTo(new Point(x, y), true, false);
        }
    }
    
    geo.Freeze(); // 冻结后不可修改，性能最优
    path.Data = geo;
    return path;
}
```

### 3. 工业场景选型建议

| 图形类型               | 推荐方案                                          |
| :--------------------- | :------------------------------------------------ |
| 简单矩形 / 圆形 ROI    | `Rectangle`/`Ellipse` 专用控件                    |
| 纯直线多边形选区       | `Polygon`                                         |
| 带圆弧、圆角的异形 ROI | `Path` + `PathGeometry`                           |
| 带孔 / 镂空的工件轮廓  | `Path` + `CombinedGeometry` 或 `EvenOdd` 嵌套路径 |
| 平滑运动轨迹、曲线     | `Path` + 贝塞尔曲线                               |
| 大量静态复杂图形       | `Path` + `StreamGeometry` + `Freeze()`            |

### 4. 实用工具推荐

复杂路径不需要手写：

- **Blend for Visual Studio**：内置钢笔工具，可视化绘制路径，自动生成 XAML 代码
- **矢量图导出**：AI、Figma、Inkscape 绘制后导出为 XAML 格式
- **在线转换**：SVG 转 XAML 工具，可直接复用海量 SVG 素材

## 五、综合实战：绘制工业异形检测工件

以下用两种方式实现同一个带圆角、带内凹、带安装孔的工业工件轮廓，直观对比两种实现方式。

### XAML 路径语法版本（简洁）

xaml:

```xaml
<Canvas Width="400" Height="350" Background="#1E1E1E" SnapsToDevicePixels="True">
    <!-- 工件外轮廓 -->
    <Path Data="M 80,250
               L 80,100
               A 40,40 0 0 1 120,60
               L 280,60
               A 40,40 0 0 1 320,100
               L 320,250
               L 250,250
               L 250,180
               L 150,180
               L 150,250
               Z"
          Stroke="Cyan" StrokeThickness="2" Fill="#2200FFFF" StrokeLineJoin="Round"/>
    
    <!-- 两个安装孔（利用EvenOdd镂空） -->
    <Path Data="M 150,110 m -15,0 a 15,15 0 1 0 30,0 a 15,15 0 1 0 -30,0
               M 250,110 m -15,0 a 15,15 0 1 0 30,0 a 15,15 0 1 0 -30,0"
          FillRule="EvenOdd"
          Stroke="Cyan" StrokeThickness="1.5" Fill="Transparent"/>
</Canvas>
```

### 效果说明

- 外轮廓带顶部圆角、底部内凹，贴合真实工件形状
- 两个圆形安装孔通过嵌套路径 + 奇偶填充实现镂空
- 全矢量无损缩放，放大无锯齿，完全满足工业视觉检测的精度要求

## 六、常见避坑点

1. **路径忘记闭合**：需要填充的图形务必加 `Z` 命令，或设置 `IsClosed="True"`，否则填充会出现异常。
2. **大小写混淆**：路径语法中大写是绝对坐标，小写是相对坐标，混用容易导致形状错乱，建议统一风格。
3. **圆弧参数记错**：圆弧的 `largeArc` 和 `sweep` 是 0/1 枚举，不是布尔值，写错会导致圆弧方向完全相反。
4. **性能浪费**：静态图形不要用 `PathGeometry`，优先 `StreamGeometry` 并冻结；不要用多个 Path 拼接，尽量用单个 Path 组合。
5. **填充镂空异常**：自相交图形填充不符合预期时，切换 `FillRule` 通常就能解决。
