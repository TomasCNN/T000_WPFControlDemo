异常报警是工业系统中最关键的可靠性保障之一。我们将实现一个支持**多渠道报警、防抖动、分级报警**的完整报警系统。

### 1.1 定义报警特性与接口

csharp:

```c#
// IndustrialAutomation.Core/Attributes/AlarmAttribute.cs
using System;

namespace IndustrialAutomation.Core.Attributes
{
    /// <summary>
    /// 异常报警特性：标记方法抛出异常时需要发送报警
    /// </summary>
    [AttributeUsage(AttributeTargets.Method, Inherited = false)]
    public sealed class AlarmAttribute : Attribute
    {
        /// <summary>
        /// 报警标题
        /// </summary>
        public string Title { get; }
        
        /// <summary>
        /// 报警级别
        /// </summary>
        public AlarmLevel Level { get; }
        
        /// <summary>
        /// 报警防抖时间(秒)：相同异常在该时间内只发送一次报警
        /// </summary>
        public int DebounceSeconds { get; }
        
        /// <summary>
        /// 需要报警的异常类型（为空则所有异常都报警）
        /// </summary>
        public Type[] ExceptionTypes { get; }

        public AlarmAttribute(string title, AlarmLevel level = AlarmLevel.Error, 
            int debounceSeconds = 60, params Type[] exceptionTypes)
        {
            Title = title;
            Level = level;
            DebounceSeconds = debounceSeconds;
            ExceptionTypes = exceptionTypes ?? Array.Empty<Type>();
        }
    }

    /// <summary>
    /// 报警级别
    /// </summary>
    public enum AlarmLevel
    {
        /// <summary>
        /// 信息：仅记录日志
        /// </summary>
        Info,
        
        /// <summary>
        /// 警告：需要关注但不影响运行
        /// </summary>
        Warning,
        
        /// <summary>
        /// 错误：影响部分功能
        /// </summary>
        Error,
        
        /// <summary>
        /// 严重：系统无法运行
        /// </summary>
        Critical
    }
}
```

```c#
// IndustrialAutomation.Core/Alarms/ConsoleAlarmNotifier.cs
using System;
using System.Threading.Tasks;

namespace IndustrialAutomation.Core.Alarms
{
    /// <summary>
    /// 控制台报警通知器（开发环境用）
    /// </summary>
    public class ConsoleAlarmNotifier : IAlarmNotifier
    {
        public Task SendAlarmAsync(AlarmLevel level, string title, string message, Exception exception = null)
        {
            var color = level switch
            {
                AlarmLevel.Info => ConsoleColor.Gray,
                AlarmLevel.Warning => ConsoleColor.Yellow,
                AlarmLevel.Error => ConsoleColor.Red,
                AlarmLevel.Critical => ConsoleColor.DarkRed,
                _ => ConsoleColor.Gray
            };

            Console.ForegroundColor = color;
            Console.WriteLine($"[{DateTime.Now:HH:mm:ss.fff}] [{level}] 【{title}】");
            Console.WriteLine($"    {message}");
            if (exception != null)
            {
                Console.WriteLine($"    异常详情：{exception.Message}");
            }
            Console.ResetColor();

            return Task.CompletedTask;
        }
    }
}
```

```c#
using System;
using System.Net;
using System.Net.Mail;
using System.Threading.Tasks;
using Microsoft.Extensions.Options;

namespace IndustrialAutomation.Core.Alarms
{
    /// <summary>
    /// 邮件报警通知器配置
    /// </summary>
    public class EmailAlarmOptions
    {
        public string SmtpServer { get; set; }
        public int SmtpPort { get; set; } = 587;
        public string Username { get; set; }
        public string Password { get; set; }
        public string FromAddress { get; set; }
        public string[] ToAddresses { get; set; }
        public bool EnableSsl { get; set; } = true;
    }

    /// <summary>
    /// 邮件报警通知器
    /// </summary>
    public class EmailAlarmNotifier : IAlarmNotifier
    {
        private readonly EmailAlarmOptions _options;

        public EmailAlarmNotifier(IOptions<EmailAlarmOptions> options)
        {
            _options = options.Value;
        }

        public async Task SendAlarmAsync(AlarmLevel level, string title, string message, Exception exception = null)
        {
            if (level < AlarmLevel.Error)
                return; // 只发送错误及以上级别的邮件

            var mailMessage = new MailMessage
            {
                From = new MailAddress(_options.FromAddress),
                Subject = $"[{level}] {title}",
                Body = $@"
                    报警时间：{DateTime.Now:yyyy-MM-dd HH:mm:ss}
                    报警级别：{level}
                    报警标题：{title}
                    报警详情：{message}
                    
                    {(exception != null ? $"异常信息：{exception}" : "")}
                "
            };

            foreach (var toAddress in _options.ToAddresses)
            {
                mailMessage.To.Add(toAddress);
            }

            using var client = new SmtpClient(_options.SmtpServer, _options.SmtpPort)
            {
                Credentials = new NetworkCredential(_options.Username, _options.Password),
                EnableSsl = _options.EnableSsl
            };

            await client.SendMailAsync(mailMessage);
        }
    }
}
```

### 1.3 实现报警装饰器

csharp:

```c#
// IndustrialAutomation.Core/Decorators/AlarmDecorator.cs
using System;
using System.Collections.Concurrent;
using System.Reflection;
using System.Threading.Tasks;
using IndustrialAutomation.Core.Alarms;
using IndustrialAutomation.Core.Attributes;
using Microsoft.Extensions.Logging;

namespace IndustrialAutomation.Core.Decorators
{
    /// <summary>
    /// 异常报警装饰器：根据[Alarm]特性自动发送异常报警
    /// </summary>
    public class AlarmDecorator : PlcServiceDecoratorBase
    {
        private readonly ILogger<AlarmDecorator> _logger;
        private readonly IAlarmNotifier[] _alarmNotifiers;
        private readonly ConcurrentDictionary<string, DateTime> _lastAlarmTimes = new();

        public AlarmDecorator(IPlcCommunicationService innerService, 
            ILogger<AlarmDecorator> logger,
            IEnumerable<IAlarmNotifier> alarmNotifiers) 
            : base(innerService)
        {
            _logger = logger;
            _alarmNotifiers = alarmNotifiers.ToArray();
        }

        public override ushort[] ReadHoldingRegisters(ushort startAddress, ushort length)
        {
            try
            {
                return base.ReadHoldingRegisters(startAddress, length);
            }
            catch (Exception ex)
            {
                HandleException(nameof(ReadHoldingRegisters), ex);
                throw;
            }
        }

        public override void WriteSingleRegister(ushort address, ushort value)
        {
            try
            {
                base.WriteSingleRegister(address, value);
            }
            catch (Exception ex)
            {
                HandleException(nameof(WriteSingleRegister), ex);
                throw;
            }
        }

        public override bool Connect(string ipAddress, int port = 502)
        {
            try
            {
                return base.Connect(ipAddress, port);
            }
            catch (Exception ex)
            {
                HandleException(nameof(Connect), ex);
                throw;
            }
        }

        public override byte[] ExecuteCustomCommand(byte[] commandData)
        {
            try
            {
                return base.ExecuteCustomCommand(commandData);
            }
            catch (Exception ex)
            {
                HandleException(nameof(ExecuteCustomCommand), ex);
                throw;
            }
        }

        /// <summary>
        /// 处理异常并发送报警
        /// </summary>
        private void HandleException(string methodName, Exception exception)
        {
            var attribute = GetAttribute<AlarmAttribute>(methodName);
            if (attribute == null)
                return;

            // 检查是否是需要报警的异常类型
            if (attribute.ExceptionTypes.Length > 0 && 
                !attribute.ExceptionTypes.Any(t => t.IsInstanceOfType(exception)))
            {
                return;
            }

            // 报警防抖：相同方法的相同异常在防抖时间内只发送一次
            string alarmKey = $"{methodName}_{exception.GetType().Name}";
            var now = DateTime.Now;
            if (_lastAlarmTimes.TryGetValue(alarmKey, out var lastTime) && 
                (now - lastTime).TotalSeconds < attribute.DebounceSeconds)
            {
                _logger.LogDebug("报警防抖：{AlarmKey} 在 {DebounceSeconds}秒内已发送过报警", 
                    alarmKey, attribute.DebounceSeconds);
                return;
            }

            _lastAlarmTimes[alarmKey] = now;

            // 发送报警
            string message = $"PLC通信异常：{methodName} 方法执行失败";
            _logger.LogError(exception, message);

            // 并行发送所有报警通知
            Parallel.ForEach(_alarmNotifiers, notifier =>
            {
                try
                {
                    notifier.SendAlarmAsync(attribute.Level, attribute.Title, message, exception).Wait();
                }
                catch (Exception ex)
                {
                    _logger.LogError(ex, "发送报警失败：{NotifierType}", notifier.GetType().Name);
                }
            });
        }
    }
}
```

```c#
// 更新LoggingDecorator以使用ILogger
public class LoggingDecorator : PlcServiceDecoratorBase
{
    private readonly ILogger<LoggingDecorator> _logger;

    public LoggingDecorator(IPlcCommunicationService innerService, 
        ILogger<LoggingDecorator> logger) 
        : base(innerService)
    {
        _logger = logger;
    }

    // ... 修改ExecuteWithLogging方法使用ILogger而不是Console.WriteLine ...
    private T ExecuteWithLogging<T>(Func<T> operation, LogExecutionAttribute attribute, params object[] parameters)
    {
        var stopwatch = Stopwatch.StartNew();
        try
        {
            if (attribute.LogParameters)
            {
                string paramStr = string.Join(", ", parameters.Select(p => p?.ToString() ?? "null"));
                _logger.LogInformation("开始执行 {OperationName}，参数：{Parameters}", 
                    attribute.OperationName, paramStr);
            }
            else
            {
                _logger.LogInformation("开始执行 {OperationName}", attribute.OperationName);
            }

            var result = operation();

            if (attribute.LogExecutionTime)
            {
                _logger.LogInformation("执行 {OperationName} 成功，耗时：{Elapsed}ms", 
                    attribute.OperationName, stopwatch.ElapsedMilliseconds);
            }
            else
            {
                _logger.LogInformation("执行 {OperationName} 成功", attribute.OperationName);
            }

            return result;
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "执行 {OperationName} 失败，耗时：{Elapsed}ms", 
                attribute.OperationName, stopwatch.ElapsedMilliseconds);
            throw;
        }
    }
}
```

```c#
using Microsoft.AspNetCore.Mvc;
using IndustrialAutomation.Core.Services;

namespace IndustrialAutomation.Web.Controllers
{
    [ApiController]
    [Route("api/[controller]")]
    public class PlcController : ControllerBase
    {
        private readonly IPlcCommunicationService _plcService;

        public PlcController(IPlcCommunicationService plcService)
        {
            _plcService = plcService;
        }

        /// </summary>

        /// 连接PLC

            bool connected = _plcService.Connect(ipAddress, port);

        /// 断开PLC连接
        /// </summary>
```

## 四、关键设计说明

### 4.1 装饰器执行顺序

我们按照以下顺序注册装饰器，这是经过工业实践验证的最优顺序：

plaintext:

```tex
调用方 → AlarmDecorator → LoggingDecorator → RetryDecorator → TimeoutDecorator → 实际服务
```

- **AlarmDecorator 在最外层**：确保能捕获所有下层抛出的异常
- **LoggingDecorator 在 RetryDecorator 外层**：记录每次重试尝试
- **RetryDecorator 在 TimeoutDecorator 外层**：每次重试都应用超时控制
- **TimeoutDecorator 在最内层**：直接控制实际通信操作的超时

### 4.2 报警系统设计要点

1. **分级报警**：不同级别的异常使用不同的通知渠道
2. **报警防抖**：避免同一个异常短时间内发送大量报警
3. **多渠道支持**：同时支持控制台、邮件、短信等多种通知方式
4. **异常过滤**：只对指定类型的异常发送报警
5. **故障隔离**：一个报警通知器失败不会影响其他通知器

### 4.3 依赖注入最佳实践

- **PLC 服务使用 Singleton 生命周期**：因为它包含持久的 TCP 连接
- **装饰器自动注入依赖**：所有装饰器的依赖都由 DI 容器自动注入
- **配置集中管理**：所有配置都在`appsettings.json`中，便于不同环境部署
- **健康检查集成**：监控 PLC 连接状态，便于 K8s 等容器编排系统进行自动恢复

## 五、扩展建议

1. **添加更多报警渠道**：
   - 企业微信 / 钉钉机器人报警
