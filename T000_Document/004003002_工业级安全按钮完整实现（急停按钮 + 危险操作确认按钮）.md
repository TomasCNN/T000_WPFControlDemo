## 一、工业急停按钮（E-Stop Button）

### 1.1 设计规范（必须遵守）

工业急停按钮是设备最重要的安全部件，必须符合以下要求：

- ✅ **圆形红色按钮**，黄色边框
- ✅ **大尺寸**：最小直径 60mm，触摸屏操作推荐 80mm
- ✅ **自锁式**：按下后保持锁定状态，必须手动旋转复位
- ✅ **醒目位置**：放在操作员伸手可及的地方
- ✅ **最高优先级**：按下后立即切断所有动力输出

### 1.2 控件类定义

csharp:

```c#
using System;
using System.Windows;
using System.Windows.Controls.Primitives;
using System.Windows.Input;

namespace IndustrialVisionTemplate.Controls
{
    /// <summary>
    /// 工业级自锁式急停按钮
    /// 符合GB/T 5226.1机械安全标准
    /// </summary>
    public class EmergencyStopButton : ToggleButton
    {
        static EmergencyStopButton()
        {
            DefaultStyleKeyProperty.OverrideMetadata(
                typeof(EmergencyStopButton), 
                new FrameworkPropertyMetadata(typeof(EmergencyStopButton)));
        }

        public EmergencyStopButton()
        {
            // 默认未按下
            IsChecked = false;
            
            // 禁止通过空格键触发，防止误触
            IsTabStop = false;
        }

        // 依赖属性：急停触发事件
        public static readonly RoutedEvent EmergencyStopEvent = EventManager.RegisterRoutedEvent(
            nameof(EmergencyStop), 
            RoutingStrategy.Bubble, 
            typeof(RoutedEventHandler), 
            typeof(EmergencyStopButton));

        public event RoutedEventHandler EmergencyStop
        {
            add => AddHandler(EmergencyStopEvent, value);
            remove => RemoveHandler(EmergencyStopEvent, value);
        }

        // 依赖属性：复位事件
        public static readonly RoutedEvent ResetEvent = EventManager.RegisterRoutedEvent(
            nameof(Reset), 
            RoutingStrategy.Bubble, 
            typeof(RoutedEventHandler), 
            typeof(EmergencyStopButton));

        public event RoutedEventHandler Reset
        {
            add => AddHandler(ResetEvent, value);
            remove => RemoveHandler(ResetEvent, value);
        }

        /// <summary>
        /// 手动触发急停
        /// </summary>
        public void TriggerEmergencyStop()
        {
            if (!IsChecked.GetValueOrDefault())
            {
                IsChecked = true;
                OnEmergencyStop();
            }
        }

        /// <summary>
        /// 手动复位急停
        /// </summary>
        public void ResetEmergencyStop()
        {
            if (IsChecked.GetValueOrDefault())
            {
                IsChecked = false;
                OnReset();
            }
        }

        protected override void OnChecked(RoutedEventArgs e)
        {
            base.OnChecked(e);
            OnEmergencyStop();
        }

        protected override void OnUnchecked(RoutedEventArgs e)
        {
            base.OnUnchecked(e);
            OnReset();
        }

        protected virtual void OnEmergencyStop()
        {
            // 记录急停日志（最高级别）
            Logger.LogSafety.Fatal("急停按钮被触发！所有设备已停止");
            
            // 触发路由事件
            RaiseEvent(new RoutedEventArgs(EmergencyStopEvent));
        }

        protected virtual void OnReset()
        {
            Logger.LogSafety.Info("急停按钮已复位");
            RaiseEvent(new RoutedEventArgs(ResetEvent));
        }

        // 禁止鼠标右键点击
        protected override void OnMouseRightButtonDown(MouseButtonEventArgs e)
        {
            e.Handled = true;
            base.OnMouseRightButtonDown(e);
        }

        // 禁止双击
        protected override void OnMouseDoubleClick(MouseButtonEventArgs e)
        {
            e.Handled = true;
            base.OnMouseDoubleClick(e);
        }
    }
}
```

private void EmergencyStopButton_EmergencyStop(object sender, RoutedEventArgs e)
{
    // 急停逻辑：立即停止所有设备
    try
    {
        // 1. 停止相机采集
        StaticObject.Camera.StopGrab();
        
        // 2. 停止PLC所有输出
        Device.PLC.StopAllOutputs();
        
        // 3. 停止所有运动轴
        Device.Motion.StopAllAxes();
        
        // 4. 更新设备状态
        CurrentDeviceStatus = DeviceStatus.EmergencyStop;
        
        // 5. 弹出报警提示
        MessageBox.Show("急停已触发！所有设备已停止运行", "安全警告", 
            MessageBoxButton.OK, MessageBoxImage.Stop);
    }
    catch (Exception ex)
    {
        Logger.LogSafety.Fatal($"急停执行失败：{ex.Message}", ex);
    }
}

private void EmergencyStopButton_Reset(object sender, RoutedEventArgs e)
{
    // 复位逻辑
    try
    {
        // 1. 复位PLC
        Device.PLC.ResetEmergencyStop();
        
        // 2. 更新设备状态
        CurrentDeviceStatus = DeviceStatus.Idle;
        
        MessageBox.Show("急停已复位，请检查设备状态后再启动", "提示", 
            MessageBoxButton.OK, MessageBoxImage.Information);
    }
    catch (Exception ex)
    {
        Logger.LogSafety.Error($"急停复位失败：{ex.Message}", ex);
        MessageBox.Show($"急停复位失败：{ex.Message}", "错误", 
            MessageBoxButton.OK, MessageBoxImage.Error);
    }
}

## 二、带二次确认的危险操作按钮

### 2.1 设计规范

工业现场中，删除数据、重置参数、清空记录等危险操作必须进行二次确认，防止误操作导致生产事故。

- ✅ 点击后弹出模态确认对话框
- ✅ 对话框显示明确的警告信息
- ✅ 默认焦点在 "取消" 按钮上
- ✅ 支持自定义确认消息和标题
- ✅ 只有用户点击 "确认" 后才执行命令

### 2.2 控件类定义

csharp:

```c#
using System;
using System.Windows;
using System.Windows.Controls;
using System.Windows.Input;

namespace IndustrialVisionTemplate.Controls
{
    /// <summary>
    /// 带二次确认的危险操作按钮
    /// 点击后弹出确认对话框，确认后才执行命令
    /// </summary>
    public class DangerousOperationButton : Button
    {
        static DangerousOperationButton()
        {
            DefaultStyleKeyProperty.OverrideMetadata(
                typeof(DangerousOperationButton), 
                new FrameworkPropertyMetadata(typeof(DangerousOperationButton)));
        }

        // 依赖属性：确认对话框标题
        public static readonly DependencyProperty ConfirmTitleProperty = DependencyProperty.Register(
            nameof(ConfirmTitle), 
            typeof(string), 
            typeof(DangerousOperationButton), 
            new PropertyMetadata("危险操作确认"));

        public string ConfirmTitle
        {
            get => (string)GetValue(ConfirmTitleProperty);
            set => SetValue(ConfirmTitleProperty, value);
        }

        // 依赖属性：确认对话框消息
        public static readonly DependencyProperty ConfirmMessageProperty = DependencyProperty.Register(
            nameof(ConfirmMessage), 
            typeof(string), 
            typeof(DangerousOperationButton), 
            new PropertyMetadata("此操作不可恢复，确定要继续吗？"));

        public string ConfirmMessage
        {
            get => (string)GetValue(ConfirmMessageProperty);
            set => SetValue(ConfirmMessageProperty, value);
        }

        // 依赖属性：是否显示取消按钮
        public static readonly DependencyProperty ShowCancelButtonProperty = DependencyProperty.Register(
            nameof(ShowCancelButton), 
            typeof(bool), 
            typeof(DangerousOperationButton), 
            new PropertyMetadata(true));

        public bool ShowCancelButton
        {
            get => (bool)GetValue(ShowCancelButtonProperty);
            set => SetValue(ShowCancelButtonProperty, value);
        }

        protected override void OnClick()
        {
            // 弹出确认对话框
            MessageBoxResult result = MessageBox.Show(
                ConfirmMessage, 
                ConfirmTitle, 
                ShowCancelButton ? MessageBoxButton.OKCancel : MessageBoxButton.OK, 
                MessageBoxImage.Warning, 
                ShowCancelButton ? MessageBoxResult.Cancel : MessageBoxResult.OK);

            // 只有点击OK才执行基类的OnClick（触发Click事件和Command）
            if (result == MessageBoxResult.OK)
            {
                Logger.LogCommucation.Warn($"危险操作已确认：{Content}");
                base.OnClick();
            }
            else
            {
                Logger.LogCommucation.Info($"危险操作已取消：{Content}");
            }
        }
    }
}
```

## 三、工业现场使用注意事项

### 3.1 急停按钮使用规范

1. **安装位置**：必须放在操作员正面伸手可及的位置，距离地面 1.2~1.5 米
2. **尺寸要求**：触摸屏操作最小直径 60mm，推荐 80mm；物理按钮最小直径 40mm
3. **颜色要求**：必须是红色按钮配黄色边框，禁止使用其他颜色
4. **优先级**：急停命令必须高于所有其他命令，按下后立即切断所有动力输出
5. **日志记录**：急停的触发和复位必须记录最高级别的安全日志
6. **测试要求**：每天开机前必须测试急停按钮功能是否正常

### 3.2 危险操作按钮使用规范

1. **所有可能导致数据丢失或设备动作的操作都必须使用二次确认**
2. **确认消息必须明确说明操作的后果**，特别是 "不可恢复" 的提示
3. **对话框默认焦点必须在 "取消" 按钮上**，防止误按回车键确认
4. **危险操作按钮必须使用红色样式**，与普通按钮区分开
5. **危险操作必须记录详细日志**，包括操作人、操作时间、操作内容

### 3.3 命令绑定最佳实践

- 危险操作的命令必须添加权限验证，只有管理员才能执行
- 命令执行前必须再次检查设备状态，确保操作安全
- 命令执行过程中必须禁用按钮，防止重复点击
- 命令执行完成后必须给出明确的结果提示

### 4.2 长按触发的急停按钮

防止误触，可以设置为长按 1 秒才触发急停：

csharp:

```c#
private DateTime _pressTime;

protected override void OnMouseLeftButtonDown(MouseButtonEventArgs e)
{
    _pressTime = DateTime.Now;
    base.OnMouseLeftButtonDown(e);
}

protected override void OnMouseLeftButtonUp(MouseButtonEventArgs e)
{
    if ((DateTime.Now - _pressTime).TotalMilliseconds < 1000)
    {
        e.Handled = true;
        MessageBox.Show("请长按1秒触发急停", "提示", MessageBoxButton.OK, MessageBoxImage.Information);
        return;
    }

    base.OnMouseLeftButtonUp(e);
}
```
