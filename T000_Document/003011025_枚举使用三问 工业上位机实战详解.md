# 003011025_枚举使用三问 工业上位机实战详解

## 问题一：如何在代码中定义枚举类型？

### 1.1 基础语法

csharp:

```c#
// 访问修饰符 enum 枚举名 { 枚举值 = 整数, ... }
public enum 枚举名称
{
    枚举值1 = 整数值1,
    枚举值2 = 整数值2,
    枚举值3 = 整数值3
}
```

### 1.2 工业项目枚举定义黄金规范（必须遵守）

| 规范                       | 说明                                 | 工业场景原因                                                 |
| :------------------------- | :----------------------------------- | :----------------------------------------------------------- |
| ✅ **显式指定所有整数值**   | 每个枚举值都必须写清楚对应的整数     | 必须和 PLC 寄存器值、MES 接口约定值**完全一致**，不能依赖编译器默认分配 |
| ✅ **有效业务值从 1 开始**  | 不要用 0 作为有效业务值              | 枚举的默认值是 0，避免混淆 "未初始化" 和 "有效状态"          |
| ✅ **枚举名用名词**         | 如`EqpMainStatus`、`RecipeEventType` | 表示一组固定的状态或类型                                     |
| ✅ **枚举值用帕斯卡命名法** | 如`RUN`、`DOWN`、`Enable`            | 符合 C# 编码规范，且和 MES 接口要求的字符串一致              |
| ✅ **添加 XML 注释**        | 每个枚举值都要说明含义               | 团队协作和后期维护必备                                       |
| ❌ **不要用中文枚举值**     | 永远不要写`运行中 = 1`               | 会导致序列化、反射等操作出现各种问题                         |

### 1.4 错误定义 vs 正确定义对比

❌ 错误定义（工业项目致命）:

```c#

// PLC 返回 1 对应 DOWN，完全错误

{
	RUN,    // 默认 = 0 
	DOWN,   // 默认 = 1
	Idle,   // 默认 = 2
	PM      // 默认 = 3 
}
```

✅ 正确定义:

```c#
// 显式指定所有值，与 PLC 完全一致
public enum EqpMainStatus 
{                                  
	Undefined = 0, 
	RUN = 1,
	DOWN = 2,
	Idle = 3,
	PM = 4
} 
```



## 问题二：如何将枚举类型转换为其他数据类型？

工业项目中90%的枚举使用都是**PLC整数→枚举→MES字符串/数字**的转换流程，这是必须掌握的核心。

### 2.1 转换关系总览

PLC 读取整数 → 安全转换为枚举 → 业务逻辑判断 → 转换为字符串 / 数字 → 上报 MES

### 2.2 整数 → 枚举（PLC读取后转换）
这是最常用的转换，PLC返回的都是整数，需要转换成强类型枚举。

#### ❌ 不安全写法（绝对不要用）
```csharp
int plcValue = Device.PLC.GetEqpStateMassage;
// 直接强制转换，PLC返回5会得到数字5，不会报错
// 后续逻辑会出现各种诡异问题
EqpMainStatus status = (EqpMainStatus)plcValue;
```

#### ✅ 工业级安全写法（必须用）

使用`Enum.IsDefined`检查转换后的值是否有效，无效值做兜底处理：

csharp:

```c#
int plcValue = Device.PLC.GetEqpStateMassage;
EqpMainStatus status;

if (Enum.IsDefined(typeof(EqpMainStatus), plcValue))
{
    // 有效值，正常转换
    status = (EqpMainStatus)plcValue;
}
else
{
    // 无效值处理：记录日志 + 使用默认值
    Logger.LogCommucation.Error($"PLC返回无效设备状态值：{plcValue}，已自动切换为Idle");
    status = EqpMainStatus.Idle;
}
```

### 2.3 枚举 → 整数（写入 PLC 或上报数字）

csharp:

```c#
EqpMainStatus status = EqpMainStatus.RUN;
// 直接强制转换为整数
int plcValue = (int)status; // 输出：1

// 写入PLC
Device.PLC.WriteInt("DB1.DBW0", plcValue);

// 上报MES数字类型字段
requestObj["RECIPE_EVENT"] = ((int)RecipeEventType.Enable).ToString();
```

### 2.4 枚举 → 字符串（上报 MES 接口）

**这是你 MES 上报最常用的转换**，接口要求的`"RUN"`、`"DOWN"`字符串，直接用`ToString()`就能得到，完全不需要硬编码字符串数组。

csharp:

```c#
EqpMainStatus status = EqpMainStatus.RUN;
// 直接转换为枚举值名称的字符串
string mesStatus = status.ToString(); // 输出："RUN"

// 上报MES
requestObj["MAINSTATUS"] = mesStatus;
```

#### 原代码对比（彻底淘汰硬编码数组）

❌ 原错误代码:

```c#
// 硬编码字符串数组，索引越界风险
List<string> list = new List<string>()
{ 
    "RUN", 
    "DOWN", "IDLE", "PM" }; var eqpStateMessage = list[eqpStatNo - 1].ToString();requestObj["MAINSTATUS"] = eqpStateMessage; 
```

✅ 优化后代码

```c#
// 安全转换 + 直接 ToString，零风险
if (Enum.IsDefined(typeof(EqpMainStatus), eqpStatNo)) 
{
    var status = (EqpMainStatus)eqpStatNo;requestObj["MAINSTATUS"] = status.ToString();   }                                                     |      |
```





### 2.5 字符串 → 枚举（解析MES返回或配置文件）

用于解析MES返回的字符串或配置文件中的字符串值。

#### ❌ 不安全写法
```csharp
string mesResult = "OK";
// 直接Parse，字符串无效会抛出异常
MesResult result = (MesResult)Enum.Parse(typeof(MesResult), mesResult);
```

#### ✅ 工业级安全写法

使用`Enum.TryParse`，不会抛出异常，返回 bool 表示是否成功：

```c#
string mesResult = "OK";
MesResult result;

// ignoreCase: true 表示忽略大小写
if (Enum.TryParse<MesResult>(mesResult, ignoreCase: true, out result))
{
    // 解析成功，正常处理
    if (result == MesResult.OK)
    {
        UpdateProcess("MES上报成功");
    }
}
else
{
    // 解析失败处理
    Logger.LogCommucation.Error($"MES返回无效结果：{mesResult}");
}
```

## 问题三：如何在 UI 界面中显示枚举类型的描述信息？

枚举值是英文（如`RUN`），但操作人员需要看中文（如 "运行中"）。我们通过 **[Description] 特性 + 扩展方法 ** 来实现，这是 WPF 项目的标准做法。

### 3.1 第一步：给枚举添加 [Description] 特性

首先需要引用`System.ComponentModel`命名空间：

csharp:

```c#
using System.ComponentModel;
```

然后给每个枚举值添加中文描述：

csharp:

```c#
public enum EqpMainStatus
{
    [Description("未定义")]
    Undefined = 0,
    
    [Description("运行中")]
    RUN = 1,
    
    [Description("停机")]
    DOWN = 2,
    
    [Description("空闲")]
    Idle = 3,
    
    [Description("维护中")]
    PM = 4
}
```

### 3.2 第二步：编写通用扩展方法获取描述

在`09_Common/Extensions`文件夹下新建`EnumExtensions.cs`：

csharp:

```c#
using System;
using System.ComponentModel;
using System.Reflection;

namespace IndustrialVisionTemplate.Common.Extensions
{
    /// <summary>
    /// 枚举扩展方法
    /// </summary>
    public static class EnumExtensions
    {
        /// <summary>
        /// 获取枚举值的Description特性描述
        /// 如果没有Description特性，返回枚举值的ToString()
        /// </summary>
        public static string GetDescription(this Enum enumValue)
        {
            if (enumValue == null)
                return string.Empty;

            // 获取枚举值的字段信息
            FieldInfo field = enumValue.GetType().GetField(enumValue.ToString());
            if (field == null)
                return enumValue.ToString();

            // 获取Description特性
            DescriptionAttribute attribute = field.GetCustomAttribute<DescriptionAttribute>();
            
            // 返回特性值或枚举名称
            return attribute?.Description ?? enumValue.ToString();
        }
    }
}
```

### 3.3 第三步：在代码中使用

现在你可以在任何地方调用`GetDescription()`方法获取中文描述：

csharp:

```c#
using IndustrialVisionTemplate.Common.Extensions;

// 1. UI状态栏显示中文
EqpMainStatus status = EqpMainStatus.RUN;
StatusTextBlock.Text = $"设备状态：{status.GetDescription()}"; // 显示："设备状态：运行中"

// 2. 日志记录中文
Logger.LogCommucation.Info($"设备状态变更为：{status.GetDescription()}");

// 3. 弹窗提示中文
MessageBox.Show($"设备当前处于{status.GetDescription()}状态，无法执行此操作");
```

### 3.4 WPF 高级用法：枚举绑定到下拉框

如果需要在 ComboBox 中显示枚举的中文描述，可以使用`ObjectDataProvider`和转换器：

#### 第一步：编写枚举描述转换器

csharp:

```c#
using System;
using System.Globalization;
using System.Windows.Data;
using IndustrialVisionTemplate.Common.Extensions;

namespace IndustrialVisionTemplate.Common.Converters
{
    /// <summary>
    /// 枚举转描述转换器
    /// </summary>
    public class EnumToDescriptionConverter : IValueConverter
    {
        public object Convert(object value, Type targetType, object parameter, CultureInfo culture)
        {
            if (value is Enum enumValue)
            {
                return enumValue.GetDescription();
            }
            return string.Empty;
        }

        public object ConvertBack(object value, Type targetType, object parameter, CultureInfo culture)
        {
            throw new NotImplementedException();
        }
    }
}
```

#### 第二步：在 XAML 中使用

xaml:

```xaml
<Window.Resources>
    <converters:EnumToDescriptionConverter x:Key="EnumToDescriptionConverter"/>
    
    <!-- 绑定枚举所有值到下拉框 -->
    <ObjectDataProvider x:Key="EqpMainStatusEnum" 
                        MethodName="GetValues" 
                        ObjectType="{x:Type sys:Enum}">
        <ObjectDataProvider.MethodParameters>
            <x:Type TypeName="models:EqpMainStatus"/>
        </ObjectDataProvider.MethodParameters>
    </ObjectDataProvider>
</Window.Resources>

<!-- 下拉框显示中文描述 -->
<ComboBox ItemsSource="{Binding Source={StaticResource EqpMainStatusEnum}}"
          SelectedItem="{Binding CurrentStatus}"
          DisplayMemberPath="."
          ContentTemplate="{StaticResource EnumDescriptionTemplate}"/>

<!-- 显示模板 -->
<DataTemplate x:Key="EnumDescriptionTemplate">
    <TextBlock Text="{Binding Converter={StaticResource EnumToDescriptionConverter}}"/>
</DataTemplate>
```

## 总结：工业项目枚举使用三步法

1. **定义**：根据 PLC 和 MES 约定，定义强类型枚举，显式指定整数值，添加 [Description] 特性
2. **转换**：从 PLC 读取整数后，用`Enum.IsDefined`安全转换为枚举；上报 MES 时用`ToString()`转字符串，用`(int)`转数字
3. **显示**：用`GetDescription()`扩展方法获取中文描述，用于 UI 和日志
