# 006001002_WPF `Shape` 基类官方定义、功能与使用详解

`Shape` 是 WPF 二维矢量图形体系的**高层抽象基类**，隶属于 `System.Windows.Shapes` 命名空间，是 WPF 中最易用、最常用的绘图载体。它继承自 `FrameworkElement`，因此天然具备完整的 WPF UI 元素能力，可直接融入布局系统、支持数据绑定、样式动画与交互事件，无需开发者手动处理底层渲染逻辑。

------

## 一、官方类定义与继承体系

### 1. 官方基本信息

- **命名空间**：`System.Windows.Shapes`
- **程序集**：`PresentationCore.dll`
- **官方定义**：为二维矢量图形元素提供基类，所有形状均基于向量绘图系统渲染，支持填充、描边、变换等通用绘图能力。
- **类修饰**：`abstract` 抽象类，不能直接实例化，必须使用其标准派生类。

### 2. 完整继承链

plaintext:

```tex
System.Object
  └─ System.Windows.Threading.DispatcherObject
      └─ System.Windows.DependencyObject
          └─ System.Windows.Media.Visual
              └─ System.Windows.UIElement
                  └─ System.Windows.FrameworkElement
                      └─ System.Windows.Shapes.Shape
```

继承 `FrameworkElement` 是 Shape 最核心的特征：它不是单纯的绘图数据，而是**完整的界面控件**，拥有独立的布局槽位、生命周期、输入事件与数据上下文，可直接放入 Grid、StackPanel 等任何布局容器中。

### 3. 标准派生类

WPF 内置 6 个 Shape 标准实现，覆盖绝大多数二维绘图场景：

`Line`、`Rectangle`、`Ellipse`、`Polyline`、`Polygon`、`Path`

## 二、Shape 基类核心属性详解

所有派生类共享以下依赖属性，全部支持数据绑定、样式触发器与动画。

### 1. 填充与描边核心属性

这是 Shape 最基础、最高频使用的属性。

| 属性名                | 类型     | 官方说明                                                     | 典型工业场景                                                 |
| :-------------------- | :------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **`Fill`**            | `Brush`  | 获取或设置用于填充形状内部区域的画刷                         | 状态指示灯填充色、设备本体颜色、工位背景填充；支持纯色、渐变、纹理、图片等所有画刷类型 |
| **`Stroke`**          | `Brush`  | 获取或设置用于绘制形状轮廓的画刷                             | 设备边框、管路线条、分隔线颜色                               |
| **`StrokeThickness`** | `double` | 获取或设置形状轮廓的粗细，单位为与设备无关的像素（默认值 1.0） | 主管路用粗线、支管路用细线，区分线路层级                     |

> 注意：`Line`、`Polyline` 这类开放路径的形状没有闭合内部区域，`Fill` 属性对其无效。

### 2. 笔触样式高级属性

用于精细控制线条的端点、转角、虚线样式，在工业管路、流程图绘制中非常实用。

#### 端点样式

- `StrokeStartLineCap` / `StrokeEndLineCap`：`PenLineCap` 枚举类型，控制直线起点与终点的端头样式。

  枚举值：

  - `Flat`（默认）：平端，线条在端点处精确截止
  - `Round`：圆头，端点处形成半圆
  - `Square`：方头，端点向外延伸线宽的一半长度
  - `Triangle`：三角尖头，端点形成三角形

  工业场景中，绘制管道通常使用 `Round` 圆头，模拟真实管路的平滑衔接。

#### 转角样式

- `StrokeLineJoin`：`PenLineJoin` 枚举类型，控制折线转角处的连接样式。

  枚举值：

  - `Miter`（默认）：尖角连接
  - `Bevel`：斜切倒角
  - `Round`：圆角过渡

- `StrokeMiterLimit`：`double` 类型，限制尖角的延伸长度比例（默认值 10），防止锐角处尖角过长出现视觉异常。

#### 虚线样式

- `StrokeDashArray`：`DoubleCollection` 类型，通过「实线长度，间隙长度」的数值序列定义虚线规则。

  示例：`StrokeDashArray="2,2"`表示 2 像素实线 + 2 像素空白的均匀虚线。

  工业场景中常用虚线表示预留管路、未启用线路、示意边界。

- `StrokeDashOffset`：`double` 类型，虚线的起始偏移量，可实现虚线流动动画。

- `StrokeDashCap`：`PenLineCap` 类型，虚线每一小段的端头样式。

### 3. 拉伸与布局属性

- **`Stretch`**：`Stretch` 枚举类型，控制图形如何适配自身的布局分配空间，是 Shape 布局的核心属性。

  

  枚举值：

  1. `None`（默认，Path 除外）：保持图形原始尺寸，不拉伸，超出布局区域则裁剪
  2. `Fill`：强制拉伸填满整个布局区域，宽高比可能变化，图形会变形
  3. `Uniform`：等比例缩放，完整显示整个图形，不变形，周围可能留空白
  4. `UniformToFill`：等比例缩放填满整个区域，超出部分裁剪，保证无空白

> 除 `Stretch` 外，Shape 继承了 `FrameworkElement` 所有布局属性：`Width`、`Height`、`Margin`、`HorizontalAlignment`、`VerticalAlignment`、`RenderTransform`（旋转 / 缩放 / 平移）、`Opacity` 等，用法与普通控件完全一致。

### 4. 几何与变换属性

- `RenderedGeometry`：`Geometry` 类型，只读，获取形状最终渲染的几何数据。
- `GeometryTransform`：`Transform` 类型，获取或设置应用到形状几何上的变换，在渲染前对图形做坐标变换。

## 三、标准派生类与使用示例

### 1. Line（直线）

**官方说明**：绘制两个坐标点之间的直线段，属于开放路径，仅描边生效，无填充。

**核心独有属性**：`X1`、`Y1`（起点坐标）；`X2`、`Y2`（终点坐标）。

**XAML 示例**：

xaml:

```xaml
<!-- 灰色水平分隔线 -->
<Line X1="0" Y1="10" X2="300" Y2="10" 
      Stroke="Gray" StrokeThickness="2"/>

<!-- 圆头管道样式斜线 -->
<Line X1="0" Y1="0" X2="100" Y2="50"
      Stroke="#1890FF" StrokeThickness="6"
      StrokeStartLineCap="Round" StrokeEndLineCap="Round"/>
```

**适用场景**：产线输送线、管路连接、界面分隔线、电气连线。

### 2. Rectangle（矩形）

**官方说明**：绘制矩形或正方形，支持圆角设置，可填充可描边。

**核心独有属性**：`RadiusX`（水平圆角半径）、`RadiusY`（垂直圆角半径）。

**XAML 示例**：

xaml:

```xaml
<!-- 圆角工位框 -->
<Rectangle Width="120" Height="60" 
           Fill="#F5F9FF" Stroke="#1890FF" StrokeThickness="2"
           RadiusX="6" RadiusY="6"/>
```

**适用场景**：工位框、按钮背景、液位指示器、面板边框、储罐轮廓。

### 3. Ellipse（椭圆 / 圆形）

**官方说明**：绘制椭圆；当 `Width` 与 `Height` 相等时为正圆形。

**独有属性**：无特殊独有属性，通过宽高控制形状。

**XAML 示例（绿色运行状态灯）**：

xaml:

```xaml
<Ellipse Width="16" Height="16" 
         Fill="#52C41A" Stroke="#389E0D" StrokeThickness="1"/>
```

**适用场景**：状态指示灯、设备节点、报警灯，是工业上位机最高频使用的 Shape。

### 4. Polyline（折线）

**官方说明**：由一组顶点连接而成的多段折线，属于开放路径，仅描边生效，不会自动闭合首尾。

**核心独有属性**：`Points`（`PointCollection` 类型，顶点坐标集合）。

**XAML 示例**：

xaml:

```xaml
<Polyline Points="0,50 50,0 100,50 150,0"
          Stroke="#FF7A45" StrokeThickness="2"
          StrokeLineJoin="Round"/>
```

**适用场景**：趋势曲线、管路走向、不规则连线、简单波形示意。

### 5. Polygon（多边形）

**官方说明**：由一组顶点构成的闭合多边形，自动将首尾点连接，支持填充与描边。

**核心独有属性**：`Points` 顶点集合。

**XAML 示例（三角形警告标识）**：

xaml:

```xaml
<Polygon Points="0,20 20,0 40,20"
         Fill="#FAAD14" Stroke="#D48806" StrokeThickness="1"/>
```

**适用场景**：警示标识、六边形工位、不规则设备轮廓、料斗图形。

### 6. Path（路径）

**官方说明**：功能最强的 Shape，通过几何数据绘制任意复杂的二维图形，可包含直线、圆弧、贝塞尔曲线、复合图形、孔洞等。

**核心独有属性**：`Data`（`Geometry` 类型，路径几何数据），支持**路径标记语法**（字符串简写格式）快速定义复杂轮廓。

**常用路径标记语法**：

- `M x,y`：移动画笔到指定点（起点）
- `L x,y`：画直线到指定点
- `A`：画圆弧
- `Z`：闭合路径

**XAML 示例（箭头图形）**：

xaml:

```xaml
<Path Data="M0,10 L20,0 L20,6 L40,6 L40,14 L20,14 L20,20 Z"
      Fill="#1890FF" Stretch="Uniform"/>
```

**适用场景**：自定义设备图标、管道弯头、阀门泵体、复杂流程图、矢量图标。

## 四、核心特性与底层机制

### 1. 矢量无损渲染

Shape 基于 WPF 的矢量渲染管线（DirectX 加速），无论放大、缩小多少倍，都不会出现锯齿、模糊，完美适配工业现场不同分辨率的触控屏、监视器，无需多套图片资源。

### 2. 完整 UI 元素能力

与 GDI+ 绘图、低级 `DrawingVisual` 不同，Shape 是完整的 `FrameworkElement`：

- 参与 WPF 布局系统，支持对齐、边距、自动排列；
- 支持 `MouseEnter`、`MouseLeftButtonUp` 等所有鼠标键盘事件，可实现点击、悬停交互；
- 支持数据绑定、样式、触发器、故事板动画，完全适配 MVVM 架构；
- 支持 `RenderTransform` 变换（旋转、缩放、平移、扭曲），轻松实现设备动画效果。

### 3. 声明式开发

所有图形均可通过 XAML 直接声明定义，无需后台代码编写绘图逻辑，界面与业务逻辑完全分离，符合 WPF 的开发范式，便于样式复用与主题切换。

## 五、进阶用法：数据绑定与状态触发器（工业场景实战）

工业场景中最常用的用法是：将设备运行状态绑定到 Shape 的填充色，通过触发器自动切换状态。

### 示例：状态指示灯（MVVM 数据驱动）

xaml:

```xaml
<Window.Resources>
    <Style x:Key="StatusLampStyle" TargetType="Ellipse">
        <Setter Property="Width" Value="16"/>
        <Setter Property="Height" Value="16"/>
        <Setter Property="StrokeThickness" Value="1"/>
        <Style.Triggers>
            <!-- 运行状态：绿色 -->
            <DataTrigger Binding="{Binding DeviceStatus}" Value="Running">
                <Setter Property="Fill" Value="#52C41A"/>
                <Setter Property="Stroke" Value="#389E0D"/>
            </DataTrigger>
            <!-- 待机状态：黄色 -->
            <DataTrigger Binding="{Binding DeviceStatus}" Value="Standby">
                <Setter Property="Fill" Value="#FAAD14"/>
                <Setter Property="Stroke" Value="#D48806"/>
            </DataTrigger>
            <!-- 故障状态：红色 + 闪烁动画 -->
            <DataTrigger Binding="{Binding DeviceStatus}" Value="Error">
                <Setter Property="Fill" Value="#F5222D"/>
                <Setter Property="Stroke" Value="#CF1322"/>
                <DataTrigger.EnterActions>
                    <BeginStoryboard>
                        <Storyboard RepeatBehavior="Forever">
                            <ColorAnimation 
                                Storyboard.TargetProperty="Fill.Color"
                                From="#F5222D" To="#FFCCC7"
                                Duration="0:0:0.5" AutoReverse="True"/>
                        </Storyboard>
                    </BeginStoryboard>
                </DataTrigger.EnterActions>
            </DataTrigger>
        </Style.Triggers>
    </Style>
</Window.Resources>

<!-- 使用 -->
<Ellipse Style="{StaticResource StatusLampStyle}"/>
```

> 效果：设备状态变化时，指示灯自动切换颜色，故障状态自动红色闪烁，全程数据驱动，无需后台操作 UI。

## 六、综合实战：简易产线工位流程图

通过多个 Shape 组合，快速搭建产线布局图，完全通过 XAML 实现：

xaml:

```xaml
<StackPanel Orientation="Horizontal" VerticalAlignment="Center" Margin="20">
    <!-- 上料工位 -->
    <Rectangle Width="80" Height="50" Fill="#E6F7FF" Stroke="#1890FF" StrokeThickness="2" RadiusX="4" RadiusY="4"/>
    
    <!-- 输送线 -->
    <Line X1="0" Y1="25" X2="60" Y2="25" Stroke="#8C8C8C" StrokeThickness="4" StrokeStartLineCap="Round" StrokeEndLineCap="Round" Margin="-1 0"/>
    
    <!-- 检测工位 + 状态灯 -->
    <Grid>
        <Rectangle Width="80" Height="50" Fill="#F6FFED" Stroke="#52C41A" StrokeThickness="2" RadiusX="4" RadiusY="4"/>
        <Ellipse Width="10" Height="10" Fill="#52C41A" HorizontalAlignment="Right" VerticalAlignment="Top" Margin="0 4 4 0"/>
    </Grid>
    
    <!-- 输送线 -->
    <Line X1="0" Y1="25" X2="60" Y2="25" Stroke="#8C8C8C" StrokeThickness="4" StrokeStartLineCap="Round" StrokeEndLineCap="Round" Margin="-1 0"/>
    
    <!-- 下料工位 -->
    <Rectangle Width="80" Height="50" Fill="#FFF1F0" Stroke="#F5222D" StrokeThickness="2" RadiusX="4" RadiusY="4"/>
</StackPanel>
```

## 七、选型建议与性能注意事项

### 1. 不同绘图方案对比

| 方案            | 层级   | 交互能力                   | 性能量级           | 适用工业场景                                               |
| :-------------- | :----- | :------------------------- | :----------------- | :--------------------------------------------------------- |
| **Shape**       | 高层   | 完整 UI 交互               | 百级以内无压力     | 少量图形、需要状态绑定与交互，如指示灯、工位图、简单流程图 |
| Geometry + Path | 中高层 | 仅 Path 容器可交互         | 千级以内           | 中等复杂度图形，如设备简图、自定义图标                     |
| DrawingVisual   | 底层   | 无原生交互，需手动命中测试 | 万级以上           | 海量数据点、实时高速曲线、复杂工业图纸                     |
| WriteableBitmap | 底层   | 无原生交互                 | 极高（像素级操作） | 高速图像渲染、相机实时画面显示                             |

### 2. 性能优化建议

1. **数量控制**：单个界面 Shape 数量建议控制在数百个以内，超大量图形优先使用 `DrawingVisual`。
2. **画刷复用**：相同颜色的 Fill/Stroke 尽量复用静态画刷资源，减少重复创建。
3. **避免频繁变更**：减少动画中对 Fill、StrokeThickness 等属性的高频修改，降低渲染开销。
4. **复杂图形用 Path**：多个简单 Shape 组合的复杂图形，优先合并为单个 Path，减少布局与渲染开销。
