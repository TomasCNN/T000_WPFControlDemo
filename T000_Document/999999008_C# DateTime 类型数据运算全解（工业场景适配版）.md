# 999999008_C# `DateTime` 类型数据运算全解（工业场景适配版）

`DateTime` 是 C# 中表示时间点的**值类型结构体**，所有运算均返回新的 `DateTime` 对象（原对象不变，即「不可变类型」）。核心运算分为**时间偏移加减、时间差计算、大小比较、日期对齐取整**四大类，是工业软件中班次统计、产能计算、报警时长、报表区间、PLC 时间戳处理的核心基础。

------

## 一、时间偏移运算：加减时间量

通过 `AddXXX` 系列方法，在当前时间点上加减指定时长，返回新的时间点。所有方法均不修改原对象，必须用返回值接收结果。

### 1. 核心方法一览

| 方法                         | 作用                 | 工业典型场景                 |
| :--------------------------- | :------------------- | :--------------------------- |
| `AddYears(int years)`        | 加减年数             | 计算年度报表周期             |
| `AddMonths(int months)`      | 加减月数             | 计算月度产能区间、保质期     |
| `AddDays(double days)`       | 加减天数             | 计算 7 天历史数据、30 天趋势 |
| `AddHours(double hours)`     | 加减小时数           | 计算 8 小时班次结束时间      |
| `AddMinutes(double minutes)` | 加减分钟数           | 计算节拍累计、报警持续预判   |
| `AddSeconds(double seconds)` | 加减秒数             | 超时判断、延时触发           |
| `AddMilliseconds(double ms)` | 加减毫秒数           | 高精度时间戳校准             |
| `AddTicks(long ticks)`       | 加减刻度（100 纳秒） | 底层高精度时间计算           |
| `Add(TimeSpan ts)`           | 加减一个时间间隔     | 通用时间偏移计算             |

### 2. 代码示例

csharp:

```c#
DateTime now = DateTime.Now;

// 计算8小时后（白班结束时间）
DateTime shiftEnd = now.AddHours(8);

// 计算30天前（历史数据起始时间）
DateTime historyStart = now.AddDays(-30);

// 计算当月第一天加1个月（下月第一天）
DateTime nextMonth = new DateTime(now.Year, now.Month, 1).AddMonths(1);

// 加减 TimeSpan 时间间隔
TimeSpan step = TimeSpan.FromSeconds(12); // 12秒节拍
DateTime nextProductTime = now.Add(step);
```

> ⚠️ 重要注意
>
> 1. `DateTime` 是不可变类型，`now.AddDays(1)` 不会修改 `now`，必须用新变量接收。
> 2. `AddMonths` / `AddYears` 会自动处理月末、闰年，例如 `1月31日.AddMonths(1)` 会返回 `2月28日/29日`，不会报错。

## 二、时间差运算：计算两个时间点的间隔

两个 `DateTime` 相减，会得到 `TimeSpan` 类型的时间间隔，用于计算运行时长、停机时长、节拍耗时等。

### 1. 基础语法

csharp:

```c#
DateTime start = DateTime.Parse("2026-06-16 08:00:00");
DateTime end = DateTime.Parse("2026-06-16 16:30:45");

// 时间差：结束时间 - 开始时间 = TimeSpan
TimeSpan duration = end - start;
```

### 2. TimeSpan 核心属性

| 属性           | 含义               | 示例值（对应上例） |
| :------------- | :----------------- | :----------------- |
| `TotalHours`   | 总小时数（带小数） | `8.5125`           |
| `TotalMinutes` | 总分钟数（带小数） | `510.75`           |
| `TotalSeconds` | 总秒数（带小数）   | `30645`            |
| `Hours`        | 小时部分（0~23）   | `8`                |
| `Minutes`      | 分钟部分（0~59）   | `30`               |
| `Seconds`      | 秒部分（0~59）     | `45`               |

### 3. 工业场景示例

csharp:

```c#
// 场景1：计算设备运行时长
DateTime runStart = plcRunStartTime.Value; // PLC记录的启动时间
TimeSpan runDuration = DateTime.Now - runStart;
double runHours = runDuration.TotalHours; // 用于产能核算

// 场景2：计算报警持续时间
TimeSpan alarmDuration = alarmEndTime - alarmStartTime;
string alarmTip = $"报警持续 {alarmDuration.Hours}小时{alarmDuration.Minutes}分钟";

// 场景3：计算生产节拍
DateTime product1Time = DateTime.Parse("10:00:00");
DateTime product2Time = DateTime.Parse("10:00:12");
double beatSeconds = (product2Time - product1Time).TotalSeconds; // 12秒/片
```

### 4. 反向运算

csharp:

```c#
// DateTime + TimeSpan = DateTime
DateTime next = startTime + TimeSpan.FromHours(8);

// DateTime - TimeSpan = DateTime
DateTime before = endTime - TimeSpan.FromMinutes(30);
```

## 三、比较运算：判断时间先后

支持运算符直接比较，也支持方法调用，用于判断时间区间、是否过期、班次是否结束。

### 1. 运算符比较（最常用）

csharp:

```c#
DateTime t1 = new DateTime(2026, 6, 16);
DateTime t2 = new DateTime(2026, 6, 20);

bool isEarlier = t1 < t2;    // true
bool isLater = t1 > t2;      // false
bool isEqual = t1 == t2;     // false
bool isNotEqual = t1 != t2;  // true
bool isEarlyOrEqual = t1 <= t2; // true
```

### 2. 方法比较

csharp:

```c#
// CompareTo：小于返回-1，等于返回0，大于返回1
int result = t1.CompareTo(t2);

// 判断时间是否在区间内（报表查询高频）
DateTime queryStart = new DateTime(2026, 6, 1);
DateTime queryEnd = new DateTime(2026, 6, 30);
bool inRange = t1 >= queryStart && t1 <= queryEnd;
```

> ⚠️ 注意：比较时确保两个 `DateTime` 的 `Kind` 属性一致（均为本地时间或均为 UTC），否则可能出现逻辑错误。工业场景建议统一使用本地时间或统一转 UTC 后再比较。

## 四、工业高频：日期对齐与取整运算

产能统计、班次划分、报表生成场景中，经常需要把时间对齐到整点、当天零点、周初、月初等基准点。

### 1. 取当天零点（最常用）

csharp:

```c#
DateTime now = DateTime.Now;
DateTime dayStart = now.Date; // 当天 00:00:00

// 当天最后一刻（用于SQL查询闭区间）
DateTime dayEnd = now.Date.AddDays(1).AddTicks(-1); // 23:59:59.9999999
```

### 2. 取当月第一天

csharp:

```c#
DateTime monthStart = new DateTime(now.Year, now.Month, 1);
```

### 3. 取当周周一（国内生产周统计）

csharp

```c#
DateTime today = shturl.cc/mbc5;
int dayOfWeek = (int)today.DayOfWeek; // 周日=0，周一=1...周六=6
// 转换为周一为一周起点
int offset = dayOfWeek == 0 ? -6 : 1 - dayOfWeek;
DateTime weekStart = today.AddDays(offset).Date;
```

### 4. 按小时取整（小时产能统计）

舍去分钟和秒，对齐到整点：

csharp:

```c#
DateTime now = DateTime.Now;
DateTime hourStart = now.Date.AddHours(now.Hour); // 当前小时 0分0秒
```

### 5. 班次时间对齐

例如白班 08:00 开始，计算当前时间所属班次的起始时间：

csharp:

```c#
DateTime now = DateTime.Now;
DateTime shiftStart;
if (now.Hour >= 8 && now.Hour < 20)
{
    // 白班：当天8点
    shiftStart = now.Date.AddHours(8);
}
else
{
    // 夜班：当天20点（0点后则前一天20点）
    shiftStart = now.Hour < 8 
        ? now.Date.AddDays(-1).AddHours(20) 
        : now.Date.AddHours(20);
}
```

## 五、可空 `DateTime?` 安全运算

`DatePicker.SelectedDate`、数据库可空时间字段、PLC 读取的时间戳，通常都是 `DateTime?`（可空 DateTime），运算前必须判空，避免空引用异常。

### 1. 基础判空

csharp:

```c#
DateTime? selectedDate = datePicker.SelectedDate;

if (selectedDate.HasValue)
{
    // 有值才运算
    DateTime end = selectedDate.Value.AddDays(1);
}
```

### 2. 空合并运算符（简化写法）

csharp:

```c#
// 为空则默认用今天
DateTime date = selectedDate ?? shturl.cc/mbc5;
DateTime endDate = date.AddDays(7);
```

### 3. 空值时间差安全写法

csharp:

```c#
DateTime? startTime = GetPlcStartTime();
DateTime? endTime = GetPlcEndTime();

// 两个都有值才计算时长
TimeSpan? duration = startTime.HasValue && endTime.HasValue
    ? endTime.Value - startTime.Value
    : null;
```

## 七、常见坑与最佳实践

1. **不可变性**：所有 `AddXXX` 方法都不会修改原对象，必须用变量接收返回值，这是新手最容易犯的错误。
2. **DateTime.Kind**：`DateTime.Now` 是本地时间，`DateTime.UtcNow` 是 UTC 时间，两者直接比较会出错；存入数据库、跨服务传输时建议统一用 UTC。
3. **月末 / 闰年**：不要自己通过「加天数」实现加月，直接用 `AddMonths`，框架会自动处理 28/29/30/31 天。
4. **精度问题**：`DateTime` 理论精度是 100 纳秒，但 Windows 系统时钟实际精度约 10~15 毫秒，毫秒级以下比较无意义。
5. **相等比较**：工业场景尽量不要用 `==` 判断两个时间点完全相等，建议判断时间差小于某个阈值（如 `Math.Abs((t1-t2).TotalMilliseconds) < 50`）。
6. **高频运算性能**：大量时间计算优先用 `Ticks` 运算，性能优于 `AddXXX` 方法。
