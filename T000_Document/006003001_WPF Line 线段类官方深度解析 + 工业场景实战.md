# 006003001_WPF `Line` 线段类官方深度解析 + 工业场景实战

`Line` 是 WPF 矢量图形体系中 `Shape` 抽象基类的**密封派生类**，用于绘制两点定义的单段直线，是工业上位机中实现刻度标尺、尺寸标注、限位警戒线、扫描辅助线、运动轴指示的核心图形控件。它本身仅提供端点坐标定义，所有描边样式、布局交互能力全部继承自 `Shape` 基类。

------

## 一、官方类定义与继承体系

### 1. 基础信息

- **命名空间**：`System.Windows.Shapes`
- **程序集**：`PresentationFramework.dll`（WPF 核心框架程序集）
- **类修饰符**：`public sealed`（公共密封类，不可被继承）

### 2. 完整继承链

plaintext:

```tex
System.Object
  └─ System.Windows.Threading.DispatcherObject
     └─ System.Windows.DependencyObject
        └─ System.Windows.Media.Visual
           └─ System.Windows.UIElement
              └─ System.Windows.FrameworkElement
                 └─ System.Windows.Shapes.Shape
                    └─ System.Windows.Shapes.Line
```

- 继承 `FrameworkElement`：天然融入 WPF 布局系统，支持数据绑定、样式、动画、路由事件；
- 继承 `Shape`：获得统一的描边、拉伸、几何渲染等图形通用能力；
- `Line` 自身：仅实现直线的几何定义与端点坐标属性，是 Shape 体系中最轻量化的具体图形。

### 3. 官方类声明

csharp:

```c#
public sealed class Line : Shape
{
    // 四个独有依赖属性字段
    public static readonly DependencyProperty X1Property;
    public static readonly DependencyProperty Y1Property;
    public static readonly DependencyProperty X2Property;
    public static readonly DependencyProperty Y2Property;

    // 构造函数
    public Line();

    // 四个端点坐标属性
    public double X1 { get; set; }
    public double Y1 { get; set; }
    public double X2 { get; set; }
    public double Y2 { get; set; }

    // 重写Shape抽象属性：定义直线几何
    protected override Geometry DefiningGeometry { get; }
}
```

#### 关键解读

1. **密封类设计**：不允许继承 `Line`，如需自定义直线变体（带箭头的直线），请直接继承 `Shape` 基类重写 `DefiningGeometry`；
2. **极轻量实现**：仅新增 4 个坐标依赖属性 + 1 个重写几何属性，无其他自定义方法，所有外观逻辑全部复用基类；
3. **开放图形特性**：直线属于非闭合图形，**`Fill` 填充属性完全无效**，仅 `Stroke` 描边属性生效，这是新手最高频踩坑点。

## 二、核心属性深度解析

### 1. Line 独有：端点坐标属性（4 个）

这是直线的形状定义核心，全部为依赖属性，原生支持数据绑定、动画驱动。

| 属性 | 类型     | 默认值 | 官方说明                                            |
| :--- | :------- | :----- | :-------------------------------------------------- |
| `X1` | `double` | `0.0`  | 线段起点的 X 轴坐标，相对于 Line 元素自身的布局区域 |
| `Y1` | `double` | `0.0`  | 线段起点的 Y 轴坐标                                 |
| `X2` | `double` | `0.0`  | 线段终点的 X 轴坐标                                 |
| `Y2` | `double` | `0.0`  | 线段终点的 Y 轴坐标                                 |

> 坐标说明：坐标原点在 Line 元素布局区域的左上角，X 向右递增，Y 向下递增，与 WPF 标准坐标系一致。

### 2. 继承自 Shape 的核心描边属性

Line 是纯轮廓图形，描边属性直接决定显示效果，工业场景高频使用：

| 属性                 | 类型               | 工业用途                                                     |
| :------------------- | :----------------- | :----------------------------------------------------------- |
| `Stroke`             | `Brush`            | 线条颜色 / 画刷，为 `null` 时线条完全不显示                  |
| `StrokeThickness`    | `double`           | 线条厚度，单位为与设备无关像素，支持小数                     |
| `StrokeStartLineCap` | `PenLineCap`       | 起点端点样式：`Flat`(平端)/`Square`(方端)/`Round`(圆端)/`Triangle`(三角端) |
| `StrokeEndLineCap`   | `PenLineCap`       | 终点端点样式，同起点                                         |
| `StrokeDashArray`    | `DoubleCollection` | 虚线样式，按「实线长度、空白长度」交替循环                   |
| `StrokeDashOffset`   | `double`           | 虚线起始偏移量，配合动画实现流动效果                         |
| `StrokeDashCap`      | `PenLineCap`       | 虚线段的端点样式                                             |

> 工业场景技巧：
>
> - 标尺刻度线用 `Flat` 平端，保证刻度精度；
> - 指示线、轨迹线用 `Round` 圆端，避免尖锐毛刺，视觉更柔和；
> - 扫描线、传送带用 `StrokeDashOffset` 动画模拟单向流动。

### 3. 无效属性说明

- **`Fill` 填充属性**：Line 是开放图形，没有封闭内部区域，设置 `Fill` 完全不生效，不会有任何填充效果；
- **`StrokeLineJoin` 拐角属性**：单段直线没有拐角，该属性无效果，仅对 `Polyline`、`Polygon` 等多段图形生效。

### 4. 布局与拉伸属性

| 属性             | 作用                     | 直线场景特性                                                 |
| :--------------- | :----------------------- | :----------------------------------------------------------- |
| `Stretch`        | 控制线条如何适配布局空间 | `None`（默认）：按坐标原始长度；`Fill`：拉伸填满容器；`Uniform`：等比例缩放 |
| `Width`/`Height` | 布局尺寸                 | **不直接决定线条长度**，仅影响元素的布局空间；线条长度由 `X1/Y1/X2/Y2` 和 `Stretch` 共同决定 |

> 高频坑：给 Line 设置 `Width="100"` 不会让线条变成 100 像素长，线条长度只由两个端点的坐标差决定。

## 三、核心功能与底层原理

### 1. 形状定义：DefiningGeometry 实现

`Line` 唯一重写的核心属性，内部逻辑：

1. 读取 `X1`、`Y1`、`X2`、`Y2` 四个坐标值；
2. 构造 `LineGeometry` 直线几何对象，传入起止点；
3. 返回该几何对象供基类渲染使用。

csharp:

```c#
protected override Geometry DefiningGeometry
{
    get
    {
        return new LineGeometry(
            new Point(X1, Y1), 
            new Point(X2, Y2));
    }
}
```

### 2. 渲染机制

基类 `Shape` 的 `OnRender` 方法拿到几何对象后：

- 跳过填充绘制（开放图形填充无意义）；
- 根据 `Stroke`、`StrokeThickness`、线帽、虚线等参数构造 `Pen` 对象；
- 调用 `DrawingContext.DrawLine` 绘制直线，通过 DirectX 硬件加速输出。

### 3. 精确命中测试

Line 基于线条实际范围做命中测试：

- 只有点击到线条实体（含厚度范围）才会触发鼠标事件；
- 线条外接矩形内的空白区域不会响应点击；
- 工业场景中点击刻度线、标注线交互时，精准度远高于矩形控件。

### 4. 布局行为

- `MeasureOverride`：根据端点坐标、线条厚度计算元素的期望尺寸；
- `ArrangeOverride`：应用 `Stretch` 拉伸模式，调整最终渲染坐标；
- 在 Canvas 中使用时，`Canvas.Left/Top` 定位的是 Line 元素的左上角，端点坐标相对于元素自身计算。

## 四、基础使用方法

### 1. XAML 基础用法

最常用方式，直接声明并设置端点坐标与样式。

xaml:

```xaml
<!-- 水平直线：从(0,0)到(200,0)，红色2像素 -->
<Line X1="0" Y1="0" X2="200" Y2="0"
      Stroke="Red" StrokeThickness="2"/>

<!-- 垂直直线：黑色1像素，平端 -->
<Line X1="50" Y1="0" X2="50" Y2="100"
      Stroke="Black" StrokeThickness="1"
      StrokeStartLineCap="Flat" StrokeEndLineCap="Flat"/>

<!-- 斜向虚线：蓝色虚线 -->
<Line X1="0" Y1="0" X2="150" Y2="150"
      Stroke="Blue" StrokeThickness="1.5"
      StrokeDashArray="4,2"/>
```

### 2. C# 后台动态创建

适合算法动态生成辅助线、限位线的场景。

csharp:

```c#
using System.Windows.Media;
using System.Windows.Shapes;

// 创建水平限位线
Line limitLine = new Line();
limitLine.X1 = 0;
limitLine.Y1 = 0;
limitLine.X2 = 500;
limitLine.Y2 = 0;

// 样式设置
limitLine.Stroke = new SolidColorBrush(Colors.Red);
limitLine.StrokeThickness = 2;
limitLine.StrokeDashArray = new DoubleCollection() { 6, 3 };
limitLine.StrokeStartLineCap = PenLineCap.Flat;

// 添加到Canvas，定位到Y=200处
Canvas.Children.Add(limitLine);
Canvas.SetTop(limitLine, 200);
Canvas.SetLeft(limitLine, 50);
```

### 3. 不同布局容器中的使用

- **Canvas 绝对定位**：最常用，`Canvas.Left/Top` 定位线条整体位置，端点坐标做相对偏移，适合精确绘图；
- **Grid 自适应**：配合 `Stretch="Fill"`，线条自动拉伸填满单元格，适合分隔线、边框线；
- **StackPanel 流式布局**：参与标准流式布局，适合简单的分隔线场景。

## 五、工业上位机实战实例

### 案例 1：标尺刻度线（主刻度 + 次刻度）

**场景**：视觉检测界面的坐标轴标尺、运动轴位置刻度。

xaml:

```xaml
<Canvas Width="500" Height="60" SnapsToDevicePixels="True">
    <!-- 主刻度轴线 -->
    <Line X1="20" Y1="50" X2="480" Y2="50"
          Stroke="Black" StrokeThickness="1.5"/>

    <!-- 长主刻度（每50像素一个） -->
    <Line X1="20" Y1="30" X2="20" Y2="50" Stroke="Black" StrokeThickness="1.5"/>
    <Line X1="70" Y1="30" X2="70" Y2="50" Stroke="Black" StrokeThickness="1.5"/>
    <Line X1="120" Y1="30" X2="120" Y2="50" Stroke="Black" StrokeThickness="1.5"/>
    <!-- ... 更多主刻度 -->

    <!-- 短次刻度（每10像素一个） -->
    <Line X1="30" Y1="40" X2="30" Y2="50" Stroke="Gray" StrokeThickness="1"/>
    <Line X1="40" Y1="40" X2="40" Y2="50" Stroke="Gray" StrokeThickness="1"/>
    <Line X1="50" Y1="40" X2="50" Y2="50" Stroke="Gray" StrokeThickness="1"/>
    <Line X1="60" Y1="40" X2="60" Y2="50" Stroke="Gray" StrokeThickness="1"/>
    <!-- ... 更多次刻度 -->
</Canvas>
```

**要点**：`SnapsToDevicePixels="True"` 保证刻度线对齐物理像素，不发虚，精度更高。

### 案例 3：动态流动扫描线

**场景**：线扫相机扫描过程指示，通过虚线流动动画直观展示扫描进度与方向。

xaml:

```xaml
<Canvas Width="400" Height="300" Background="#1E1E1E">
    <!-- 扫描线：绿色流动虚线 -->
    <Line X1="0" Y1="150" X2="400" Y2="150"
          Stroke="LimeGreen" StrokeThickness="2"
          StrokeDashArray="10,5"
          StrokeDashCap="Round">
        <Line.Triggers>
            <EventTrigger RoutedEvent="Loaded">
                <BeginStoryboard>
                    <Storyboard RepeatBehavior="Forever">
                        <!-- 虚线偏移量动画，实现从左到右流动 -->
                        <DoubleAnimation 
                            Storyboard.TargetProperty="StrokeDashOffset"
                            From="0" To="-15" Duration="0:0:0.6" />
                    </Storyboard>
                </BeginStoryboard>
            </EventTrigger>
        </Line.Triggers>
    </Line>
</Canvas>
```

**原理**：持续修改 `StrokeDashOffset` 让虚线产生单向位移，模拟扫描、传送的运动感，工业设备中非常常用。

### 案例 5：C# 动态生成网格线

**场景**：视觉检测界面的定位网格，后台代码批量生成。

csharp:

```c#
/// <summary>
/// 在Canvas上绘制等距网格线
/// </summary>
/// <param name="canvas">目标画布</param>
/// <param name="width">总宽度</param>
/// <param name="height">总高度</param>
/// <param name="gridSize">网格间距</param>
public void DrawGrid(Canvas canvas, double width, double height, double gridSize)
{
    Brush gridBrush = new SolidColorBrush(Color.FromArgb(50, 128, 128, 128));
    gridBrush.Freeze();

    // 垂直网格线
    for (double x = 0; x <= width; x += gridSize)
    {
        Line vLine = new Line();
        vLine.X1 = x;
        vLine.Y1 = 0;
        vLine.X2 = x;
        vLine.Y2 = height;
        vLine.Stroke = gridBrush;
        vLine.StrokeThickness = 1;
        canvas.Children.Add(vLine);
    }

    // 水平网格线
    for (double y = 0; y <= height; y += gridSize)
    {
        Line hLine = new Line();
        hLine.X1 = 0;
        hLine.Y1 = y;
        hLine.X2 = width;
        hLine.Y2 = y;
        hLine.Stroke = gridBrush;
        hLine.StrokeThickness = 1;
        canvas.Children.Add(hLine);
    }
}
```

## 六、常见避坑与最佳实践

### 1. 高频坑：设置了 Fill 但没效果

Line 是开放图形，没有封闭内部区域，`Fill` 属性完全无效，只需设置 `Stroke` 和 `StrokeThickness` 即可显示线条。

### 2. 高频坑：Width/Height 不控制线条长度

`Width`、`Height` 是布局属性，不决定线条本身的长度；线条长度由 `X1/X2`、`Y1/Y2` 的坐标差 + `Stretch` 模式共同决定。

### 3. 线条模糊发虚

- 原因：坐标落在像素缝隙中，亚像素渲染导致边缘模糊；
- 解决：父容器设置 `SnapsToDevicePixels="True"`，尽量使用整数坐标。

### 4. 端点样式选择

- 刻度、标注用 `Flat` 平端，保证尺寸精度；
- 指示线、轨迹用 `Round` 圆端，视觉更平滑；
- 标注箭头用 `Triangle` 三角端，简单场景可替代箭头图形。

### 5. 性能注意事项

- 少量线条（几十条）用 Line 开发效率最高；
- 上百条高频刷新的线条（如实时轨迹），每个 Line 都是完整 `FrameworkElement`，有布局开销，建议改用 `DrawingVisual` 或 `WriteableBitmap` 低层绘制；
- 静态线条使用的画刷调用 `Freeze()` 冻结，提升渲染性能。

### 6. 多段折线用 Polyline

如果需要绘制连续多段折线（运动轨迹、曲线），不要用多个 Line 拼接，直接使用 `Polyline` 控件，性能更好、拐角更平滑、代码更简洁。
